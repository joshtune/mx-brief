What it is: A walkthrough of Claude Code subagents — what they are, why they exist, and how to use them better than most people.

How it works:

  • The main session is the orchestrator — it's the only one talking to you. It delegates discrete tasks (read these files, do this research, fix that bug) to subagents, which report back so the main session relays results.

  • Per-subagent model selection — main session can run on Opus while subagents run on cheaper Haiku or Sonnet, so you get research done faster and cheaper without burning your premium context.
  • Built-in subagents exist — Claude Code auto-invokes its own research agent without you explicitly asking.
  • Demos shown in both the terminal and the Claude Desktop app (he notes the desktop app is easier to visualize parallel agent sessions).
