Claude Code Dynamic Workflows Clearly Explained

23.1K

Claude Code's new dynamic workflows feature, explained and compared.

If you're already on Claude Code, this clarifies when workflows beat sub-agents/agent teams — and how one prompt can quietly torch half your $200/month limit.

details

What it is: Claude Code's new Dynamic Workflows feature (shipped with Opus 4.8), where Claude writes a JavaScript orchestration script that fans out to many parallel agents and merges their results.

How it works:

  • You describe an end goal; Claude generates a JavaScript file that becomes the actual workflow — it holds the plan, not the main session.
  • That script dynamically spins up many agents (can be hundreds). In Nate's demo it launched 41 Haiku scoring agents (one per skill), all running in parallel.
  • Parallel agents keep it fast, but burn input tokens hard — his skill-analysis run ate ~5M input tokens (cheap-ish because little output), and one heavier workflow burned half his $200/mo Max sub in a single 30+ min prompt.
  • Results from all sub-agents merge and flow into a final Opus synthesis agent, which here produced an HTML report ranking all 41 skills worst→best with fix suggestions, patterns, and pitfalls.
  • Workflows can be saved and re-run later like reusable automations.

The 'ladder' — how it differs from existing features:

  • Skill = a reusable recipe; can be run by you, an automation, a sub-agent, an agent team, or a workflow.
  • Sub-agents = parallel agents with their own clean context; can't talk to each other, only report back to the main session.
  • Agent teams = a small crew with individual roles/tools that DO talk to each other and share a task list (war rooms, councils, debates) — pricier.
  • Workflows = Claude-authored script running many lone sub-agents in parallel, results merged at the end. Highest complexity/functionality = highest cost + risk.

Watch out for:

  • No hard cost guardrail mentioned — easy to nuke your session limit fast if you aren't deliberate.
  • Question Nate raises: did Anthropic ship this partly to incentivize more token burn?

Tools & links:

  • Claude Code (Opus 4.8) — the platform this feature ships on; no repo, it's the CLI itself.
  • Nate's free AI OS course — Skool community
  • AI Automation Society Plus — paid courses + support
  • Lovable — sponsor (app builder), not part of the workflow demo

Why it matters for you: This is the clearest mental model yet for choosing between skills, sub-agents, agent teams, and workflows in Claude Code — plus a real token-cost reality check before you wire one into your own dev pipeline.

BEAST RTX 5090 vs RTX Pro 6000

7.0K

Three NVIDIA GPUs benchmarked head-to-head on AI inference.

If you're weighing a GPU AI box against a Mac mini, this shows where a $10K+ workstation card actually wins — and where it embarrassingly loses.

details

What it is: Real AI inference benchmarks (not games) pitting a regular RTX 5090, the limited-edition RTX 5090 Lightning, and the workstation-class RTX Pro 6000 against each other.

The hardware in play:

  • RTX 5090 (regular) — baseline consumer flagship, ~$2K street
  • RTX 5090 Lightning — limited edition (case #27/1,666, GPU #48/1,300), ~8% faster than stock, premium/scalper pricing
  • RTX Pro 6000 — workstation card with a 1,000-watt power cap, the expensive option (typically ~$8K–$10K)

How the benchmark ran (Qwen3 4B, BF16):

  • Single-stream prefill (i.e. you chatting with it):
  • Regular 5090 → 27,000 tok/s
  • 5090 Lightning → 29,414 tok/s (~8% faster)
  • RTX Pro 6000 → 49,520 tok/s — nearly 2× either 5090
  • Decode / generation speed (the number you actually feel when chatting):
  • Regular 5090 → 160 tok/s
  • 5090 Lightning → 162 tok/s
  • RTX Pro 6000 → 151 tok/s — the most expensive card is the *slowest* for single-user chat

The takeaway he's setting up: Prefill (prompt ingestion / batch throughput) scales with the Pro 6000's horsepower, but for one person chatting, the cheap 5090 ties or beats the $10K card. Pay-up only pays off under heavy parallel load.

Tools & links:

  • Mac Studio CLUSTER vs M3 Ultra — his Apple-silicon AI comparison
  • Mini PC portable setup — small-form AI rig
  • Model tested: Qwen3 4B (BF16)

Why it matters for you: Direct answer to your question — for solo AI chat, a single RTX 5090 box delivers near-identical or better speed than a $10K Pro 6000 and crushes a Mac mini on raw tokens; the Pro 6000 only justifies its price for batched/multi-user prefill workloads.

  • "Scaffolding" = the systems, context, and coaching that turn a high bar into something reachable.
