Anthropic Engineer Explains: What to Build Instead of AI Agents

103.9K

Build reusable Claude Code skills, not bespoke agents.

Nate distills Anthropic's own skill-building playbook into four concrete practices (saved scripts, progressive disclosure, etc.) you can apply to your Claude Code setup today.

details

What it is: A breakdown of why Anthropic's skills creators (Barry Zhang and Mahesh Murag) stopped building one-off agents and started packaging jobs as skills for one general-purpose agent, plus four practices that make skills actually work.

The core mental model:

  • Model = processor, agent runtime (Claude Code) = operating system, skills = apps
  • You don't rebuild the OS for every job; you give the same agent a skill containing the process, context, scripts, and examples for that specific task
  • Claude Code already reads files, writes code, and calls tools, so a skill just needs to steer it, not rebuild it

Practice 1: DRY for Claude (save proven scripts):

  • Anthropic's team watched Claude rewrite the same slide-styling Python script every run, burning tokens and producing inconsistent output
  • Fix: have Claude save the script inside the skill as a "tool for its future self" and execute that file on future runs
  • Nate's carousel workflow does this: renderers, templates, and scripts are fixed; Claude only changes the content
  • The prompt he uses: "Save the script you just used inside the skill's scripts folder. Update SKILL.md so future runs execute that file instead of rewriting it. Run the skill again and verify the result."
  • Still test it: run the same task twice, compare the important parts, confirm the skill is actually calling the saved file

Practice 2: Progressive disclosure (the mechanic's toolbox):

  • Claude doesn't load every skill's full instructions, examples, and scripts at startup
  • It starts with only the name and description of each skill, then loads the full body only when the job matches
  • Write skill names and descriptions so Claude can route correctly without reading everything (the transcript cuts off here; practices 3 and 4 are in the remainder of the video)
