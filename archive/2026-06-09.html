How to Build Claude Subagents Better Than 99% of People

13.9K

How and when to use Claude Code subagents.

Subagents let you offload research and grunt work to fresh, cheaper-model contexts so your main session stays clean and focused — directly useful for any dev running Claude Code on real codebases.

details

What it is: A walkthrough of Claude Code subagents — what they are, why they exist, and how to use them better than most people.

How it works:

  • The main session is the orchestrator — it's the only one talking to you. It delegates discrete tasks (read these files, do this research, fix that bug) to subagents, which report back so the main session relays results.
  • Subagents run in parallel — Nate spins up 5 at once, each with a distinct persona/lens (beginner, software engineer, business owner, publisher, enterprise COO) to review his book from different angles.
  • Each subagent gets its own injected prompt — you can scroll into a subagent's session and see the exact prompt the main session handed it (e.g. "You are Linda, 58, a retired teacher, complete AI beginner — read all chapters and give a review").
  • Context isolation is the killer feature — subagents run in a completely fresh context, so heavy research/file-reading doesn't pollute your main context window (he shows the status line at ~48k tokens / 5%).
  • Per-subagent model selection — main session can run on Opus while subagents run on cheaper Haiku or Sonnet, so you get research done faster and cheaper without burning your premium context.
  • Built-in subagents exist — Claude Code auto-invokes its own research agent without you explicitly asking.
  • Demos shown in both the terminal and the Claude Desktop app (he notes the desktop app is easier to visualize parallel agent sessions).

Tools & links:

  • AI Automation Society (free Skool) — Nate's free AI OS course
  • AI Automation Society Plus (paid Skool) — full courses + unlimited support
  • Claude Code (terminal + Desktop app) — the host environment for subagents
  • Fireflies.ai — used as the example research target for a subagent demo
  • Models referenced: Opus (main), Haiku / Sonnet (cheaper subagent work)

Why it matters for you: This is the practical mental model for delegation in Claude Code — keep your orchestrator context clean, push expensive exploration to disposable cheaper-model agents, and parallelize independent work; the transcript is light on config files/repos but heavy on the *when and why* of reaching for subagents.
