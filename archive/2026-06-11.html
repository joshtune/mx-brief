Google's Agents CLI: The CLI + Skills Combination to Ship AI Agents EASILY

2.0K

Build and ship AI agents using Google's open-source Agents CLI plus skills.

Cole demos the exact CLI-as-capability + skills-as-instructions pattern you can copy into mx-workflow so your coding agent drives an entire build-eval-deploy pipeline from natural language.

details

What it is: A live build using Google's open-source Agents CLI (built on Google's ADK) where the coding assistant — not you — drives scaffolding, eval, prompt optimization, and deployment end-to-end via natural language.

What he's doing differently now:

  • He's stopped making line-by-line "build an agent in LangChain" videos — tooling got good enough that the agent itself is no longer the substance.
  • The new unit of work is the coding assistant orchestrating a CLI, not you reading framework docs. He explicitly says in 2026 you "don't have to spend a single second in the documentation" because the docs are baked into a skill.
  • Single command installs the CLI + skills; from there everything is natural-language driven.

The core pattern (the actual takeaway):

  • CLI = capability — the runnable commands (scaffold project, evaluate agent, run single prompt against agent, optimize prompts from eval data). Note: there's built-in self-iteration — it tunes prompts against your eval set.
  • Skills = instructions — each CLI stage ships with a matching skill telling the coding agent *how* and *when* to use that command. One skill bundles the full Google ADK documentation so the agent writes correct ADK code without ever opening docs.
  • Every lifecycle stage (scaffold → eval → optimize → deploy → production observability) has a paired CLI command + skill, so the agent runs the whole pipeline from your spec alone.
  • His differentiator claim: most agent frameworks ship skills, but Google's is the only one taking it through deployment *and* production observability.

Production story (from description): deployed agent gets its own identity and a locked-down sandbox to run the code it generates. Disclosed: he's partnering with Google on this video.

Tools & links:

  • Google Agents CLI / ADK — open-source agent framework + CLI; install pulls the CLI and skills (exact repo link is in the video description — transcript cuts off before naming the GitHub URL).
  • Pydantic AI — framework he also builds agents with, mentioned as comparison.
  • LangChain — referenced as the old line-by-line way he started with.
  • Cole's Archon — his own agent orchestration / harness tooling (channel context).

Why it matters for you: This is the blueprint for mx-workflow — pair each pipeline stage you have a command for with a skill that injects the docs/instructions, so your coding agent drives scrape→analyze→generate→publish end-to-end; steal his eval+prompt-optimization-from-eval-data loop to make stages self-tuning.

Why Everyone Is Freaking Out About Mythos

22.7K

Anthropic's new Fable 5 model, hype vs. reality.

Fable 5 is pitched as a set-and-forget model for huge, grindy coding jobs — the kind of long-running refactors and migrations that eat your web app maintenance time.

details

What it is: Anthropic's new Fable 5 — first publicly-released model from their "Mythos" tier, sitting a step above the Opus class.

How it works:

  • Claimed state-of-the-art on nearly every benchmark; lead grows the longer/more complex the task.
  • Pitched for "point it at huge grindy work and let it run" — overnight, multi-hour autonomous jobs.
  • Marquee example: Stripe ran a codebase-wide migration on a 50M-line Ruby codebase in a day — work that allegedly took a team 2+ months by hand.
  • Token-hungry: burns through a lot of tokens on long tasks.

Pricing & access (the catch):

  • $10 / million input tokens, $50 / million output — roughly 2x the price of Opus.
  • Free on Pro/Max/Team plans only through June 22, 2026. On June 23 it's pulled from plans and shifts to usage credits. Anthropic says it aims to restore it to subscriptions "when capacity allows."

Mythos vs. Fable — the misinformation cleanup:

  • What shipped publicly is Fable 5, NOT Mythos 5.
  • Mythos 5 = same underlying brain, but with safety guardrails *lifted* in certain areas; it's locked to "Project Glass Wing" partners (cyber defenders, critical infra, gov, vetted researchers).
  • Fable 5 is the safety-capped ("lobotomized") version of the same model. Anyone claiming the full frontier model is in your Claude app is selling hype.
  • Mythos Preview (April 2026) was the first Mythos-class model, given only to Glass Wing partners.

Third-party validation:

  • Dan Shipper (Every) tested it ~a week across coding, writing, marketing, editing — said it "broke their benchmarks."
  • Scored 91/100 on their senior-engineer benchmark vs. previous highs of 63 (Opus 4.8) and 62 (GPT 5.5). Called it a "one-shot wonder" you can set-and-forget for hours.

Tools & links:

  • FutureTools — Matt's AI tools/news directory
  • Dan Shipper / Every — source of the benchmark writeup referenced

Why it matters for you: If the benchmarks hold, Fable 5 is built exactly for the unglamorous web-app work — big migrations, framework upgrades, sweeping refactors — but the June 23 paywall flip and 2x-Opus pricing mean you'd want to front-load those jobs before access tightens.

Lloyd Blankfein's Retirement Portfolio Got Him Roasted Live

3.7K

Ex-Goldman CEO day-trades his billions; advisor roasts him.

A masterclass in what NOT to do with serious wealth — straight from the guy who ran Goldman Sachs getting publicly schooled on risk-adjusted returns.

details

What it is: A clip where wealth manager Barry Ritholtz roasts retired Goldman Sachs CEO Lloyd Blankfein for actively day-trading the bulk of his net worth.

The featured individual — Lloyd Blankfein:

  • Former CEO of Goldman Sachs (one of the most powerful jobs in finance)
  • Now retired, and self-admittedly addicted to day trading
  • Says he's *always* grabbing his phone to check stocks — got so anxious about a 2-hour podcast that he pre-placed all his trade orders in advance
  • Claims roughly 70% of his net worth (~a couple of billion dollars) is actively traded
  • Says he's "doing good" on returns
  • Post-podcast routine: market's closed, nothing else to do, so he walks 2 miles home

The roast (Barry Ritholtz's take):

  • Calls actively trading 70% of net worth "the biggest risk-adjusted mistake of your career"
  • His prescription: that 70% should sit in municipal (MUN) bonds paying a large tax-free yield
  • Carve-out: keep a few million dollars to actively trade for fun — "knock yourself out" — but don't gamble the core
  • The kicker: "the schmuck that used to run Goldman Sachs should know better"
  • Joked he's now uninvited from Shabbat dinner for the burn

How they (would) make money — the actual lesson:

  • For large, already-won wealth, the move is capital preservation + tax-efficient yield, not active trading
  • Municipal bonds: interest is typically federal- (and often state-) tax-free, so the effective yield on a high earner's money is outsized
  • Risk-adjusted return > raw return: minimizing downside on billions beats chasing alpha you don't need

Why it matters for you: A blunt reminder that even elite operators fall for active-trading dopamine — and that the boring, tax-optimized allocation is usually the smarter play once you've already made your money.
