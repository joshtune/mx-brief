Should you use a VPN in 2026?

61.1K

Zero AI or home-lab content here — it's a NordVPN-sponsored privacy explainer, so skim only if you want a clean refresher on what VPNs actually hide post-HTTPS.

details

What it is: A sponsored (NordVPN) myth-busting explainer on whether personal VPNs still matter in 2026.

How it works:

  • Distinguishes personal VPNs (NordVPN) from corporate VPNs — only the former is in scope.
  • A VPN forms an encrypted tunnel to a VPN server, so the internet sees the provider's network, not yours — it changes the network you appear to be on.
  • Tackles the big anti-VPN argument: HTTPS (TLS) already encrypts traffic, so the payload is hidden either way.
  • The catch: HTTPS hides content but not which sites you visit or how often — your ISP and on-path attackers can still profile you.
  • Live demo: Kali Linux + Wireshark sniffing an Ubuntu box shows `academy.networkchuck.com` plainly visible in DNS packets.
  • Teases the counter-argument — DNS over HTTPS (DoH) — to encrypt that lookup, referencing a David Bombal video (transcript cuts off mid-test).

Tools & links:

  • NordVPN — sponsor; personal VPN being reviewed
  • Kali Linux + Wireshark — packet sniffing lab used in the demo
  • DNS over HTTPS (DoH) — encrypts DNS queries that a VPN would otherwise hide

Week 24 · June 8–12 (v2.1.166 → v2.1.176)

Move sessions with /cd, nested sub-agents, safe mode.

Three workflow-changing features — relocate a session without losing cache, let sub-agents fan out their own trees, and a one-flag clean boot to debug broken config.

details

This week shipped 3 headline features. Deep dive on each:

1. Move a session with `/cd` (v2.1.169)

  • Moves your current session to a different working directory *without rebuilding the prompt cache*
  • The new directory's `CLAUDE.md` is appended as a message instead of replacing the system prompt
  • Session relocates to the new directory's project storage, so `--resume` / `--continue` find it there
  • Prompts you to trust the directory if you haven't worked in it before
  • Example — hop into another project without restarting:

```text

> /cd ../other-project

```

  • Commands reference

2. Sub-agents can spawn sub-agents (v2.1.172)

  • Sub-agents can now spawn their *own* sub-agents; the subagent panel shows the full tree, each row carrying a descendant count and a path back to `main`
  • Background sub-agents capped at 5 levels deep to prevent runaway concurrent trees; foreground chains can go any depth and are self-limiting
  • Example — watch the nested tree as work fans out:

```text

> /agents

```

  • Spawn nested subagents

3. Troubleshoot with safe mode (v2.1.169)

  • `claude --safe-mode` (or set `CLAUDE_CODE_SAFE_MODE`) launches with ALL customizations disabled: `CLAUDE.md`, skills, plugins, hooks, MCP servers, custom commands/agents
  • Auth, model selection, built-in tools, and permissions still work — so if a bug vanishes in safe mode, one of those disabled surfaces is the cause
  • Example — isolate a broken config:

```bash

claude --safe-mode

```

  • Test against a clean configuration

Other wins:

  • `fallbackModel` configures up to 3 fallback models tried in order; `--fallback-model` now applies to interactive sessions
  • Session titles generated in your conversation's language (pin with the `language` setting)
  • `claude agents --json` adds `--all`, plus new `id` and `state` fields
  • Search bar added to `/plugin` marketplace browsing
  • New `disableBundledSkills` setting / `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` to hide bundled skills, workflows, built-in commands from the model
  • Deny rules accept a glob in the tool-name position (`"*"` denies all tools); unknown tool names now warn at startup
  • Cross-session messaging hardened: `SendMessage`-relayed messages no longer carry user authority, and auto mode blocks them
  • Bedrock reads AWS region from `~/.aws` when `AWS_REGION` is unset; `/status` shows the source
  • New `enforceAvailableModels` managed setting constrains the Default model too
  • Claude in Chrome batches browser-tool loads into one call
  • `claude update` announces the target version before downloading
  • New `footerLinksRegexes` setting for regex-matched footer link badges

Breaking changes:

  • None — all features are opt-in flags/commands. Note `/cd` changes where `--resume`/`--continue` locate the session (it follows the new directory's project storage).
