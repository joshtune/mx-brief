This Local LLM Looked Smart Until I Saw What It Made Up

49.2K

New benchmark catches local LLMs hallucinating on your code.

Skip the hardware deep-dive — this one's about a tool to test if local models actually read your files, run on whatever Mac you've got.

details

What it is: Alex open-sources "Code Needle," a benchmark that tests whether local LLMs actually read your code or hallucinate from training data.

How it works:

  • Drops an entire source file into the model's context
  • Asks model to reproduce the first 20 lines of a specific function verbatim
  • Samples functions at varying file depths (line 200, 2000, 8000) — tests recall at depth, not just top
  • Configurable K (number of functions tested) and glob patterns for file selection
  • Deterministic line-level diff grading — no LLM-as-judge
  • Two metrics, not one: `matched` (expected lines reproduced in order) vs `hallucinated` (lines the model invented)
  • A 20/20 score with 65 hallucinations ≠ 13/20 with 1 hallucination

Hardware context (light — this video is mostly about the tool):

  • Tested on M3 Max running LM Studio
  • Hit ~78 tokens/sec on the model shown
  • No Mac mini comparison in this one — pure software/benchmark video

Gotchas he found:

  • Reasoning models burn output budget on thinking tokens — needed `suppress_thinking` config
  • LM Studio UI caps Qwen 34B context at 32k, but the CLI lets you go higher (UI is lying)
  • Gemma 4 failed miserably until configured differently
  • Models config supports base URL, name, API key, temperature, max tokens, suppress_thinking

Tools & links:

  • Code Needle — Alex's open-source benchmark on GitHub (URL not given in transcript snippet, check video description)
  • LM Studio — local model runner he used
  • Inspired by Protoricus (~6k sub channel he credits)
  • Gobii (sponsor) — autonomous AI agent platform

Why it matters for you: Even though this is software-not-hardware, it's the rare Alex video where you don't need to sit through 20 minutes of bench numbers — clone the repo, point it at your own codebase, and find out which local model on your Mac actually reads files vs. bullshits.

claude-code

v2.1.133

Worktree base ref setting, hook effort level, many fixes.

If you use `--worktree` or `EnterWorktree` daily, the default base just changed back to `origin/<default>` — your unpushed commits won't carry over unless you opt in.

details

What changed:

  • New `worktree.baseRef` setting (`fresh` | `head`) controls whether `--worktree`, `EnterWorktree`, and agent-isolation worktrees branch from `origin/<default>` or local `HEAD`
  • Hooks now receive `effort.level` JSON field and `$CLAUDE_EFFORT` env var; Bash tool commands can also read `$CLAUDE_EFFORT`
  • New `sandbox.bwrapPath` and `sandbox.socatPath` managed settings (Linux/WSL) for custom binary paths
  • New `parentSettingsBehavior` admin key (`'first-wins' | 'merge'`) for SDK `managedSettings` policy merging
  • Improved focus mode behavior
  • Memory usage improvements: warm-spare background workers released under pressure
  • `claude --help` now lists `--remote-control`

Bug fixes worth knowing:

  • Parallel sessions no longer dead-end at 401 after refresh-token race
  • `/effort` in one session no longer changes other concurrent sessions' effort level
  • Subagents now properly discover project/user/plugin skills via the Skill tool
  • Remote Control stop/interrupt from claude.ai now fully cancels CLI sessions like local Esc
  • Esc during compaction no longer shows spurious error notification
  • Read/Write/Edit on mapped network drives via `--add-dir` now works
  • `Edit`/`Write` allow rules scoped to drive root (`C:\`) or POSIX `/` now match correctly
  • `HTTP(S)_PROXY`/`NO_PROXY`/mTLS now respected through full MCP OAuth flow
  • Unhandled `ECOMPROMISED` rejection on history/session-log file lock issues fixed

Breaking changes:

  • `EnterWorktree` default base reverts to `origin/<default>` (was local `HEAD` since 2.1.128). If you rely on unpushed commits flowing into new worktrees, set `worktree.baseRef: "head"`

Links:

  • Release notes

Why it matters for you: Subagent skill discovery and the parallel-session 401 fix are quiet but huge for daily Claude Code use — and the worktree default flip will silently change your branching behavior if you don't set `worktree.baseRef`.
