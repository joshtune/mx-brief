v2.1.132

Bug-fix release: paste, resume, MCP, and terminal fixes.

Several daily-driver annoyances are gone — paste-with-slash, `--resume` crashes, MCP silent failures, and statusline token miscounts.

details

What changed:

  • New `CLAUDE_CODE_SESSION_ID` env var exposed to Bash subprocesses (matches the hooks `session_id`)
  • New `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` to keep conversation in native terminal scrollback instead of fullscreen
  • "Pasting…" footer hint while Ctrl+V image paste is read from clipboard
  • Graceful shutdown on external SIGINT (IDE stop button, `kill -INT`) — terminal restored, `--resume` hint printed
  • `--resume` no longer fails with `no low surrogate in string` when emoji truncation corrupts a session; old sessions sanitized on load
  • `--permission-mode` flag now respected when resuming plan-mode sessions with `-p --continue`/`--resume`; plan mode re-applies after `ExitPlanMode`
  • Fullscreen no longer blanks after laptop sleep/wake or Ctrl+Z/`fg`
  • Pasting text starting with `/` no longer silently swallowed or triggers unknown-command
  • `/usage` Ctrl+S no longer hangs when copying screenshot on Linux/X11
  • `/effort` picker now honors `CLAUDE_CODE_EFFORT_LEVEL`
  • Statusline `context_window` now shows current context usage, not cumulative session
  • Slash command autocomplete now scales with terminal height (was capped at 3–5)
  • Alt+T (thinking toggle) now works on macOS terminals without "Option as Meta"
  • MCP: stdio servers writing non-protocol data to stdout no longer cause unbounded memory growth (10GB+ RSS)
  • MCP: servers that connect but fail `tools/list` retry once and show "connected · tools fetch failed" in `/mcp` instead of silent 0 tools
  • Cursor/VS Code 1.92–1.104 mouse wheel scrolling speed fixed; JetBrains 2025.2 terminal scroll quirks fixed
  • Cursor handling fixes for Indic conjuncts, ZWJ emoji, and NFD-decomposed accented characters in vim operators
  • Bracketed paste no longer dumps stray escape sequences when focus/mouse events interleave
  • Windows: dead keyboard input after re-opening background session from `claude agents` fixed; `/terminal-setup` no longer shows wrong Shift+Enter error in Windows Terminal
  • `/status` now shows correct default model

Breaking changes:

  • None

Why it matters for you: As a daily Claude Code user, the `--resume` emoji-corruption fix, accurate statusline token count, and MCP silent-failure surfacing remove three classes of "why is this broken?" friction — and `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` is worth trying if you miss having the conversation in your terminal's scrollback.
