This is exactly what you're after — Chuck runs a live home-lab experiment hiring multiple AI agents as a staffed department, which is the clearest look yet at how he's restructuring his own work around AI.

What it is:

  • Paperclip is an open-source "meta harness" for orchestrating teams of AI coding agents as if they were employees — with managers, assigned tasks, shared goals, budgets, and human oversight.

How it works:

  • Any existing harness (Claude Code, Codex, Hermes, OpenClaw) can be brought into Paperclip — it doesn't replace your tools, it manages them.
  • Agents are organized into a company org chart: a CTO, engineers reporting to them, and a CEO role at the top.
  • Agents communicate with each other only through assigned tasks (not freeform chat), and hold daily "stand-ups" with each other.
  • Chuck's build-out for his home lab / studio:
  • Ron — CTO (Hermes agent)
  • Fred — network engineer (Hermes agent, reports to Ron)
  • George — storage engineer (Hermes agent, reports to Ron)
  • CEO role — running Claude Code
  • Security engineer — running Codex
  • Help desk engineer — running a local model
  • Hermes agents are described as pre-trained "employees" that live on their own VMs and come with skills baked in, so they're closer to plug-and-play hires than agents you have to configure from scratch.
  • Deployment options: run it locally (Mac/Linux/WSL2) to try it fast, or put it on a dedicated server/VM (Proxmox, VPS) for a persistent setup — Chuck does the latter.
  • Real test case: his studio's toilet flush keeps disconnecting everyone from the NAS, and he assigns the agent "IT department" to diagnose and fix it live.
