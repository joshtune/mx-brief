Inline AI image editing: select region, prompt, done

Skip it unless you need quick asset tweaks (thumbnails, OG images, hero shots) for your web apps; the video has no dev-relevant content beyond a 60-second demo.

What it is: A short demo of "CreAI 3" (name as transcribed, likely a mis-transcription of Krea AI), an image editor where you select a region and prompt the edit inline.

How it works:

  • Upload an image (Matt uses a YouTube thumbnail)
  • Highlight a region and type a prompt, e.g. "change this to the Google logo"
  • It returns three variations in a few seconds
  • Text edits keep the original font, with only the words changed
  • Multiple regional edits can be queued and submitted in one go: logo to wolf, shirt pink, irises red
