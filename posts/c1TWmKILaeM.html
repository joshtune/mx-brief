Huge ChatGPT Update You Need to See!

Nate Herk | AI Automation · 2026-07-21 · 19,279 views  ·  Watch on YouTube →
ChatGPT becomes a work OS with Chat, Codex, and Work.

OpenAI just merged Chat, Codex, and a new long-running agent into one connected desktop app that can actually execute multi-app workflows — worth knowing before you architect anything on top of it.

What it is: A promo/overview of OpenAI's new unified ChatGPT desktop app that bundles Chat, Codex, and a new agent called "Work" into a single connected "AI operating system."

How it works:

  • Three surfaces in one app: Chat (ask questions), Codex (developer tasks/coding), and ChatGPT Work (a new agent that takes on long-running projects and connects to apps you already use).
  • Work is the headline: it executes multi-step, long-running tasks rather than just answering — the agentic layer.
  • Ships to web and mobile too, so workflows stay in sync across devices.
  • Includes a cloud browser with plugins for 100+ apps; when no native plugin exists, computer use drives the app directly (screen/click automation fallback).
  • Nate's demo — an "AI chief of staff": a 6:00 AM scheduled workflow that reviews his ClickUp tasks, project ideas, team chats, and calendar, then hands him a daily game plan (what needs attention, what's blocked, what can wait, where to focus).

Availability (from description):

  • ChatGPT Work: live today on web + mobile for Pro, Enterprise, Edu; Plus and Business rolling out over the following days.
  • Desktop app: Chat, Work, and Codex available on every plan including Free, globally.

Tools & links:

  • ChatGPT desktop app — the unified Chat + Codex + Work client
  • ChatGPT Codex — developer/coding agent surface
  • ClickUp — task manager Nate wires into his morning workflow

Caveat: This is a thin announcement/hype video — no repo, no build walkthrough, no actual workflow config shown. The "AI chief of staff" is described, not demonstrated step-by-step.

Why it matters for you: If ChatGPT Work + computer use can reliably chain across 100+ apps, it's a direct competitor to the n8n/agent-builder workflows Nate usually teaches — worth evaluating as a build platform, but wait for a real hands-on before betting on it.
