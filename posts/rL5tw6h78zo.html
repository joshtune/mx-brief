I Tested the Viral Reverse Engineer Anything Skill. What You Need to Know.

Nate Herk | AI Automation · 2026-10-13 · 73,842 views  ·  Watch on YouTube →
Reverse-engineering existing outputs beats prompting from scratch

Nate shows the exact method behind his Instagram-editing skill, a motion-design skill, and a Loom clone, and the lesson is to give the agent the finished thing as its spec instead of describing it.

What it is: Nate tests the viral "reverse engineer anything" GitHub repo (REA), which lets agents study an existing app or feature and rebuild it. His take: it's impressive but not new, because he's been using the same trick to build skills for a long time.

How it works:

  • The repo's pitch: point agents at a feature you like in an existing app, and they work out how it functions and recreate it. Matthew Bourbon's "software is done" quip is what made it blow up.
  • Nate's thesis: AI isn't creative, but given a clear vision it executes well. A generic goal gets a generic result, so the existing output becomes the PRD.
  • Instagram Reels skill:
  • He had the agent watch about 30 of his best-performing, human-edited Reels.
  • The agent analyzed them frame by frame and built a skill that reproduces the style: B-roll, font colors, shimmers, animations.
  • The AI-edited result looks nearly identical to his.
  • Motion-design skill:
  • He downloaded a Jordan Watkins motion edit and gave it to Opus.
  • The prompt: analyze it frame by frame, work out how and why it works, build a skill around it, and prove it by editing a similar video.
  • The original still wins on motion and sound design, but Opus couldn't have invented that design from a text prompt.
  • Loom clone:
  • He pointed the REA repo at Loom to rebuild the recording bubbles and countdown.
  • The demo is a working recorder, though his face cam conflicted with the screen recording.
  • He also says he's built games, tools and software this way, and has done landing pages with borrowed elements and animations (he cites a Glido example).
  • The rule he preaches: reverse-engineer the output. For a Friday report skill, feed it five good Friday reports. Then communicate intent specifically.
