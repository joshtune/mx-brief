Opus 5.5 vs Sonnet 5.5: which to use when

Opus costs about 2x Sonnet, and this tells you which tasks justify paying it. Spoiler: vague, open-ended goals, not well-specified ones.

What it is: A three-task head-to-head of Opus 5.5 against Sonnet 5.5. Opus costs roughly double, so the question is whether it delivers double the quality.

How it works:

  • Test 1, landing page for Perk Form: Sonnet ran 28 min, Opus ran 52 min. Opus cost about 2x. Nate says Opus's output is not 2x better, so this is a Sonnet win on value.
  • Test 2, vague prompt: "Create a research-backed 90-day action plan for getting How They AI to 1,000 subscribers." Sonnet's plan was passable but not very helpful. Opus produced a specific write-up with concrete tasks. Opus wins.
  • Test 3, YouTube resource guide from a video link, using a skill: The skill defines what "good" looks like. Outputs were very similar. Sonnet was about 2x faster and $1.40 cheaper. Sonnet wins.
  • Takeaway:
  • Use Sonnet when you know exactly what you want and can spell it out.
  • Use Opus when the goal is open-ended or vague and needs creativity.
