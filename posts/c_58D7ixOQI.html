M5 Ultra… Apple Wasn’t Messing Around

Alex Ziskind · 2026-09-22 · 392,729 views  ·  Watch on YouTube →
M5 Ultra Mac Studio benchmarked against M3 Ultra for local AI/dev work.

The machine and price you care about: M5 Ultra Mac Studio as tested (80-core GPU, 256GB RAM, 8TB storage) runs $14,299 — way past Mac mini territory, and this video tells you what that buys.

What it is: Hands-on benchmark of Apple's new M5 Ultra Mac Studio vs. the previous M3 Ultra, focused on local LLM and dev workloads.

The machine & price:

  • Base M5 Ultra Mac Studio starts at $5,499
  • As tested: 80-core GPU, 256GB unified memory, 8TB storage — $14,299
  • 512GB memory config arriving next month
  • For comparison, a Mac mini tops out far cheaper and with far less memory/GPU — this is a different class of machine, built for running large local models, not general dev work

Key specs vs M3 Ultra:

  • Memory bandwidth: 1.2 TB/s
  • 36 CPU cores (24 performance + 12 "super" cores, no efficiency cores)
  • Every GPU core now has a dedicated neural accelerator for matrix multiplication (new in M5 gen)

Local LLM performance (the numbers that matter for you):

  • Prompt processing (compute-bound, scales with GPU cores) and token generation (memory-bandwidth-bound) both improved substantially over M3 Ultra
  • Storage: ~14,888 MB/s read, ~20,000 MB/s write vs. M3 Ultra's 6,500 MB/s read — over 2x faster, which matters when loading large (100GB+) local models off disk
  • Tested with identical Llama.cpp and MLX builds on both machines for a fair comparison

Verdict on value:

  • Alex explicitly says if you're buying this just for developer tasks (compiling, scripting), it's overkill — the CPU/compile gains are nice but not $14K nice
  • The real justification is local AI: bigger models, faster load times, faster inference — that's the only case where this price tag makes sense over a Mac mini

Why it matters for you: If you're weighing a Mac mini against a high-end Studio for local AI, this is your data point — the M5 Ultra costs ~3-9x a Mac mini depending on config, and that premium buys you memory capacity and bandwidth for running much larger models locally, not raw dev productivity.
