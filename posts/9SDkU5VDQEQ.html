Chuck installs Omarchy, DHH's AI-first Arch distro.

Chuck is rebuilding his daily driver around an OS that treats AI tooling and keyboard-only flow as first-class, which is exactly the kind of workstation change that shows up in his lab and his workflow later.

What it is: Chuck installs Omarchy — DHH's opinionated Arch Linux distro — on a spare gaming desktop in under two minutes and pitches it as the first Linux desktop he can *use* without *managing*.

The pitch (DHH's framing, via Chuck):

  • AI-first OS — Chuck flags this as the headline feature and the thing he "cannot wait to show"; the ThreatLocker sponsor read is explicitly about locking down which AI tools are allowed to run in your environment
  • Sub-60-second install — Chuck's actual run clocked 1:47 from BIOS boot; the ISO does the Arch setup you'd normally hand-roll
  • No mouse, ever — keyboard-driven by design, which Chuck says he's "kinda here for"
  • Endlessly customizable — ricing culture, but with sane defaults out of the box
  • Gaming-friendly — one of the four stated goals
  • Target user, per DHH: "anyone who either already loves their computer or is interested in loving their computer"

Why Arch is the base (Chuck's explainer, delivered during the install timer):

  • One of the "big five" from-scratch distros alongside Slackware, Fedora/Red Hat, Gentoo, and Debian — everything else (Ubuntu, Kali) is downstream
  • Rolling releases instead of fixed point releases — always cutting edge
  • Minimal to the point of hostility: root prompt, `pacman`, no GUI, no sound, no fonts, no sudo. "An empty canvas."
  • The "I run Arch, btw" meme exists because *maintaining* it was the flex — Omarchy's whole bet is deleting that maintenance tax while keeping the ownership

Hardware (the home-lab-envy section):

  • DHH's daily driver: Dell XPS 16
  • Also runs: Framework Laptop 13 Pro
  • Chuck's test box: an old gaming desktop lying around — his point being Omarchy revives dead hardware, so this is a cheap thing to try on a spare mini or tower

Tools & links:

  • Omarchy — DHH's Arch-based, Hyprland-flavored, AI-first distro; latest release codenamed "Quattro"
  • Arch Linux — the base; `pacman` is the package manager
  • ThreatLocker — sponsor; application allowlisting, pitched here for gating AI tools
  • Framework / Dell XPS 16 — the two machines named as good Omarchy targets

Why it matters for you: This is Chuck changing his own workstation, not just reviewing one — an AI-first, keyboard-only OS on throwaway hardware is a low-cost lab experiment you could clone this weekend, and it's the substrate his future AI-workflow videos will run on.
