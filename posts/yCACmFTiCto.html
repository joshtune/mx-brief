What it is: A no-code-required build where Claude Code becomes the orchestration layer over Higgsfield's AI image/video models — you set up a project with brand context, reusable skills, and guideline files, then ask for marketing assets in plain English.

The setup, in three steps:

  • 1. The project — Get Claude Code installed, then scaffold the files/folders that hold your business context. This is the part that does the actual work; everything downstream reads from it.
  • 2. Connect Higgsfield — Wire Higgsfield into Claude as an MCP server via the referral link below. One subscription, many models.
  • 3. Generate assets — Ask for logos, product shots, ads. Nate's demo brand is "Perk Form," a fake coffee-protein energy drink; every asset shown (logos in light/dark/text variants, individual + studio product shots for vanilla latte, salted caramel, bold mocha) came out of Claude + Higgsfield.

The project files that matter:

  • Brand guidelines file — Color scheme, logo system, typography, brand mission. Claude reads this on every generation so output stays on-brand instead of drifting.
  • Skills — Nate's framing: "basically just like recipes, workflows." An Instagram carousel skill produces carousels the same way every time; a UGC ad skill does the same for ads. Skills are what make this scale past one-off prompts.
  • The AI Monetization Readiness Assessment — His three Ps: Pain (what problem), Person (who specifically feels it), Promise (how your brand solves it). He's blunt that without this the project has nothing to condition on and you get generic AI slop. This doc feeds the whole system.

  • *Marketing Studio:* Template-driven turn of your assets into ad creatives and sizzle reels, models running underneath
