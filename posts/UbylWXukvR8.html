11 Tiny Coding Agent Fixes With A Stupid Amount Of Payoff

Cole Medin · 2026-09-01 · 48,398 views  ·  Watch on YouTube →
Eleven small workflow tweaks that make coding agents reliable.

Cole's core thesis here — agent instruction files rot and you need an automated drift audit — is a direct, cheap upgrade you can ship into mx-workflow as a new command.

What it is: A rapid-fire tips video (1–2 minutes per tip, 11 total) on making coding agents more reliable without rebuilding your workflow. Agent-agnostic — he demos in Claude Code but says everything applies to Cursor, Codex, whatever. Transcript captured here covers tips 1–2 in full; the rest are teased but cut off.

What he's doing different:

  • Framing shift: stop treating rules files as documentation. His #1 job when planning work with an agent is *reducing the number of assumptions the agent can make* — that's the metric he optimizes for, not clarity or brevity.
  • He accepts staleness as the cost of specificity. Human docs stay vague on purpose so they age well. Agent rules must be brittle-specific (exact paths, exact commands, exact numbers), which *guarantees* rot — so he pairs specificity with a maintenance mechanism instead of avoiding it.
  • He automated the maintenance. "Rule drift" is his term for rules referencing deleted files, renamed folders, or replaced databases. He built a `rules-check-drift` skill that makes the agent audit its own rules against the actual codebase.

Tip 1 — Write for the agent, not the human:

  • Bad (human-style): "keep database code organized sensibly"
  • Good (agent-style): "all SQL has to live in the `database/` folder"
  • Be explicit about file paths, numeric thresholds, and the literal commands you want run
  • The conscious effort is the point — ask "how do I make this specific?" not "is this good advice?"

Tip 2 — Your instruction files rot:

  • Cites a study (linked in his video description): 1 in 4 repos with an AI rules layer have stale rules
  • Stale rules are worse than no rules — the agent burns context reconciling why reality differs from its instructions
  • Fix: run a drift audit skill periodically; the agent diffs rules against the codebase and reports discrepancies
