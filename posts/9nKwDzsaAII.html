I Gave Two AI Supercomputers a Real Job

Alex Ziskind · 2026-10-07 · 133,349 views  ·  Watch on YouTube →
DGX Station vs 8x RTX Pro 6000 rig, running Turnstone

You get the two machines (NVIDIA DGX Station and a Comino Grando with 8x RTX Pro 6000), but the part of the video we have contains no prices and no Mac mini comparison.

What it is: Alex and guest Wendell run two very large local-AI boxes, the NVIDIA DGX Station and the Comino Grando, and use an agent-orchestration tool called Turnstone as the real workload.

How it works:

  • Machine 1: NVIDIA DGX Station, run headless and managed remotely through its management port (power, sensors, logs, BIOS, KVM).
  • Machine 2: Comino Grando, a rig with 8x RTX Pro 6000 GPUs that draws power through four plugs. Alex says the Grando and DGX Station are "eight RTX Pro 6000s versus DGX station" in a head-to-head.
  • Power and noise: About 6,000 W of heat combined, loud enough that the door stays closed. The DGX Station idles at about 319 W.
  • Workload: Turnstone is meant to run Claude Code sessions across a fleet of machines (Alex already uses multiple DGX Sparks) and have the tool pick where each session runs.
  • Turnstone features: You point it at a model by base URL, including local models, and can load several models and route request types to different ones. It ships personas (engineer, executive, manager, orchestrator, researcher, scribe, writer), supports MCP servers, and keeps memories.
  • Mac angle: A Mac appears only as a setup target, when he tells the agent to set Turnstone up "on this Mac." It is not benchmarked.
  • Sponsor segment: A mid-roll ad for ChatLLM by Abacus AI, starting at $10 a month. Skip it.

Tools & links:

  • ChatLLM by Abacus AI — sponsor, multi-model chat subscription
  • Abacus AI DeepAgent — sponsor, agent builder
