Apple’s Hidden AI Model… The Speed they never showed

Alex Ziskind · 2026-07-23 · 26,494 views  ·  Watch on YouTube →
macOS 27's hidden local AI runs on the Neural Engine.

The $10K Mac Studio gives you zero speed advantage over a $600-tier Mac mini for Apple's built-in AI — save the money.

What it is: Alex benchmarks "FM," Apple's hidden on-device Foundation Model shipped inside macOS 27, on a Mac mini vs. a maxed Mac Studio.

The hardware showdown (what you actually care about):

  • Mac mini (M4 Pro): 273 GB/s memory bandwidth — the cheap machine
  • Mac Studio (M3 Ultra): 819 GB/s memory bandwidth — the ~$10,000 machine
  • Result: Nearly identical speeds. Prompt processing ~1,142, decode ~56 on *both*. The 3x bandwidth advantage buys you nothing.

Why they tie (the clever part):

  • Alex stress-tested each engine to find where FM actually runs
  • Hammer the Neural Engine (ANE) → FM's *decode* slowed, prompt processing untouched
  • Hammer the GPU → FM's *prompt processing* slowed, decode untouched
  • Conclusion: decode runs on the ANE, prompt processing on the GPU. The ANE is the same across both chips, so the Studio's massive GPU/bandwidth edge is wasted.

Cost takeaway for you:

  • For Apple's built-in FM tool, a Mac mini = maxed Mac Studio in speed at a fraction of the price
  • Do NOT buy up the Mac lineup expecting faster local AI *from Apple's own model* — the Neural Engine caps the gain
  • (Note: this applies to Apple's FM specifically, not third-party LLMs via GPU/MLX, where bandwidth still matters)
