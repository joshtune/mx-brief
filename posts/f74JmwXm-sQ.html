Sponsored demo of a multi-agent expense tracker

Skip it — this is a Hyperagent ad with no build detail, no code, and nothing that transfers to a web app project.

What it is: A ~90-second sponsored spot for Hyperagent dressed up as a build video — Matt walks through a three-agent expense tracker he "built" on the platform.

How it works:

  • Agent 1 ("Fernando") connects to email, scans for receipts/invoices/subscription confirmations, extracts vendor + amount + date
  • Agent 2 ("Jackson") categorizes each expense (software, gear, travel, subcontractors) and flags likely miscategorizations
  • Agent 3 ("Sander") renders a dashboard, surfaces spend breakdowns, flags forgotten subscriptions, refreshes daily
  • The actual pitch: agents hand off to each other with shared context, so you're not copy-pasting between chat windows or rebuilding prompts
  • Distribution angle — agents are usable by teammates via the Hyperagent app or Slack, and builds are copyable/forkable

Tools & links:

  • Hyperagent — no-code multi-agent builder with Slack integration; sponsor of this video, free credits via Matt's affiliate link
  • FutureTools — Matt's AI tool directory

What's missing: No architecture, no prompts, no code, no discussion of how email auth/OAuth was handled, no accuracy numbers on the extraction, no cost. The one genuinely interesting engineering idea — persistent shared context across an agent handoff chain — gets a single sentence and zero implementation detail.

Why it matters for you: Nothing here helps you build web apps; if the multi-agent handoff pattern interests you, the transferable version is orchestrating subagents with a shared context store in your own stack, and this video won't teach you that.
