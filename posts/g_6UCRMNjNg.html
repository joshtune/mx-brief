GLM 5.2 on a DGX Station, coding in VS Code.

This is the machine at the far end of the local-AI spectrum — 748GB unified memory running a frontier open model for one user — and it's the honest comparison point for what a Mac mini can and can't do.

What it is: Alex runs GLM 5.2 locally on an NVIDIA DGX Station with 748GB of unified memory, driving the VS Code agent, and clocks the token speed.

The machine:

  • NVIDIA DGX Station — 748GB unified memory, the single-user end of the spectrum
  • The model does not fully fit in HBM (high bandwidth memory), so part of it spills to slower memory
  • Even spilling, Alex calls the speed acceptable for agentic coding in VS Code
  • Ballpark: DGX Station class hardware is a five-figure buy (~$70–80k); Alex doesn't quote a price in the clip

How it compares to a Mac mini:

  • Mac mini M4 Pro tops out at 64GB unified memory (~$2,000 configured) — roughly 1/12th the DGX's pool
  • 748GB is what it takes to hold a GLM-5.2-class model near-resident; a mini can only run heavily quantized mid-size models
  • The interesting takeaway isn't "buy a DGX" — it's that even at 748GB you're still spilling out of HBM, which tells you where the real bottleneck is (memory bandwidth, not capacity)
