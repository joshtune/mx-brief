Omnigent: The New Meta-Harness for EVERY Coding Agent - Claude Code, Codex, Pi, More

Cole Medin · 2026-06-15 · 19,362 views  ·  Watch on YouTube →
Databricks' open-source meta-harness orchestrates multiple coding agents.

If you're building mx-workflow, this is the blueprint for the next layer up — orchestrating Claude Code + Codex + others in one session instead of juggling terminals and handoff docs.

What it is: Omnigent (a.k.a. OmniAgent) — an open-source *meta-harness* from Databricks that runs longer AI coding workflows by mixing multiple coding assistants under one orchestration layer.

The core thesis (what Cole is pushing now):

  • The harness matters as much as or more than the model — and with Fable 5 banned, you can't count on better LLMs, so you make the *system around* the LLM stronger.
  • A *harness* = system prompt + tools + skills + workflows + rules packaged to make one agent reliable.
  • A *meta-harness* = the layer above that, orchestrating many agents on one larger task. Cole calls this "peak harness engineering" and the next big thing for AI coding.
  • Classic pattern: Claude Code implements → Codex reviews; route simple tasks to cheaper models (Kimi/Minimax) — lean on each model's strengths and isolate sessions for context/token optimization.

How it works:

  • One session manages all your coding agents — no more bouncing between terminals or writing handoff documents.
  • Connects the popular assistants: Claude Code, Codex, and Pi, across many models.
  • Uses existing CLI credentials — no re-auth; it runs locally on your machine using whatever you're already signed into.
  • Ships with two example orchestrator agents, Polly and Debbie, that hand off between Claude and Codex out of the box.
  • Supports custom agents and orchestrators, shared sessions (collaborate with others — rare for coding agents today), and policies/guardrails + sandboxed execution for production use.
  • Works across devices in the same environment.

Setup:

  • Hand the GitHub repo link to your coding assistant and tell it to set everything up — or run a single install command. Up and running in minutes.

Provenance / why it's credible:

  • Open-sourced by Databricks, driven by their CTO, and dogfooded internally for their everyday engineering.
  • Cole says he's pulling Omnigent's ideas into his own meta-harness tool, Archon.

Tools & links:

  • Omnigent / OmniAgent — Databricks' open-source meta-harness (repo linked in the video description; search `github.com` for the Databricks Omnigent repo — exact URL not stated in transcript).
  • Archon — Cole's own agent-orchestration / meta-harness project, which he's evolving with Omnigent's ideas.
  • Coding assistants referenced: Claude Code, Codex, Pi; models for cheap tasks: Kimi, Minimax.

Why it matters for you: This is exactly the gap mx-workflow could close — instead of a single Claude Code agent, add an orchestration layer that routes implementation vs. review vs. cheap-task work across assistants, with credential reuse and guardrails. Steal the Polly/Debbie orchestrator pattern and the "isolated session per role for token optimization" idea directly.
