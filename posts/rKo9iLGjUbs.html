I Built a FREE App That Runs Your Entire Business

Matt Wolfe · 2026-08-26 · 89,444 views  ·  Watch on YouTube →
Vibe-coding a personal business dashboard with Codex.

It's a concrete, end-to-end walkthrough of scoping and building a multi-tab web dashboard with an AI coding agent — the skeleton-first prompting pattern transfers directly to your own web app builds.

What it is: Matt rebuilds his "Wolf Control Tower" — a single-tab web dashboard aggregating news, newsletters, brand mentions, reminders, audience stats, and site analytics — from scratch using ChatGPT's Codex app, and promises the finished repo as a free download.

The build pattern (the actually useful part):

  • Create a local project in the ChatGPT/Codex app pointed at a folder on disk — not a hosted sandbox
  • Use the strongest model for the initial scaffold (he uses GPT-5.6 "soul high"), then downgrade to a cheaper model for iterative feature tweaks. Model tiering by phase, not by whole project
  • Skeleton first: one prompt that lays out all tabs and rough structure without working functionality, then build each feature in its own follow-up pass. Don't ask for a finished app in prompt one
  • Feature list is enumerated as separate tabs/pages up front — news, reminders, audience tracker, newsletter, task list — giving the agent a clear route/component boundary per feature

Dashboard features he wires up:

  • AI Intel — pulls headlines from every major lab plus TechCrunch/The Verge (RSS-style aggregation)
  • Newsletter tab — the dashboard itself is "subscribed" to AI newsletters, inbox-as-data-source
  • Brand monitoring — a self-hosted Google Alerts for his name, handles, and "Future Tools" mentions
  • Reminders — backed by a companion Chrome extension for save-from-anywhere, with notes and folder organization. This is the interesting architectural bit: browser extension as capture client, dashboard as store
  • Audience tab — social growth across platforms in one view
  • Sites tab — snapshot of site performance

Tools & links:

  • ChatGPT / Codex — the coding agent doing the build; local project mode
  • FutureTools — Matt's AI tool directory
  • Newsletter
  • GitHub repo for the finished dashboard — promised at the end of the video, URL not stated in the transcript

The thesis worth arguing with: Matt's claim is that SaaS is in trouble because bespoke internal tools are now cheap to build. For a web app dev that cuts both ways — it's a real warning about thin-wrapper products, and a real green light for building your own internal tooling instead of paying per-seat for five dashboards.

Why it matters for you: The skeleton-first + model-tiering prompting workflow and the extension-as-capture-client pattern are directly liftable into your own web app projects; the dashboard itself is just the demo.
