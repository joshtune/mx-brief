Astra 6.2 vs Fable 5.2 across 12 real builds

Nate runs both models on identical prompts and reports dollars, tokens and wall-clock time for each, so you can see which model is worth its cost for web design, decks, dashboards and video editing.

What it is: A 12-round head-to-head of GPT 6.2 Astra and Claude Fable 5.2 on real build tasks, scored on output quality, dollar cost, input/output tokens and run time. (The transcript cuts off during round 2, so rounds 3-12 aren't covered here.)

How it works:

  • Test setup: Both models get the exact same goal prompt, both run on high effort, and each works in its own git worktree so they can't interfere with each other.
  • Planned use cases (12): web design, professional slide decks, travel planning, 3D games, financial dashboards and spreadsheets, editing Instagram videos, editing YouTube videos, and a few others.
  • Metrics per test: API-equivalent cost in dollars, input tokens, output tokens, and run time.
  • Blind judging: Nate shows the outputs unlabeled and asks you to guess which model made which before revealing.
  • Round 1, web design (Perk Form):
  • Perk Form is a fake coffee-and-protein brand with existing brand guidelines and assets, which Nate reuses across tests.
  • Site 1 (Astra) is clean and on-brand with a real photo and a dynamic navbar. Its flaws: a hero animation that scrolls away too early, and a flavor-picker image that's cropped out. Nate says the model should have used vision to catch that.
  • Site 2 (Fable) has much more motion: animated text entrance, an orbiting ring around the can, layered text and can, flavor switching in the hero and nav, and a coffee-and-protein swirl. Images fit properly, but it makes you scroll a lot.
  • Stats: Fable ran 56 min and would have cost about $175 on API billing. Astra ran 12 min and cost about $2.50. The token counts were "very, very different."
  • Verdict: Both are good. Nate picks Astra for cleanliness and cost, so Astra leads 1-0.
  • Round 2, slide deck:
  • The prompt: turn a mock survey into a 12-slide "Hercules advisory" presentation. Hercules is another fake brand with guidelines.
  • Astra's deck is on-brand with the logo, charts and light text. It feels professional but simple, and the format gets repetitive, with three near-identical slides in a row.
  • Fable's deck and the verdict are not in the provided transcript.
