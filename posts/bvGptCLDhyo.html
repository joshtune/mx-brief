I Built Another Andrej Karpathy Using Claude

Nate Herk | AI Automation · 2026-10-05 · 58,549 views  ·  Watch on YouTube →
Cloning Karpathy's teaching style into a Claude Code agent

It's a repeatable four-step recipe for crawling an expert's public output, compiling it into a project knowledge base, and wiring it into Claude Code agents, with the exact tools named.

What it is: A Claude Code build that turns Andrej Karpathy's public writing, lectures, and posts into a teaching agent. It copies his reasoning and teaching rules, not his voice.

How it works:

  • Goal: an agent that explains the way Karpathy teaches, not an impression of him. It follows seven rules drawn from his blogs, lectures, and writing.
  • Example rules: build the smallest version first, predict the result before running it, show the broken version, and never hand over code you haven't run.
  • Why bother: stock Claude over-explains and makes things up. Karpathy publicly said Claude Code wouldn't teach him while it wrote code, because it wants to write code more than explain it. This agent is meant to fix that.
  • Four steps, six prompts: he runs six prompts inside Claude Code and shows them on screen to screenshot. The transcript I got cuts off during step one (the crawl), so the compile, agent-build, and wiring steps below are not covered here.
  • Step 1, crawl: a prompt names every source and the tool for each, then spawns one subagent per source so they run in parallel. It writes down what it collected.
  • Sources: blogs, lecture transcripts, GitHub repos, and X posts.
  • YouTube: captions pulled with two free Python packages, YouTube Transcript API and yt-dlp.
  • X: twitterapi.io, a paid API. He pulled essentially every post since 2023 for about $1.
  • Later steps (per his framing): compile the raw material into something Claude can use, talk to it until you understand the topic, then wire that knowledge into your own skills, agents, and workflows.
  • Reuse: the same four steps work for any expert, such as a sales teacher, an author, or a coach you pay for.
  • Context claims (his, unverified): he says Karpathy joined Anthropic's pre-training team in May, after co-founding OpenAI, running Tesla Autopilot vision, and starting Eureka Labs.

Tools & links:

  • Claude Code — runs the whole build, including parallel subagents
  • youtube-transcript-api — free caption pulls for YouTube videos
  • yt-dlp — video and caption downloader, the second YouTube source
  • twitterapi.io — paid X/Twitter API, about $1 for Karpathy's posts since 2023
  • Free AI OS template — his opt-in kit for building an agent operating system, which he says pairs with this setup
  • The six prompts are shown on screen only. The description snippet I have lists no repo for them.

Why it matters for you: The crawl-compile-wire pattern is the useful part. You get a reusable knowledge base inside your project that your own skills and agents can call. The video's sections after the crawl step aren't in the transcript, so watch it for those prompts.
