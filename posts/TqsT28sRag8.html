I Paid Claude $1 vs $1,000 to Build a Video Game

Nate Herk | AI Automation · 2026-11-23 · 36,364 views  ·  Watch on YouTube →
Same game brief, four Claude budgets, compared

Nate shows the headless-Claude-Code build loop he used, with real per-round costs and the failure mode he hit (an agent that decides it's done and stops shipping), so you can copy the setup and skip the mistake.

What it is: A budget-ladder experiment. Nate gave Claude Code $1, $10, $100 and $1,000 to build the same browser-based 3D open-world Miami driving game, then compared what each tier produced. The transcript cuts off partway through the $10 tier, so the $100 and $1,000 results and his final pick aren't covered here.

How it works:

  • The brief: One page, identical for every tier. An original 3D open-world driving game set in Miami with a drivable car, traffic, missions, day/night, beaches and a radio. It had to run in the browser.
  • The harness: Claude Code in headless mode, with no UI and nobody at the keyboard, running in a loop of sessions.
  • Each session builds the game, then opens it in a hidden browser and plays it to find what's broken.
  • That feedback goes into a fresh session, which picks it up and repeats the loop.
  • A dollar cap per tier makes Claude Code cut off when the money runs out.
  • Every round saves a checkpoint, which is how he rolled back after a cap hit mid-edit.
  • Model and team per tier:
  • $1: Haiku 5.5, single agent.
  • $10: Sonnet 5.5.
  • $100: Opus 5.5 with a team of 3 agents.
  • $1,000: Fable 5.2 with a team of 8 agents.
  • $1 tier (Haiku, 'Neon Tide Miami Drive'):
  • Spent $0.98 over 29 rounds and about 2 hours, roughly 3¢ per round.
  • 7 missions (package runs, drift challenges), traffic that obeys red lights, pedestrians, and a bridge to an island.
  • 3 radio stations with all music generated in code, so there are no audio files.
  • It looks rough: buildings and the car are basically boxes. But the logic and physics work, so it's a legit proof of concept.
  • $10 tier (Sonnet, 'Palmetto Drift'):
  • 43 rounds in about 1h45m.
  • 21 missions, cops with a wanted level, rival racers, 3 selectable cars, a pier with a Ferris wheel, and rain that makes roads slippery.
  • 5 radio stations with fake news bulletins and ads between songs.
  • The failure he hit: On the first $10 run, Sonnet declared the game done around round 30. For the next ~90 rounds it opened the game, said it looked good, and changed nothing, burning $4.72 (about half the budget).
  • Fix: He scrapped that run. In the rerun, every round must pick one real focus (driving feel, city look, a new mission) and ship something a player would notice.
  • On the final round the cap hit mid-edit, right after it cleared the main game file. The checkpoint rollback recovered it.

Why it matters for you: It's a copyable pattern for unattended agent loops (headless run, self-playtest, fresh-session feedback, spend cap, checkpoints). The main lesson is to give every loop iteration a mandatory deliverable, or the agent will quietly stop working while still spending your money.
