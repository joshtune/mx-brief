100 Hours Testing Deepseek Harness vs. Claude Code. What You Need to Know.

Nate Herk | AI Automation · 2026-08-23 · 47,655 views  ·  Watch on YouTube →
Hands-on review of DeepSeek's open-source agent harness

If you live in Claude Code, this is the first credible open-source harness where you can rewrite the loop, tools, and UI yourself — Nate walks through the actual setup and what it costs you.

What it is: A week-long, out-of-the-box test of DeepSeek's new open-source agent harness, benchmarked against Claude Code from a working-dev perspective — no third-party plugins, just stock behavior.

The harness distinction (the 60-second version):

  • A *harness* is the agent shell — prompting rules, tool calls, agent loop, UI. A *model* is the engine you drop in.
  • Codex = harness, natively runs GPT-5.6 Soul / GPT-5.6 Luna.
  • Claude Code = harness, natively runs Claude Opus / Claude Fable.
  • DeepSeek Harness = harness, natively runs DeepSeek V4 Flash / Pro — but accepts Opus, GPT, Kimi, Meta, or anything else you point it at.
  • Nate's framing: closed-source harness = a car you can drive and swap the engine on, but can't rearrange. Open-source harness = you can swap the seats, the steering wheel, the way the agent behaves under the hood.
  • Not groundbreaking tech — OpenClaw and Hermes Agent are also agent harnesses. What's new is that this one is fully open and free.

"Everything is a plugin":

  • Not just skills and MCP servers — tools, skills, sessions, sandboxes, storage, loops, and the UI are all plugin surfaces.
  • That's the actual unlock: you can replace the agentic loop itself, which you cannot touch in Claude Code.
  • Nate deliberately ran zero third-party plugins for this test to judge the stock experience.

Setup, exactly how he did it:

  • Handed the GitHub repo link to Codex and said "help me set this up." That was the whole install process.
  • Runs fully local, served on localhost.
  • Settings → Models → drop in an API key. He used an OpenRouter key, which exposes every model OpenRouter carries in the model picker.
  • UI is a standard chatbot layout — projects on the left, session management, nothing to relearn.

The catches:

  • No subscription auth by default. You cannot point it at a Claude or Codex subscription out of the box — it's per-token API billing. Nate has seen plugins claiming to bridge this but hasn't tested them himself.
  • Plugin supply chain risk. Open-source plugins from strangers are arbitrary code on your machine. His rule: have Claude Code or Codex review any plugin before you install it.
  • Output quality still comes down to model + effort level. The harness only carries you so far.
