I Told Claude to "Make it better" 100 Times (It Went Too Far)

Nate Herk | AI Automation · 2026-10-30 · 92,395 views  ·  Watch on YouTube →
Looping 'make it better' 100 times on Claude

If you want to see what Claude Code actually builds when you hand it one forced-change prompt 100 times, with Sonnet 5.5 and Opus 5.5 side by side on a deliberately awful coffee shop site.

What it is: Nate gave Claude Code a deliberately ugly coffee shop website and sent the same "make it better" prompt 100 times in a row, once with Sonnet 5.5 and once with Opus 5.5, both on medium effort.

How it works:

  • The prompt (sent every round): "Look at the site first, then innovate. Think about the user experience and think outside the box. Make one bold change that improves conversions or the look and feel, not a small tweak. Use any tool you have. You must ship a change every time."
  • Why it's so forced: an earlier attempt stalled at about 20-25 rounds with "nothing else can be done." The "you must ship a change every time" line fixes that.
  • Clean room every round: fresh session, no skills, no CLAUDE.md, no plugins, no memory. Each model only has its own knowledge and built-in tools.
  • Review UI: a local host dashboard shows every round, tool calls per round, and total lines of code. It also has a milestone view that flags the big jumps.
  • Thesis: vague goals like "make it prettier" cap out around 80/100. Getting to the high 90s needs a human applying taste or borrowing proven methods. Nate says he has had more success with AI pipelines built on other people's proven approaches than on the model's own originality.

Sonnet 5.5 results (covered in the transcript excerpt):

  • Cost: $29.93 at API billing for the 100 rounds.
  • Assets: 11 images and 2 videos generated in the site.
  • Round 1: the biggest jump. It was the first time the model looked at its own site, and it produced the first AI-generated image (the hero background), the first JavaScript, and the first mobile-ready layout. The result was still plain, with a basic punch card and a boring font.
  • Round 2: first animation, a sticky order bar that stays pinned while you scroll.
  • Round 7: lines of code went from 253 to 419. Menu items now show pictures when you add them.
  • Round 24: 778 lines, with the first AI-generated video as a background and a scroll animation.
  • Takeaway so far: steady improvement through lots of small changes, but still not great.
