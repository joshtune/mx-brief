Make Money With This New AI Agent That Works 24/7

Chris Koerner on The Koerner Office Podcast · 2026-09-04 · 11,340 views  ·  Watch on YouTube →
Grok agent vibe-codes a sellable inbox-lockout app live

Chris builds a sellable Mac app and Chrome extension from one prompt with zero coding, then pivots straight to 'now I need to sell it' — a live template for a low-cost software side hustle.

What it is: A live, on-screen test of whether an agentic AI (Grok's agent, which he calls 'Grockbot') can build a sellable software product in under an hour for someone who can't code.

The idea:

  • Forced time boxing for email. Calendar blocks don't create accountability, so the app enforces it: Gmail and the Mac Mail app are locked for 90–95% of the day.
  • Unlocked window: weekday mornings until 10:00 a.m. Miss it and you don't get another shot until tomorrow. Weekends fully locked.
  • Generalized: the same mechanism blocks any website or app, either fully or outside a defined window. That's the pitch for selling it beyond his own use.
  • Deliverables: a Chrome extension (for gmail.com) plus a native Mac app (for Mail and other apps).

How it's carried out:

  • Install Grok's agent for the first time on camera; no prior experience, not sponsored.
  • Skip the connect-everything onboarding; only grant what the task needs.
  • Treat the agent like an employee (advice from his friend Billy): give it a clear brief, then let it drive.
  • The agent doesn't just write code; it opens Replit, prompts the builder, tests the output, reads the code, fixes bugs, and loops. That test-fix loop is the tedious part of vibe coding, and offloading it is the whole experiment.
  • Result: one prompt produced a working build. Chris's reaction on tape: 'That was one prompt. It just built this for me.'
  • Next step he calls out: selling access, not just using it himself.

Tools & links:

  • Grok agent — agentic layer on xAI's Grok that takes actions in other tools rather than just answering
  • Replit — where the agent actually writes, runs, and tests the code
  • playmakersai.com — his paid community for AI consultants charging $500–$5k/mo (the upsell)
  • TKOPOD.com — newsletter

Reality check:

  • Transcript cuts off mid-setup, so the actual build session and any monetization mechanics aren't in the captured portion.
  • 'Sellable' is asserted, not proven. No pricing, distribution, or customer evidence shown.
  • Locking a native Mac app and a website reliably is harder than a demo suggests; expect edge cases (bypass via other browsers, mobile, etc.).

Why it matters for you: The repeatable side-hustle play here is: pick a personal productivity itch, have an agent build and debug it end to end, then sell access — and you already have the coding chops to harden what Chris can't.
