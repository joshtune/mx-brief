I Tested 9 Ways to Use Claude Code for Free (3 are worth it)

Nate Herk | AI Automation · 2026-11-25 · 28,760 views  ·  Watch on YouTube →
Benchmarking 9 free or cheap Claude Code setups

Nate ran nine harness/model combos through the same five jobs, scored by blind judges, so you can see which free setups are worth your time and which are a waste.

What it is: A blind benchmark of nine harness + model combos for getting a Claude Code-style agentic loop for free or near-free. Paid Claude with Opus 5.5 is the 100% baseline.

How it works:

  • Core idea: Claude Code is a harness. It reads files, runs commands and makes edits, and the model inside does the thinking. You can swap in a cheaper model, or put a different harness around a model like Fable.
  • Why the subscription still wins: You're mostly paying for the model, and a subscription gives far more usage than per-token API pricing. Five small jobs on paid Claude cost $79 at API rates, and a normal build day is far more than five small jobs.
  • The 5 test jobs (same instructions and files for every setup):
  • Build a bakery landing page
  • Fix a spreadsheet with 4 hidden mistakes
  • Summarize a 48-page government PDF into one page
  • Clean up a messy folder of files
  • Write a small Python/code script
  • Scoring:
  • Two blind AI judges, one Claude and one OpenAI, graded outputs without knowing the model or harness.
  • Nate says the Claude judge was *harder* on paid Claude than the OpenAI judge, so he sees no self-preference bias.
  • Everything is scored against the paid Opus 5.5 baseline.
  • Headline result: A completely free setup scored *higher* than paid Claude Code. Three of the nine are "worth it", and Nate still pays for his own subscription.
  • Only result in the available transcript: Claude Code running Haiku 5.5 (real Claude, pay-per-use) cost about $0.03 for all five jobs. It couldn't open the PDF, told Nate so, then wrote the summary from memory with no page numbers.
  • Not tested, and he warns against these:
  • Claude Ultra free for 6 months: a real offer, but only for maintainers of popular open source projects.
  • Promo-code "free year of Claude Pro": shared or resold accounts, against Anthropic's terms, often scams.
  • Plugging your Claude login into third-party apps: against the rules, and Anthropic can suspend accounts without warning.
  • Caveat: The transcript cuts off after the Haiku result. The other eight setups, the three winners and the scores aren't in the material I have, so watch the video for those.
