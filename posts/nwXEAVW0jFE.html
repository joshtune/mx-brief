I Thought 2 TB of RAM Was Overkill… My AI Agents Disagree

Alex Ziskind · 2026-11-05 · 154,548 views  ·  Watch on YouTube →
System RAM, not VRAM, caps how many AI agents run

You get the rig in one line (Threadripper PRO box, two RTX Pro 6000s), and the video never prices it or compares it to a Mac mini, so skip it unless you care about agent RAM limits.

What it is: Alex tests whether system RAM, rather than VRAM, limits how many local AI coding agents one machine can run at once.

The machine (what you asked for):

  • CPU: AMD Threadripper PRO 9975WX
  • Board: ASUS Pro WS WRX90E-SAGE SE
  • GPUs now: 2x NVIDIA RTX Pro 6000, 192 GB VRAM total. It had 4 before; he pulled two for other projects.
  • RAM: 128 GB at baseline, doubled to 256 GB mid-test with nothing else changed
  • Budget GPU swap: one ASUS Radeon AI PRO R9700 with 32 GB VRAM, in place of both RTX cards
  • Mac mini: not mentioned anywhere in the transcript
  • Prices: none stated. The transcript cuts off before the cost comparison, and the gear links are in the description.

How it works:

  • He first assumed RAM was just overflow for when the GPU runs out. He then corrected that: the model sits on the GPU, but the agent lives in system RAM.
  • That means orchestration, tool calls, growing context, and the cache of everything the agent has seen.
  • His first benchmark leaned on the GPU and was muddied by the CPU, so he threw it out.
  • The new benchmark runs a growing number of real coding agents against one model. Between turns, each agent's conversation is parked in system RAM instead of being rebuilt.
  • Results at 128 GB:
  • 8 agents ran fine.
  • 12 was still climbing.
  • At 16, throughput fell off a cliff and time-to-first-token kept growing.
  • 10 of the 16 jobs failed, so about 12 agents is the ceiling.
  • Swap stayed at zero and the CPU sat near 6%, so RAM capacity was the bottleneck even with 192 GB of VRAM.
  • Side finding: the biggest models were the fastest, so a big model isn't necessarily a slow one.
  • The 256 GB result isn't in the provided transcript, which cuts off before it.

Context:

  • AMD's upcoming Halo Station (due 2027) pairs 2 TB of system RAM with 576 GB of HBM3 GPU memory.
  • That's almost 4x more slow memory than fast memory, which is what prompted the test.
