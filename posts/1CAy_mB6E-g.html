Building An Automated Video Production Factory

Matt Wolfe · 2026-07-06 · 6,330 views  ·  Watch on YouTube →
Vibe-coded dashboard that auto-generates short-form video scripts.

It's a real-world case study of vibe-coding a full-stack content app with feedback loops and performance-based self-improvement — the exact pattern you'd bolt onto a web app.

What it is: A custom web dashboard, built in half a day with Anthropic's Fable model, that turns articles/text/notes into fully-produced social media shorts.

How it works:

  • Input a URL, raw text, an uploaded file, or notes on the angle you want
  • Pick target length + which AI model writes the script
  • Generates a full short-form script, then fact-checks it for accuracy
  • Iterate: give feedback, rewrite/optimize, view the formula used, export as a doc, share
  • Built-in teleprompter for recording the A-roll
  • Auto-generates matching B-roll clips, tells you placement, batch-downloads all
  • Feedback loop: watches your Instagram Reels + YouTube Shorts, reads which performed best, and feeds that data back to improve future scripts

Tools & links:

  • Fable (Anthropic) — the model he vibe-coded the whole app with
  • futuretools.io — his AI tools directory

Heads up: No repo or source shared — it's a demo/promo. The Fable pricing angle (July 7 move to usage credits) is the real hook of the video, not the build.

Why it matters for you: The transferable pattern is an ingest → generate → fact-check → human-feedback → learn-from-analytics loop wired into a dashboard UI — a clean blueprint for any content or workflow feature in your web apps, minus the video-specific bits.
