Matt Wolfe · 2026-10-16 · 169,604 views  ·  Watch on YouTube →
Weekly AI news: Krea 3, Flux 3 Klein, new LLMs

Mostly image-model demos with little for web app builders, but Flux 3 Klein's open weights could mean self-hosted image generation in your app.

What it is: A weekly AI news roundup. The transcript we have only covers the image-model segment (Krea 3, Flux 3 Klein). The LLM segments (Gemini 4 Argon, Meta Muse Wonder, open-weight models) are cut off, so nothing below covers them.

How it works:

  • Krea 3 (public beta): Image editing model. Select a region of an image (phone, eyes, text, hat logo), type an instruction, and get about 3 variations in roughly 10 seconds.
  • Krea 3 editing quality: Edits leave the rest of the image untouched. Text swaps keep the original font and colors. Matt says it is cleaner than ChatGPT Image or Nano Banana, and that those will likely copy the workflow.
  • Flux 3 Image Klein (Black Forest Labs): Open-weight image model. Weights are downloadable on Hugging Face.
  • Flux 3 Klein speed: On a DGX Spark (about $4k), text-to-image takes about 7.3s and image editing about 16.2s. An RTX 4070 does the same jobs about 1.5s slower, so it runs on consumer hardware.
  • Flux 3 Klein quality: Matt calls it decent but unremarkable. Its selling point is the open weights.
  • Free trial: A free Hugging Face Space runs on shared compute, so it is slow when busy.
  • Third image model: The video says three image models shipped this week but names only two in the available transcript.

Tools & links:

  • Krea — Krea 3 public beta, with inline region-based image editing
  • Black Forest Labs on Hugging Face — Flux 3 Klein weights and the free demo Space
  • FutureTools — Matt's AI tool directory

Why it matters for you: The only real web-app angle is Flux 3 Klein, an open-weight image generator and editor that runs on a single consumer GPU, so you could self-host it for in-app image features instead of paying per call. The rest is creator tooling (thumbnail editing), so skip it unless you need that.
