The BEST Jev Use Cases for AI Coding (Absolute Game Changers)

Cole Medin · 2026-09-30 · 28,650 views  ·  Watch on YouTube →
Jev decision model as fast, cheap guardrails for coding agents

Cole shows how to swap slow LLM-based checks for a ~20-200x faster decision model inside Claude Code hooks, which is directly stealable for hardening and speeding up your mx-workflow skills and agents.

What it is: A quick tour of four practical ways to use Jev, a 'system one' decision model, in AI coding workflows. The transcript covers only the intro and the first use case (security guardrails), so the other three are not covered here.

How it works:

  • Jev in a nutshell: you pass it a situation (the 'state') plus a list of multiple-choice questions. It answers all of them in parallel, each with a probability (a confidence score).
  • Why not just use an LLM: you can already get decisions from structured output, but Cole claims Jev is 20-200x faster and 40-1,000x cheaper, and more accurate than whichever LLM you compare it to. Treat those numbers as his claims, not benchmarks you've verified.
  • Use case 1, security guardrails: coding agents will read `.env` files or delete folders even when your rules or skills say not to, especially once context bloats or a prompt invites a workaround. Rules and prompts are suggestions, but hooks are enforcement.
  • Mechanism: a `PreToolUse` hook fires before the agent runs a tool (read a file, run a command). The hook analyzes the pending action and returns an error code to block it, so the agent has to pick another route, e.g. reading `.env.example` instead of `.env`.
  • The problem he's setting up (the transcript cuts off here): a regex or pattern-matching hook is brittle, and an LLM-based hook is slow and costs tokens. Jev is the middle path: a semantic judgment at near-regex speed. This is my inference from where the sentence was heading.
  • Context: he frames this around token efficiency because rate limits are currently painful. He's also running a workshop in his Dynamis community this Friday, and says more Jev videos are coming.

Jev-style classification could also gate other decisions (route this task, does this diff need review) without spending a full LLM call.
