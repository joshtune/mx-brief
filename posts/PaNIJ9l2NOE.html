Voice-driven AI builds interactive 3D apps live.

Voice mode in ChatGPT and Claude can now iterate on running interactive code in real time — a hands-free loop worth knowing about even if this demo is a toy.

What it is: A 60-second demo of using ChatGPT's and Claude's new voice features to generate and then iteratively edit an interactive 3D Iron Man suit — no keyboard.

How it works:

  • Spoken prompt kicks off the build: "build me a complete 3D model of the Iron Man suit that I can interact with"
  • The output is a live interactive artifact — rotate, zoom, inspect individual components, toggle the arc reactor, auto-rotate
  • Follow-up edits are all voice: "make the entire suit purple," "make the helmet 20% bigger," "add solar panels across the back"
  • Edits apply to the existing artifact rather than regenerating from scratch — it's a conversational edit loop, not one-shot generation
  • Matt admits the solar panels took "a little bit of back and forth" and the result "isn't perfect" — spatial/geometry instructions still need several passes

Tools & links:

  • ChatGPT — voice available free on web and app
  • Claude — voice free on web and app across all plans; paid tiers get more usage and features
  • FutureTools — Matt's AI tool directory

Why it matters for you: The signal here isn't the Iron Man suit — it's that voice is now a viable input for *iterating* on a running web app, which maps directly to talking through UI tweaks on a live artifact instead of typing every prompt; the noise is that 3D toy demos tell you nothing about how this holds up on a real codebase.
