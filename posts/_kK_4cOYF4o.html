Nate Herk | AI Automation · 2026-08-21 · 19,211 views  ·  Watch on YouTube →
Run Claude Code on free OpenRouter models via env vars

It's a two-minute config change — swap three env vars in your Claude Code settings file and the harness routes to any OpenRouter model, including a $0/M-token stealth model, so you can burn 60M+ tokens on throwaway work for pennies.

What it is: A config hack that points the Claude Code harness at OpenRouter instead of Anthropic's API, letting you drive it with free or near-free models (Nate's demo uses "Ox Alpha" from an anonymous provider called Stealth).

How it works:

  • Desktop app won't work. The Claude Code desktop app overrides these settings and forces an Anthropic model. Nate's take: that's reasonable, not a bug. Use the VS Code extension, the VS Code integrated terminal, or a plain terminal instead.
  • Step 1 — OpenRouter account. One API key that routes to 500+ models. Filter by "free" to see the zero-cost tier; the paid ones (DeepSeek, Opus 5, Fable 5, GPT, Gemini) are all reachable through the same key.
  • Step 2 — grab a key. Account → Credits → API Keys → Create new key.
  • Step 3 — edit your Claude Code settings file. Add the block to the `env` section (the `.claude/settings.json` `env` map — Claude Code injects these into the harness process). The variable that matters is `ANTHROPIC_AUTH_TOKEN`, which you set to your OpenRouter key, alongside a base-URL override and a model override. Nate pastes the exact block into the video description rather than reading it out.
  • Cost check, receipts included. His "stealth test" key logged 61.6M tokens in one day of hammering it. Total spend on Ox Alpha for the day: ~$0.13. Ox Alpha lists at $0/M input and $0/M output on OpenRouter; the change is presumably routing/overhead.
  • Free tier caveats: rate limits and per-day caps are the norm on free models — read the fine print per model.
  • The data warning, stated plainly. Stealth is an *anonymous* model provider. Provenance unknown — Nate explicitly says "we don't know if it's Chinese or not." Don't pipe sensitive code or business context through it. He runs it against Herk 2 (his personal AI OS / second brain) and is upfront that this is a "try it, don't trust it" setup.
