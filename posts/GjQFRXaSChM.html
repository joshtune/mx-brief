Testing how quantization breaks an LLM's accuracy.

If you run local AI, this shows exactly which quant level still gives trustworthy answers — but it's software-focused, not the hardware/cost comparison you're after.

What it is: A quantization stress-test that runs Qwen 3 32B at 8 different bit-depths to find where it starts hallucinating.

How it works:

  • Takes Qwen 3 32B and quantizes it from full BF16 (unquantized) down to ~1 bit per weight
  • Uses a fact-based prompt (name the Apollo moonwalkers, missions, years, notable surface activity) because facts are objectively checkable, unlike creative writing
  • Prompt explicitly forbids inventing facts and asks the model to admit uncertainty
  • Even the unquantized base model fails one fact (claims John Young walked on the moon twice — nobody did), so degradation is measured against an already-imperfect baseline

Tools & links:

  • Qwen 3 32B — the test model (older but fine for measuring quant degradation)
  • LM Studio / Ollama — the local runners the video calls out for silently defaulting users to 4-bit
  • RTX Pro 6000 — GPU referenced in gear links
  • Thunderbolt 5 external SSD — gear link

Why it matters for you: This one is mostly a software/accuracy deep-dive — no Mac mini vs. dedicated-AI-machine cost breakdown here, so it's lower priority for your hardware interest unless you want to know which quant level is safe to run.
