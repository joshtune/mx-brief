AI News: The New Model That's As Good As Fable

Matt Wolfe · 2026-06-26 · 96,236 views  ·  Watch on YouTube →
Sakana's Fugu router model rivals Fable on benchmarks.

A new orchestrator model auto-routes your coding prompts across providers with failover — handy if you build apps and hate single-provider outages.

What it is: Sakana AI's Fugu — not a single model but an *orchestrator* that routes your prompt to the best underlying model (sometimes several), with automatic failover if a provider goes down.

How it works:

  • Two tiers: Fugu (fast, cheaper, good default) and Fugu Ultra (max quality for hard multi-step problems).
  • Acts as a manager model picking which provider/model handles each request — if OpenAI or Anthropic endpoints fail, it reroutes so you don't lose progress.
  • Benchmarks: beats Fable 5 on LiveCodeBench, beats Mythos on GPQA, ties Fable 5 on SciCode, slightly behind on SWE-bench Pro.
  • Setup is API-key based and wired into the Codex CLI — install, then `codex-fugu`, switch tiers with `/model`, crank reasoning with extra-high effort.
  • Matt YOLO'd two builds (a Megabonk clone + a FutureTools clone) on Ultra/extra-high: ~1 hour each, 22M input / 210K output tokens, ~$30 total. Apps ran but were rough.

Tools & links:

  • console.sakana.ai — create API key, add billing (pay-as-you-go), generate key
  • futuretools.io — Matt's AI tool directory (the clone target)
  • OpenAI Codex CLI — the recommended way to run Fugu locally

Why it matters for you: A provider-agnostic router with failover is genuinely useful for shipping web apps — but watch the token spend: Ultra on extra-high burned $30 for one toy app, so reserve it for hard problems, not boilerplate.
