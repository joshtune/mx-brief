Not even close… M5 Max vs Razer Blade 18

Alex Ziskind · 2026-08-25 · 32,369 views  ·  Watch on YouTube →
Razer Blade 18 with RTX 5090 beats M5 Max at local LLMs.

It's the rare Ziskind video where the Mac loses on AI inference — but only if you cut context length down, which is exactly the trade-off that decides whether a $4-5K laptop or a cheap Mac mini is the better local-AI box for you.

What it is: Head-to-head local LLM benchmark between a new M5 Max MacBook Pro and the 2026 Razer Blade 18 (RTX 5090 mobile, 24GB VRAM, Intel Core Ultra 9).

The actual numbers:

  • Qwen 3 4B multimodal, 4-bit quant — MLX on Mac vs GGUF on Razer
  • At 262K context: Razer collapses to 25 tok/s — VRAM is exhausted, model spills to CPU. Mac holds 181 tok/s
  • At 68K context: Razer recovers to 129–160 tok/s (inconsistent run to run)
  • Larger models in llama.cpp: Razer wins prompt processing decisively and wins token generation too — "not even close"

The hardware story that matters:

  • The RTX 5090 mobile's 24GB VRAM is a hard wall. Unified memory on the Mac isn't fast per-GB, but there's a lot more of it — long context is where Apple Silicon still wins by default
  • LM Studio surfaces estimated memory usage before load; on the Razer at max context it reads as consuming 100% of VRAM
  • Verdict from Alex: buy the Razer if your workload is gaming + AI; the Mac if you need big context windows

Rough cost framing (not stated in the video):

  • Razer Blade 18 / RTX 5090 config: ~$4,500–5,500
  • M5 Max MacBook Pro (high-memory): ~$4,000+
  • A Mac mini M4 with 32–64GB lands closer to $1,000–2,000 and runs the same MLX models with far more addressable memory than 24GB of VRAM — slower tok/s, but no context cliff

Tools mentioned:

  • LM Studio — GUI runner used for the MLX vs GGUF comparison
  • llama.cpp — the GGUF backend used for the larger-model tests
  • MLX — Apple's framework behind the Mac-side numbers

Why it matters for you: If you're sizing a local-AI machine, this video's real lesson is that memory capacity beats raw GPU speed once context grows — which is the argument for a cheap high-RAM Mac mini over a $5K gaming laptop, unless you also game.
