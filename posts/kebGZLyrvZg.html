Run Claude Code inside your Grokbot's terminal

It's a 2-minute setup that gives you your full AI operating system, with every skill and bit of context, on your phone through a bot that already has a terminal.

What it is: Nate shows how to install Claude Code on the shared computer behind his Grokbots, sign in with his existing subscription, and clone his repo so the whole setup is reachable from his phone.

How it works:

  • All Grokbots share one computer, which means one file system and one terminal.
  • Type `claude` in that terminal and Claude Code starts, running on his team account and drawing on the subscription rather than API billing.
  • You don't have to do the install yourself. Tell the bot to "use my Claude Code subscription on your desktop" and it installs Claude Code from the terminal.
  • Sign-in is a browser-style flow: Claude Code prompts you, you enter your credentials, and you hit authorize.
  • Then clone your repo into that machine. Nate cloned Herk 2, his "AI operating system", which holds his skills, processes, business knowledge and context.
  • Once that's done, Claude Code, Codex or any other CLI can be driven from your phone at any time.

Why it matters for you: The pattern is to put a shared terminal, a subscription-authenticated agent and a context repo behind a chat interface. That makes your whole workflow mobile, and it's a quick copy if you already have a bot with shell access. One caveat the video skips: you're leaving subscription credentials on a shared box, so check who else can reach that terminal.
