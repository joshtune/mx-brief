Herdr: tmux rebuilt for running AI agents

Chuck says he uses Herdr every single day to run Claude Code, Codex, Gemini and Grok side by side, so this is the clearest look yet at his daily AI terminal setup.

What it is: Herdr is a mouse-first, tmux-style terminal multiplexer built for AI coding agents, and it's now Chuck's daily driver.

How it works:

  • Persistent sessions — launch panes and agents on one machine, detach, then reattach from a laptop as if you never left (the tmux trick, same idea)
  • Agent-aware status — agents flag when they're done, blocked, or have a question, via notifications, icons, toasts and sounds
  • Session filtering — filter sessions by status, so you can see which agent needs you
  • Agents drive Herdr — they can open their own panes and windows
  • Agent-to-agent chat — Chuck's Claude Code launched Codex, Gemini and Grok, talked to them, and they talked back
  • Setup — install with a one-line command (macOS/Linux shell, Windows PowerShell), then run `herdr`. Onboarding detects installed agents (it found Claude and Hermes) and installs integrations
  • Controls — Ctrl+B is the prefix key, tmux-style, but the mouse works everywhere. It also has themes (he picked Groovebox)
  • Persistence demo — start `ping 1.1.1.1` in a pane, detach, and it keeps running (the transcript cuts off before the reattach)
  • Tags hint at git worktrees — worktrees are listed in the tags, but the transcript shown doesn't cover them
