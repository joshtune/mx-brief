The One-Prompt Dashboard Trick

Matt Wolfe · 2026-09-01 · 8,405 views  ·  Watch on YouTube →
Building internal dashboards with ChatGPT Codex Sites.

It's a look at ChatGPT's Sites feature shipping hosting, auth, and a database from one prompt — relevant if you're weighing whether to hand-roll another internal web app or let a prompt do it.

What it is: A 90-second demo of turning a spreadsheet into a shareable multi-platform analytics dashboard using ChatGPT's Codex "Sites" feature — one prompt, no infra work.

How it works:

  • Open Codex inside the ChatGPT app, type `@sites` in the prompt box to invoke the Sites tool, then describe the app you want.
  • Codex builds the whole thing — Matt's example aggregates audience/growth numbers across YouTube, Instagram, TikTok, LinkedIn, X, Threads, Facebook, and a newsletter into one view.
  • Sites provisions the parts you'd normally wire yourself: hosting, authentication, and the database. No deploy pipeline, no auth provider setup.
  • Output is shareable with a team and can be pointed at a custom domain.
  • Built-in analytics covers visitors and page views out of the box.
  • The genuinely new bit: web MCP support. You define explicit actions on your site that AI agents can call directly, instead of an agent screen-scraping your UI and guessing at click targets.

The honest caveat: This is a pure product demo — no code shown, no discussion of what happens when the generated app needs real maintenance, schema changes, or custom business logic. Treat it as a signal about where the tooling is, not a build tutorial.

Tools & links:

  • ChatGPT Codex app — the client hosting the Sites feature; `@sites` in the prompt box triggers it
  • futuretools.io — Matt's AI tool directory

Why it matters for you: The web MCP angle is the part worth stealing regardless of whether you ever touch Sites — exposing declared actions on your web apps so agents call intent instead of simulating clicks is a pattern you can implement in your own stack today, and it's the direction agent-facing web apps are heading.
