Nate shows a code-driven video pipeline (web page, canvas, Blender Python) that costs less than Veo or Seedance-style generation and lets you re-render single frames, which fits your need for concrete, reproducible instructions.

What it is: A walkthrough of making a video where Claude Code writes the code that defines every frame, instead of an AI video model generating pixels.

How it works:

  • Code, not generation: Claude writes code that answers one question per frame: what should the screen look like at this exact moment?
  • Web page: draws the interface.
  • Canvas: draws the title as it gets built.
  • Python script in Blender: places every object, light, and camera on every frame.
  • Cheap iteration: if a jump is too high, change one number and re-render only those frames.
  • Failure recovery: he fixed 16 frames that broke mid-render in under a minute, without redoing the whole video.
  • Cost claim: he says this is much cheaper than AI video generation models.
