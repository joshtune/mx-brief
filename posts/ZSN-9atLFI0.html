MacOS 27 adds a UI toggle for Thunderbolt 5 RDMA clustering.

Skippable — it's a 30-second settings-panel tip, not the hardware/cost comparison you're actually after.

What it is: MacOS 27 exposes a GUI toggle — "Enable RDMA over Thunderbolt" — for machines clustered via Thunderbolt 5.

How it works:

  • RDMA (remote direct memory access) gives low-latency memory access across clustered Macs.
  • Used for splitting large models across multiple machines and pooling their combined memory for local LLM inference.
  • Previously required rebooting into recovery mode and enabling via command line; now it's a one-click setting.
