Nate's seven AI tools that actually run his business

It's a quick tour of Nate's real stack (Claude Code/Codex as an OS, OpenRouter for automations), but the transcript cuts off after tool #2, so tools 3–7 aren't covered here.

What it is: A listicle of the 7 tools Nate kept after testing 100+. The transcript I have covers only #1 and #2 plus the start of a freebie pitch. Tools 3–7 are unknown. The tags also say "6" while the title says "7", so the count shifted at some point.

How it works:

  • #1: Claude Code + Codex. Local AI agents that read your files, write code and take natural-language instructions.
  • He calls them his biggest lever, driving ~90% of his daily workflow.
  • He runs his whole "AIOS" in them: second brain, projects, skills, knowledge and meeting transcripts.
  • Uses: slide decks, spreadsheets, Google Docs, brainstorming and counsel.
  • He replaced paid tools with custom-built apps: Gamma (slide decks), Poppy (content) and a homemade Loom clone.
  • His caveat: this works for personal or small-team use, not for scaling to hundreds of thousands of users.
  • His starting advice: pick a tool you pay for monthly but use one feature of, and rebuild that feature.
  • Another idea: point Claude Code at SOPs and client docs so the team asks it questions instead of asking you.
  • He pays for both and uses both weekly. Codex is better at computer/browser use; Claude Code is the better thought partner.
  • Usage limits currently last longer on one of them, and he expects that to flip within ~2 months.
  • His real goal is a folder and file structure that lets him switch between the two painlessly.
  • #2: OpenRouter. One account for 500+ models from 80+ providers.
  • It replaces separate keys, billing and logins for OpenAI, Anthropic, Google and the rest.
  • All of his production automations, for himself and for clients, use it as the model provider.
  • Fallbacks: if a model errors or goes down, it tries the next one instead of breaking the automation.
  • Per-automation API keys give cost analytics per workflow.
  • Example pattern: a cheap, fast model triages incoming leads, and a smarter model writes the replies.
  • Switching models is a one-line change.
  • Freebie pitch: a free AI OS kit built on his "Herc Loop" framework: context, connections, capabilities, cadence.
  • It ships with six skills, including setting up a "brain". The transcript cuts off before the rest.
