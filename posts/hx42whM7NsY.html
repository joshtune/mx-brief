Jev: AI model that outputs decisions, not text

If your web app burns LLM tokens on classification, scoring, or yes/no checks, Jev could do it for a fraction of the cost and latency.

What it is: Jev is a model from Type-Safe AI that skips text generation and returns structured values (a choice, a score, or true/false) directly.

How it works:

  • Output types are limited to three: choice (pick from options), score (a number), or null (basically true/false)
  • Regular LLMs like GPT generate text, even for decisions, and often write code that then makes the decision. Jev goes straight to the decision.
  • Since it emits no prose, it is very fast and very cheap
  • Pricing: input tokens are $0.04 per million ($42 per billion). Output tokens are free ("too cheap to meter").
  • Demo: Steven Tay built an app that takes a destination URL and flags whether it looks malicious before you click
  • Integration tip from the video: tell Codex or Claude Code what you want Jev to do and let it write the integration code

Tools & links:

  • Jev by Type-Safe AI — the decision-only model. The transcript gives no URL, so check the video description or Type-Safe AI's site.
  • Codex / Claude Code — suggested for generating the Jev integration code

Why it matters for you: Good fit for the boring high-volume parts of a web app: content moderation, form or link validation, routing, ranking, and intent classification. It replaces a full LLM call, and its cost and latency make those checks viable on every request.

Caveats:

  • The transcript is thin. There are no benchmarks, accuracy numbers, or API details, so validate quality on your own data first.
  • It only covers decision tasks. It won't replace an LLM for generation.
