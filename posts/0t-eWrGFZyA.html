Anthropic drops Opus 5.5: Fable-level coding at Opus pricing.

If you're building web apps with Claude, Opus 5.5 now beats Fable 5.1 on agentic coding benchmarks at 40% lower cost — this is your model-swap signal.

What it is: Anthropic shipped Claude Opus 5.5 the same day OpenAI launched GPT-6-Sol — a mid-tier model that now outperforms Anthropic's own top-tier Fable 5.1 on most benchmarks.

How it works:

  • Agentic coding (general): 66.4% — state-of-the-art
  • Agentic coding on Frontier Code: 54.4% — state-of-the-art, beats Fable 5.1
  • Agentic coding on Cursor Bench: 57.8% — state-of-the-art
  • GDPval (knowledge work): 1846 — state-of-the-art
  • Loses to GPT-6-Astra on: automation bench (Astra), Humanity's Last Exam, terminal bench science
  • Artificial Analysis aggregate score: 58, vs. Fable 5.1 and GPT-6-Astra tied at 53

Pricing (the part that matters for your build costs):

  • Input: $4/M tokens (down from $5 on Opus 5)
  • Output: $20/M tokens (down from $25 on Opus 5)
  • Compare to Fable 5.1: $10/M in, $50/M out — Opus 5.5 beats it on capability at less than half the price
  • Caveat: Opus 5.5 burns way more tokens per task (119K vs. Fable 5.1's 78K), so real-world cost-per-task only drops from ~$7.63 to ~$5.98 in max mode — still a win, just not as dramatic as the per-token price cut suggests

Tools & links:

  • No new dev tools or libraries mentioned — this is a model-capability/pricing update, not a build tutorial
  • Available now in Claude directly

Why it matters for you: If you're currently defaulting to Fable 5.1 (or Opus 5) for agentic coding in your web app projects, Opus 5.5 is now the better cost-to-capability tradeoff for most coding tasks — worth testing as your default before your next build session.
