You can monitor EVERYTHING in your homelab with this

NetworkChuck · 2026-10-12 · 432,601 views  ·  Watch on YouTube →
Free Checkmk monitors his whole homelab, AI agents included

Chuck is wiring monitoring alerts into an 'AI IT department' that fixes problems for him and giving his agents Checkmk API access, which is the AI-in-your-workflow angle you want to steal.

What it is: A Checkmk (sponsored, free Community Edition) setup walkthrough for monitoring everything in a homelab, with an AI-ops twist.

How it works:

  • Installs Checkmk on an Ubuntu 24.04 VM in under five minutes: download the .deb, install the package, run `omd version` to verify, then `omd create monitoring` and `omd start monitoring`.
  • Web UI is at `http://<ip>/monitoring`. Default admin credentials are printed in the terminal when the site is created.
  • Adds hosts under Setup > Hosts > Add host, using a DNS name or IP (his Linux box is 10.77.14.14).
  • Six monitoring methods are available. He contrasts plain ping (is it alive?) with the Checkmk agent, which is installed on the target and reports much deeper data.
  • The transcript is truncated, so the rest comes from his intro, not from walkthrough detail.
  • Targets he says he monitors: Linux servers, MikroTik and UniFi gear, Docker containers, Proxmox VMs, his website, a Windows gaming PC, Plex, Home Assistant, NAS capacity and drive health, and (jokingly) his toilet.
  • He also monitors AI infrastructure, such as a Hermes gateway and vibe-coded projects, to check they are still responding.
  • The AI part: Checkmk alerts get routed to his 'AI IT department', a set of agents that investigate and fix problems on their own.
  • He then connects his agents to the Checkmk API so they can configure and monitor things on demand. In effect, the agents manage the monitoring system itself.
  • He notes the free version takes some tinkering to cover everything.

Tools & links:

  • Checkmk — free, open source monitoring server (sponsor link, Community Edition)
  • Ubuntu 24.04 VM — host for the monitoring server (Docker or a package install also work)
  • Checkmk agent — installed on each target for deep metrics
  • Proxmox, UniFi, MikroTik, Docker, Plex, Home Assistant — things he points it at
  • Hermes gateway — an AI agent endpoint he monitors

Why it matters for you: The takeaway is a loop: monitoring detects an issue, an alert goes to an AI agent that triages and fixes it, and the agent can reconfigure the monitoring through the API. Copy that for your own homelab.
