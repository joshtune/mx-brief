Anthropic’s CEO: How to Build a 1 Person Business with Claude

Nate Herk | AI Automation · 2026-09-18 · 150,418 views  ·  Watch on YouTube →
Building a one-person AI eval SaaS using Dario's three filters.

Nate walks through the actual filtering/ideation process with Claude before writing a line of code — useful if you're hunting for your own one-person SaaS idea.

What it is: Nate breaks down Dario Amodei's comments on a one-person billion-dollar company, turns them into 3 practical filters, then uses Claude to brainstorm, debate, and pick a real business idea to build — landing on "Agent Report Card," a QA/eval tool for AI agents.

How it works:

  • Filter 1 — Capital deployment: Business trades/deploys its own money (e.g. prop trading, real estate flipping, used cars). Ruled out — too capital/risk heavy for most people.
  • Filter 2 — Software: Normal people can now build real software solo with Claude Code. Almost anything qualifies here, so it's not a strong enough filter alone.
  • Filter 3 — Automatable sales & support: Offer must be repeatable, low-customization, and support-able by an AI agent (not humans) — think file converters or ad reviewers, not enterprise tools needing consultations.
  • Nate fed Claude 3 candidate ideas: a Calendly-style scheduler, a cold outreach research/drafting tool, and an AI agent "stress tester."
  • He had Claude run a "war room debate panel" — playing devil's advocate on each idea, asking who'd pay, whether software alone could deliver it, and whether one person could sell + support it solo.
  • Scheduler idea: too crowded a market. Outreach tool: easy to pitch but can't prove email conversion. Agent stress-tester: won — clear, provable output (a report showing where an AI agent fails).
  • Resulting product: Agent Report Card — AI agencies connect their client's support bot, the tool runs it through adversarial/difficult scenarios, and generates a report flagging hallucinated policies, wrong refunds, data leaks, etc. — replacing manual QA testing every time a prompt changes.
