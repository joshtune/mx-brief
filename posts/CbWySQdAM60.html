NetworkChuck benchmarks Apple's M5 Ultra Mac Studio for local AI.

He's running it as a dedicated local-AI server in his server room (not a desktop), which is exactly the home-lab-for-AI setup worth stealing.

What it is: Apple loaned NetworkChuck an M5 Ultra Mac Studio; he racks it in his server room purely as a local-AI inference box and benchmarks it head-to-head against his M3 Ultra.

How it works:

  • Deployment choice: no keyboard/monitor — it's treated like a server, dedicated to local AI workloads only.
  • Benchmark setup: Qwen 32B 4-bit model, 32K-token prompt (summarize a long essay), run simultaneously on both machines.
  • Time-to-first-token (prompt processing): M5 = 21.66s vs M3 = 82.85s — 3.8x faster. Credited to the new per-core Neural Accelerators on the M5's 80 GPU cores (same core count as M3, but each core now has dedicated matrix-math hardware).
  • Generation speed: M5 = 43.3 tok/s vs M3 = 28.1 tok/s — 1.5x faster. Credited to memory bandwidth jump (819 GB/s → 1.2 TB/s), since every generated token requires re-reading the full ~15GB model weights from memory.
  • Planned follow-up tests (teased, not yet shown in this clip): image/video generation, transcription, video ingestion, a local open-source Jarvis/Alexa-style assistant ("Kev"), and a local model driving DaVinci Resolve for video editing.
