How to Put Claude Code on a VPS in 10 Minutes

Nate Herk | AI Automation · 2026-11-19 · 23,096 views  ·  Watch on YouTube →
Always-on Claude Code on a Hostinger VPS, driven via Telegram

If you want Claude Code and your skills reachable from your phone 24/7, this walks through the one-click Hostinger VPS route and the setup-doc-plus-Claude trick that keeps it painless.

What it is: A walkthrough of renting a Hostinger VPS with Claude Code preinstalled, so Claude Code runs 24/7 in the cloud and you can talk to it from Telegram on your phone.

How it works:

  • The demo: Nate messages Claude Code through Telegram ("Who am I and what are you supposed to help me with?"). It replies with context because his AIOS (his personal Claude Code operating system of skills and context) lives on the server.
  • Why a VPS: It's a virtual machine in the cloud that never turns off. Claude Code stays reachable, and you can also run automations, videos, or even host AI models on it.
  • Step 1, brief Claude first: He pastes his free setup doc into his local Claude Code and tells it he's setting up a new instance on a VPS. That way Claude can save details (like the VPS credentials) into his AIOS and help troubleshoot.
  • Step 2, buy the VPS: Use the Hostinger link from the description and pick a plan. CPU and RAM tiers are upgradable later, so you aren't locked in.
  • Step 3, pick the app: Choose the one-click Claude Code application template. You can also buy a plain VPS and install Claude Code yourself. Other one-click apps he runs on other servers: n8n, Hermes Agent, OpenClaw.
  • Step 4, set a root password: Store it in a password manager and/or your `.env`, so Claude can keep it for you. Optionally enable Hostinger's free malware scanner, then hit Finish setup. Provisioning takes a few minutes.
  • Step 5, manage it: The hPanel dashboard lists all your servers, and you can reset the root password there. He renames his VPS ("herk2.ios") to stay organized. SSH from your terminal also works.
  • Step 6, open Claude Code: The dashboard has a "learn how to use Claude Code" button. The transcript cuts off here, before the Telegram hookup, so that part isn't covered below.
  • Pricing claim: He says the plan is about $368 of VPS for roughly $100 for the year on a 12- or 24-month plan with his code, plus a Black Friday sale. Verify on Hostinger before buying.

  • AIOS — Nate's personal Claude Code setup of skills and context. It's his own system and isn't linked in the available description.
  • SSH — terminal access to the VPS if you want to bypass the dashboard.
  • n8n, Hermes Agent, OpenClaw — other one-click apps Hostinger offers that he runs on separate VPSs.
