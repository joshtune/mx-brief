This AI Finds Clients and Does the Work on Its Own

Chris Koerner on The Koerner Office Podcast · 2026-09-16 · 7,859 views  ·  Watch on YouTube →
Autonomous AI agents that find leads and do the work while you sleep.

If you're looking for a low-cost side hustle, this is a blueprint for using autonomous browser agents to prospect, build, and sell client work without hiring anyone.

What it is: A conversation about running fleets of autonomous AI agents that operate a real browser like a human — finding leads, doing outreach, and completing deliverable work end-to-end, unsupervised.

How it works:

  • Agents control an actual browser (mouse/keyboard off, agent driving) rather than using APIs — so they can work with any website a human could.
  • Reachable via Telegram/WhatsApp, so you can direct or check in on agents from your phone.
  • One guest reportedly runs ~20 agents fully autonomously and end-to-end, including a dedicated visual/motion design agent.
  • Workflow described: set the agent up before bed, wake up to generated leads.
  • Applied to a specific niche play: agents find prospective clients in a niche, then build them a new website/digital property on spec.
  • That built site becomes a template — reused ("stamped out") across future prospects in the same niche, turning one build into a repeatable outbound + sales motion.
  • Guest said the approach could be started "for almost nothing" — low capital requirement to test.

Why it matters for you: This is a concrete side-hustle template — pick a niche, use a browser-controlling AI agent to prospect and pre-build a product (e.g., a website) for each lead, then sell the finished implementation instead of cold-pitching an idea.
