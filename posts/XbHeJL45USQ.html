GLM-5.2 Proves Open-Source AI is Finally Good Now!

Matt Wolfe · 2026-07-01 · 65,548 views  ·  Watch on YouTube →
Testing Z.ai's cheap, MIT-licensed GLM-5.2 coding model.

GLM-5.2 is a dirt-cheap, 1M-token, coding-optimized model you can point at your app's codebase via Claude Code, Cursor, or its API — a real budget alternative for agentic dev work.

What it is: Z.ai's GLM-5.2 — a 753B-param, MIT-licensed open-weight model tuned for coding and agentic workflows, at a fraction of frontier prices.

How it works:

  • 1M token context window, 128K max output — text in, text out (no image/audio yet).
  • Supports function calling, structured output, context caching, and MCP.
  • Optimized for agentic coding: point it at files/docs/code and say "understand this, make a plan, do the work."
  • Open-weight ≠ run-at-home: 753B params, ~1.5TB of weights; even a 1-bit quant needs ~200GB memory. Not runnable on consumer hardware.
  • Three ways to use it: (1) Z.ai web chat, (2) Z.ai API into your apps or an agent harness (Claude Code, OpenCode, Cursor), (3) self-host on rented cloud GPUs for privacy/control.

Tools & links:

  • Z.ai — hosted chat + API access to GLM-5.2
  • Hugging Face — GLM-5.2 open weights for self-hosting/fine-tuning
  • Works inside Claude Code, OpenCode, and Cursor as the backing model

Why it matters for you: Cheap capable models change how you build — when agentic coding runs are inexpensive, you feed more context, let agents run longer, and experiment freely on your web apps instead of rationing tokens; big shops (Coinbase, Cursor, Lindy) are already swapping in Chinese models for cost and control.
