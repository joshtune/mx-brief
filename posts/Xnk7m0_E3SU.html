RTX Spark Is Already Making People Mad

Alex Ziskind · 2026-06-20 · 74,633 views  ·  Watch on YouTube →
NVIDIA's RTX Spark mini AI box, decoded.

It's NVIDIA's new Mac-mini-sized AI desktop with up to 128GB unified memory — the kind of machine you'd weigh against a Mac mini for running local LLMs.

What it is: NVIDIA's RTX Spark — a small-form-factor desktop built for local AI, the follow-up to the DGX Spark, now aimed at gamers, creatives, and developers (not just AI researchers).

How it works:

  • Up to a 20-core ARM CPU fused to a Blackwell GPU (roughly RTX 5070 Ti-class) over NVLink — the same chiplet trick as DGX Spark
  • GPU silicon comes from NVIDIA's Blackwell die; CPU die is built by MediaTek
  • Up to 128GB unified memory the GPU can pull from directly for AI workloads — the headline spec for running larger local models, and the direct analog to Apple's unified-memory pitch
  • Sold through OEM partners (MSI, ASUS, etc.) rather than as a single NVIDIA box

The Mac mini comparison (your focus):

  • 128GB unified memory puts it in the same conversation as a high-RAM Mac mini / Studio for local LLMs
  • Pricing isn't stated in this clip — the description points to specific OEM units (MSI EdgeExpert, ASUS GX10) where the actual dollar figures live
  • Trade-off vs Mac mini: CUDA/Blackwell native AI tooling on the NVIDIA side vs Apple's lower power draw and macOS ecosystem

Tools & links (from description):

  • MSI EdgeExpert — OEM RTX Spark box
  • ASUS GX10 — OEM RTX Spark box
  • 400Gbps switches (2-port, 4-port) — for clustering multiple units

Why it matters for you: This is the closest NVIDIA has come to a Mac-mini-style AI desktop — same unified-memory play — so it's the machine to price-check against a maxed-out Mac mini before your next local-AI build.
