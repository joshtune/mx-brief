What it is: A sponsored (NordVPN) myth-busting explainer on whether personal VPNs still matter in 2026.

How it works:

  • Distinguishes personal VPNs (NordVPN) from corporate VPNs — only the former is in scope.
  • A VPN forms an encrypted tunnel to a VPN server, so the internet sees the provider's network, not yours — it changes the network you appear to be on.
  • Tackles the big anti-VPN argument: HTTPS (TLS) already encrypts traffic, so the payload is hidden either way.
  • The catch: HTTPS hides content but not which sites you visit or how often — your ISP and on-path attackers can still profile you.
  • Live demo: Kali Linux + Wireshark sniffing an Ubuntu box shows `academy.networkchuck.com` plainly visible in DNS packets.
  • Teases the counter-argument — DNS over HTTPS (DoH) — to encrypt that lookup, referencing a David Bombal video (transcript cuts off mid-test).

Tools & links:

  • Kali Linux + Wireshark — packet sniffing lab used in the demo
  • DNS over HTTPS (DoH) — encrypts DNS queries that a VPN would otherwise hide
