I Turned Claude Code Into a Complete Video Generation System (with Archon)

Cole Medin · 2026-07-12 · 3,396 views  ·  Watch on YouTube →
Archon orchestrates agents for video marketing, not just coding.

Cole proves Archon's fan-out orchestration works for any long-running agentic workflow — the exact pattern your mx-workflow could borrow to parallelize non-coding tasks.

What it is: A demo of aiming Claude Code + Archon at a product catalog to auto-generate marketing videos — showing Archon is a general agent harness, not a coding-only tool.

How it works:

  • Builds an "AI Content Factory": a product catalog of still images that needs videos generated for each item.
  • The catalog is too big for a single coding agent, so Archon fans out parallel agents that pull products off a queue and generate a video for each — draining the queue autonomously.
  • Video generation is handled by Higgsfield (10-sec renders, vertical UGC-style ads with audio) driven entirely from the CLI, so the agent never leaves the terminal.
  • A Higgsfield "skill" (agent instructions) tells the agent when/how to invoke the CLI: "use this when the user wants to generate an image, video, or a UGC-style video ad."
  • Two Archon workflows drive the whole pipeline: queue management + parallel video-generation fan-out.
  • Explicitly framed as a proof-of-concept, not production-ready — the point is showcasing Archon's range.

What's different this time:

  • Prior Archon content was AI-coding-focused; here he generalizes it to any agentic workflow (research, content creation).
  • Notes Archon is at ~23,000 GitHub stars and users are increasingly running non-coding workflows on it — the trend that prompted this demo.
  • Leans on the emerging "skill" as CLI-wrapper pattern: a markdown instruction file teaching an agent to drive an external CLI tool.

Tools & links:

  • Archon — open-source harness/orchestration builder for connecting many agents on long autonomous tasks (queue + parallel fan-out)
  • Higgsfield — AI video/image generation with a CLI; used for the 10-sec renders and UGC ads (sponsor)
  • Claude Code — the coding agent terminal running the workflows
  • Demo repo with the Archon workflows, catalog site, sample videos, and Higgsfield skill — linked in the video description (not in the transcript excerpt)

Why it matters for you: The queue + parallel-agent-fan-out pattern is directly liftable into mx-workflow — model long non-coding tasks as a drainable queue with a skill wrapping each external CLI, instead of one agent grinding serially.
