This Completely Changes the Way We Build Production AI Agents (Vercel Eve)

Cole Medin · 2026-07-16 · 27,683 views  ·  Watch on YouTube →
Vercel's Eve turns a production AI agent into one folder.

Eve standardizes the exact folder-as-agent pattern (markdown instructions, TS tools, nested skills/subagents) you'd want to model mx-workflow on — with a compile step that wires it all together for free.

What it is: Vercel's newly open-sourced "file-system-first" agent framework, Eve — your entire production agent is a single folder of mostly markdown, compiled into a durable service.

How it works:

  • One parent folder wraps every primitive, each defined in its own subfolder — no manual wiring
  • Instructions = markdown system prompt + global rules
  • Agent definition = model choice + which skills to load
  • Skills = capabilities (same pattern as Claude Code's `skill.md` drop-in, invoked like slash commands)
  • Tools = TypeScript, run in an isolated sandbox for secure code execution
  • Channels = connect to Slack/Discord; Connections = MCP servers; plus sub-agents and schedules for autonomous runs
  • The compile step is the headline: at run/deploy time Eve traverses the folder, discovers every skill/MCP/hook, and emits a single manifest with everything linked — the main TS file imports nothing
  • Production-grade reliability via Vercel infra: durable sessions (every turn + tool call checkpointed as a workflow that survives crashes/redeploys and resumes) and isolated sandboxing for code execution
  • Cole's angle: orgs are already hand-rolling this folder-as-agent structure internally; Eve gives them a *standard* and handles the plumbing
