I Waited Two Years for This Mini PC… Then I Tested It

Alex Ziskind · 2026-09-20 · 232,829 views  ·  Watch on YouTube →
First non-cancelled Snapdragon X2 Elite mini PC, tested against Mac Mini.

It's the first real Snapdragon X2 Elite desktop box you can actually buy, positioned as a Mac Mini rival on price and memory bandwidth.

What it is: ASUS Ascent QN10, the first mini PC shipping with Qualcomm's Snapdragon X2 Elite chip (not a dev kit, not cancelled).

The machine & price:

  • Reviewer's unit: 32GB RAM, 512GB storage — no price stated for this config in the transcript
  • Chip: Snapdragon X2 Elite 88100, 18 cores (12 prime + 6 performance), all big cores, up to 4.7GHz boost, 3nm
  • Ports: 3x USB4, 2.5GbE, Wi-Fi 7
  • Needs an external 180W power brick — Mac Mini doesn't

Memory bandwidth vs Mac Mini (the number that matters for local AI):

  • This QN10 chip: up to 152 GB/s
  • Snapdragon X2 Elite Extreme (higher tier, not in this box): up to 228 GB/s
  • Mac Mini M4: 120 GB/s
  • Mac Mini M4 Pro: 273 GB/s
  • So this box sits *above* base M4 but well *below* M4 Pro on bandwidth

AI-relevant specs:

  • New GPU: Adreno X290 — handles matrix multiplication (the inference compute part), Qualcomm claims 2.3x perf/watt over gen 1
  • NPU: Hexagon, 80 TOPS (up from 45)

Historical context (background, skip if you just want the verdict): Reviewer traces the lineage from the 2019 8CX Gen 3 dev kit ($600) → Windows Dev Kit 2023 "Project Volterra" → first-gen Snapdragon Dev Kit ($900, May 2024, cancelled/refunded) → this QN10.

Why it matters for you: If you're weighing a Windows-on-ARM box against a Mac Mini for local AI work, the memory bandwidth numbers are the direct comparison point — this box beats base M4 but loses to M4 Pro, so it's a mid-tier option, not a clear Mac Mini killer.
