NVIDIA didn't want me to do this

Alex Ziskind · 2026-09-06 · 326,820 views  ·  Watch on YouTube →
Eight DGX Sparks clustered into 1TB of unified memory.

Skip the wiring saga and take the one number that matters: a ~$32K eight-box Spark cluster runs a 397B model at 24 tok/s, which no single Mac mini can do at any price.

What it is: Alex chains eight NVIDIA DGX Spark-class boxes (Dell GB10, MSI EdgeExpert, ASUS Ascent GX10, plus stock Sparks) over 400Gbps networking to pool ~1TB of memory, because NVIDIA's official docs stop at two units.

The machines:

  • NVIDIA DGX Spark — 128GB unified memory, GB10 chip, ~$3,999 each
  • Dell GB10 — same silicon, Dell-branded, similar ~$4K
  • MSI EdgeExpert ("EX10") — MSI's GB10 box, Amazon
  • ASUS Ascent GX10 — ASUS variant, typically ~$3,000, Amazon
  • Eight boxes total ≈ $28K–$32K before the switch

How it works:

  • Boxes connect via ConnectX-7 ports into a 400Gbps switch (2-port and 4-port options linked)
  • Cluster is brought up and sanity-checked with Qwen3 4B, which runs "really, really fast"
  • The real test is Qwen3.5 397B, an 800GB-on-disk mixture-of-experts model
  • Model loads to ~112GB of 119GB usable per node, spread across all eight
  • Result: 24 tokens/sec on a 397B model, viable because MoE only activates a subset of experts per token

Tools & links:

  • 2-port 400Gbps switch — links a pair of Sparks
  • 4-port 400Gbps switch — needed to scale past two
  • MSI EdgeExpert — GB10 box from MSI
  • ASUS Ascent GX10 — cheapest GB10 variant

Mac mini comparison:

  • M4 Pro Mac mini maxes at 64GB unified memory for ~$2,000; one Spark has 2x the memory at 2x the price
  • A Mac Studio M3 Ultra with 512GB (~$10K) is the closest single-box Apple answer, but still can't hold an 800GB model
  • Eight Sparks at ~$30K buys 1TB pooled; eight Mac minis can't pool memory this way without Exo-style hacks and slower Thunderbolt links
  • For sub-70B models a single mini or Studio is cheaper and quieter; this cluster only makes sense for 300B+ frontier-class weights

Why it matters for you: If you want to run open frontier-scale models locally, the answer is a GB10 cluster at ~$30K, not a Mac mini; if you don't, a single Spark or Mac Studio covers everything else.
