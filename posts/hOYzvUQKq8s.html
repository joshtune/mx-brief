Designing and deploying a full AWS app via Claude Code

Even a 20-year Amazon veteran who stopped coding 3 years ago says AI-driven dev is undeniable, so this shows the workflow you need to be fluent in: architecture, infra, deploy, tests, and CI/CD, all driven through an agent.

What it is: A 90-minute pairing session where RJ Mandalas (ex-Amazon L4→L5) teaches the host to design, build, and deploy a full-stack serverless AWS app entirely through Claude Code. The transcript is truncated, so only the opening setup is covered here.

The message to engineers:

  • AI-assisted dev is no longer optional. The host quit coding about 2 years ago and now calls AI "undeniable" as of Oct 20.
  • Even a veteran who hasn't coded in about 3 years can ship a full system in a session, so the barrier to rejoining is low.
  • The scarce skill is knowing what to ask for and judging the output, not typing the code. The guest says the first design wasn't great, but it was a solid baseline covering AWS components you'd otherwise have to already know.
  • Career angle: the guest credits advice from this channel for his first L5 promotion. A promo-visibility webinar ("Above the Cut") is also plugged.

What to prepare for:

  • Expect system design to start with an agent-generated diagram, then get iterated on by you.
  • Expect infra work (AWS CLI, IaC, deploys) to be driven by prompts, so you need to review it competently.
  • Expect load testing, dashboards, and CI/CD to be in scope for one engineer in one sitting.
  • Judgment about design tradeoffs matters more once generation is cheap.

Instructional workflow (as stated in the intro):

  • Install the prerequisites listed in the video description. The host says it took about 10 minutes, and Claude helped fix setup issues.
  • Open Claude Code and describe what you're building. Example: "build and deploy Conduit (a Medium clone) on AWS".
  • Ask for a rough system design diagram first, before any code. The guest uses Lucid Chart through Claude's tool integration, and says you shouldn't even need to name the tool. Excalidraw is an alternative.
  • Iterate on the architecture until it fits.
  • Use the AWS CLI inside Claude Code to write the infrastructure code (the transcript says "cloud for", likely CloudFormation) and deploy all assets for a serverless full-stack app.
  • Test the running app, then add load tests.
  • Set up dashboards.
  • Set up full CI/CD in GitHub.
  • Shortcut used: Conduit, a well-known Medium-style example API, gives you real-world design decisions without inventing a spec.
