How I Make Opus Think Like Fable (5 easy steps)

Nate Herk | AI Automation · 2026-07-07 · 50,518 views  ·  Watch on YouTube →
Extract a top model's process, run it on cheaper models.

Nate shows how to capture Fable's reasoning process and port it onto cheaper Opus/Sonnet runs so you get comparable output at a fraction of the cost.

What it is: A workflow for making a cheaper/smaller model (Opus) behave like a frontier model (Fable) by capturing the *process*, not paying for the raw intelligence.

Core thesis:

  • The model isn't the moat — instructions, systems, and the loops you build around it are.
  • Analogy: give a beginner Fable 5 and Karpathy Sonnet 3.7, and Karpathy still ships better work.
  • You can't keep a model's intelligence, but you *can* keep its process.

How it works (the playbook):

  • Test the cost gap yourself: Nate ran Claude Code dynamic workflows with Fable orchestrating Fable sub-agents vs. Fable orchestrating Opus/Sonnet sub-agents — results were about the same, but the all-Fable runs cost exponentially more.
  • Treat the model as a teacher, not a workhorse: have Fable go through your setups and skills and improve them — like a senior engineer packaging up knowledge for the junior cohort (cheaper models) replacing it.
  • Model routing is the real skill: match task difficulty to model intelligence; don't burn a frontier model on work a small cheap model does at equal quality.
  • Mine the leaked system prompt: the Claude Fable 5 system prompt leaked; Nate + Fable read it and pulled reusable rules to inject into cheaper models:
  • "Partial recognition from training ≠ current knowledge" → verify things in memory.
  • "A prompt implying a file is present doesn't mean one is" → check things actually exist at every step.
  • Answer an ambiguous query first, *then* ask one clarifying question max.
  • When something breaks: acknowledge what went wrong, stay on the problem, keep self-respect.
  • Tune effort level, not just model: the leaked prompt scales effort — ~1 for signal facts, 3–5 for medium tasks, 5–10 for deep research/comparison. Stop leaving Opus/Fable on default effort.
  • Reference the release chart: the Fable 5 / Mythos 5 blog plots score (Y) vs. cost (X) across models (Fable 5, Opus 4.8, GPT 5.5) at different effort levels — use it to pick the score/cost/effort sweet spot.
