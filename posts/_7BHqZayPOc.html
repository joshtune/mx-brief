I Tried PewDiePie’s Odysseus AI So You Don’t Have To (Its FREE)

Matt Wolfe · 2026-06-17 · 46,055 views  ·  Watch on YouTube →
Hands-on with PewDiePie's self-hosted open-source AI workspace.

It's an open-source, self-hostable AI workspace you could run locally or wire into your own web apps for chat, agents, and file/tool workflows without sending data to big clouds.

What it is: Project Odysseus — PewDiePie's open-source, self-hosted AI workspace (a ChatGPT/Claude-desktop-style interface layer over models you bring), already at 71k+ stars and 9.2k+ forks.

How it works:

  • It's the *interface* around models, not a new model — connects to local models, API models, and tools.
  • Pulls many AI workflows into one app: chat, agents, file work, deep research, model-output comparison, doc writing, notes/tasks, even email + calendar.
  • Pitched for privacy/control: your models, your data, on hardware you own.
  • Install via Docker (recommended); guides for Linux, macOS/Apple Silicon, and Windows.
  • Mac setup is `git clone` the repo → `cd` into it → run `./start_macos.sh` → set admin username/password → log into the local web UI.
  • Matt's honest caveat: expect jank and bugs; won't match ChatGPT/Claude/Gemini out of the box unless you have strong hardware and a good model setup.

Why it matters for you: A self-hosted, forkable AI workspace is a useful reference architecture (and possible local backend) for building privacy-first AI features into your web apps — but it's an early experiment, so treat it as inspiration over production today.
