GPT 5.6 Sol Made This Entire Video

Nate Herk | AI Automation · 2026-07-09 · 90,905 views  ·  Watch on YouTube →
One prompt, an agent produces a full talking-head video.

See the exact tool chain — Codex agents driving ElevenLabs, HeyGen, and Hyperframes via browser automation — to auto-produce a narrated avatar video end-to-end.

What it is: Nate hands GPT-5.6 "Sol" (running in Codex on Ultra) a single prompt and it orchestrates a full video production — script, voice, avatar, edit, and QA — with no human recording or editing.

How it works:

  • Model: GPT-5.6 "Sol," OpenAI's release from July 9 2026, positioned as their strongest coding model. In Ultra mode it coordinates ~4 agents at once (nine sub-agents spun up in this run) instead of answering a single question.
  • Benchmarks cited: Terminal Bench 2.1 = 91.9% on Ultra (up from 85.6% on GPT-5.5); BrowseComp (agentic browsing) = 92.2%. In a one-run 13-task in-house test, Sol took 97% of objective points (7 wins, 5 ties, 1 loss).
  • Voice: Script chopped into <60s sections to keep the cloned voice consistent, each run through Nate's authorized ElevenLabs voice.
  • Avatar: Audio uploaded to HeyGen, paired with Nate's avatar. The API couldn't lock the newest motion engine, so Sol used browser automation to open the HeyGen editor, switch every clip to Avatar V, regenerate, verify, and download.
  • Edit: Moved into Hyperframes — every visual mapped to the exact trigger phrase, avatar shifted (not covered), editorial cards for supporting ideas, avatar kept on-screen throughout.
  • Self-QA: Separate agents inspected rendered frames — checking entrances/exits, off-frame text, avatar continuity — and cross-checked factual claims against OpenAI's release notes. Any failed frame triggered another fix → render → review loop.
  • Cost: Dashboard showed 3M tokens / 2.5 hrs, but log inspection revealed ~450M total tokens (main agent ~86M) across nine sub-agents ≈ $300+. Nate notes Sol runs roughly half the price of Fable 5, comparable to Opus 4.8.
