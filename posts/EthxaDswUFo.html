Head-to-head coding test: GPT 5.6 Sol vs Fable 5.

If you're picking a model for real coding work, Nate's side-by-side shows where Fable 5's quality justifies 3x the cost and where Sol's token efficiency wins.

What it is: A practical bake-off — Nate drives GPT 5.6 Sol (via Codex) against Fable 5 (via Claude) on identical build prompts, comparing output quality, time, and cost instead of just reading benchmarks.

How it works:

  • Test 1 — browser bike game: Same prompt ("build a genuinely fun playable open-world bike game that runs in the browser," full creative freedom) to both models.
  • Sol's version: top-down bird's-eye view, functional (coins, controls, bunny hop) but awkward camera.
  • Fable's version: 3D POV, GTA-style open world, bigger map — the clear winner.
  • Time: Fable 21m 37s vs Sol 23m (roughly even).
  • Cost: Fable ~$14.22 vs Sol ~$4.50.
  • Output tokens: Fable ~90k vs Sol ~31k — Sol is far more token-efficient, but here that efficiency produced the weaker result.
  • Test 2 — scroll-stopping website: Prompt "build the most impressive interactive scroll-stopping website you can imagine." Both output interactive 3D scroll journeys ("10 billion years" timeline with sound); reveal/verdict continues past the transcript cutoff.
  • Takeaway forming: Codex/GPT are consistently more token-efficient (cheaper), but token efficiency ≠ better output — Nate rates Fable's work "significantly better" on the game test.
