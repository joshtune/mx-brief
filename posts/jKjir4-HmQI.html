Nvidia's Motion Bricks generates character and robot animation on the fly

Skip it for web app work: this is game and robotics animation research with nothing you can use in a web app.

What it is: Nvidia's Motion Bricks, an AI system that generates character and robot movement in real time instead of using hand-made animation.

How it works:

  • You give it a destination and a style (zombie walk, skipping, limping). It fills in the motion itself.
  • Details vary run to run. The character grabs a sword slightly differently each time.
  • It was trained on about 700 hours of real human motion capture.
  • Nvidia is also running it on a Unitree G1 humanoid robot, which walks around an office and drops to all fours to crawl.
  • Pitch: AAA games like Assassin's Creed need around 15,000 hand-built moves, and this could replace much of that work.
  • Matt says the code is already released.
