Agentic Apps: How Big Companies Are Actually Deploying AI Agents

Cole Medin · 2026-10-09 · 10,498 views  ·  Watch on YouTube →
Stop building agents; build business-outcome apps containing agents

It's a sponsored Oracle pitch, but the 'workflow first, agent as a tool' framing is a useful lens for deciding which parts of mx-workflow should be deterministic instead of agent-driven.

What it is: A sponsored (Oracle AI Agent Studio) walkthrough of moving from single chat agents to "agentic apps", where agents are components inside a deterministic, outcome-focused application. The transcript provided cuts off early, so the security and workflow sections he promises are not covered here.

How it works:

  • What he does differently now: Until now his channel was single-agent, chat-driven setups (second brain, coding assistants, support agents). For client work he starts from the business outcome, not the agent.
  • Oracle's definition of an agentic app: Start with the business outcome and the role you're helping. Design the experience, then embed multiple agents to automate parts of it.
  • Determinism over autonomy: Every agent-backed component runs inside a defined workflow. The LLM is used throughout, but the agent doesn't drive the whole thing. His pitch is that this gives you more control.
  • Demo prompt: "Manager coaching" app for a director with ~12 reports, giving one view of how engaged the team is with their development.
  • Generation: You describe the app in plain language, like prompting a coding agent. The platform builds the UI components and the workflows behind them.
  • Pre-configured components: Each component is backed by a workflow. One example is a button that sends follow-up emails to people who aren't meeting a goal.
  • Chat isn't dropped: You can still ask follow-up questions in chat, with structured components alongside it.
  • Stated lessons: He says he'll pull out lessons on workflows and security, aimed at enterprise but applicable to personal apps.
  • Caveat: The video is sponsored and presents Oracle as the best platform of those he's seen, so weigh that accordingly.

Tools & links:

  • Oracle AI Agent Studio — platform shown in the demo; he says the link is in the video description, and no URL appears in the transcript
  • No repos mentioned in the available transcript

Why it matters for you: For mx-workflow, the takeaway is to define the outcome first, wrap agent calls in fixed workflows (your `/mx:build` pipeline is already close), and keep chat as a follow-up layer. Check which skills still let one agent drive end to end, since those are candidates for deterministic steps with agents as tools.
