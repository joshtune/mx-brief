How I Get Claude To Edit My Videos (No Code Needed)

Matt Wolfe · 2026-11-04 · 74,635 views  ·  Watch on YouTube →
Using Claude plus MCP to edit short-form video

Off-focus for web app work: it's a video-editing workflow, and the only carryover is the pattern of a prompt, an MCP research tool and an agent producing a draft.

What it is: Matt's workflow for having Claude (Opus 5.5) turn raw talking-head footage into edited short-form videos, with no code. He's posting 1-2 shorts a day and says every Short from the Tesla one onward was AI-edited.

How it works:

  • Give Claude a source link (here the Genie 4 blog post) and optionally a path to your own B-roll on disk
  • Claude calls the vidIQ MCP server to find the best-performing YouTube videos on the topic and read their transcripts
  • From that analysis it writes a script and a predicted performance score (8/10 in the example) plus editing notes
  • Matt treats the script as a talking-points guideline, never reading it word for word, because AI scripts still read as AI
  • He records A-roll off that guideline, leaving in pauses, repeats and mistakes
  • He hands the raw footage back to Claude, which cuts the dead air and repeats (the transcript cuts off here, so the Premiere Pro handoff and final render steps aren't covered)
  • He says Codex and ChatGPT models work too

Tools & links:

  • vidIQ — YouTube analytics with an MCP server for researching top-performing videos (sponsor link)
  • Claude (Opus 5.5) — the agent doing research, scripting and editing
  • Adobe Premiere Pro — named in the tags, but the transcript we have doesn't reach the part where it's used

Why it matters for you: Not much for building web apps. The one thing worth stealing is the pattern: feed an agent a source URL, let an MCP tool do the research, then have it draft the artifact. Skip unless you also make video content.
