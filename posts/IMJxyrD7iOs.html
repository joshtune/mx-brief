3 New PCs, One Giant AI Model… This Shouldn’t Work

Alex Ziskind · 2026-06-23 · 106,940 views  ·  Watch on YouTube →
Clustering three Intel mini PCs to run a 70B model.

If you're weighing mini PCs against a Mac mini for local AI, this shows the new ASUS NUC 16 Pro's price and specs head-to-head.

What it is: Alex clusters three ASUS NUC 16 Pro mini PCs (Intel Panther Lake) to run a single 70B LLM that none of them can hold alone.

The machines (your focus):

  • ASUS NUC 16 Pro — Intel's newest Panther Lake silicon: new CPU, Arc B390 GPU, plus a dedicated NPU (AI engine)
  • CPU options: Core Ultra 5 325/559, Core Ultra 7 356, up to Core Ultra X7 358H (his units); maxes out at Core Ultra X9
  • His config: 64GB RAM. A 32GB version on Newegg is already $1,700 — so the high-end ones run well above that
  • Sized vs Mac mini: shorter, narrower, slightly longer — roughly Mac mini footprint

Price vs Mac mini (the comparison you want):

  • One 32GB NUC 16 Pro ≈ $1,700; his 64GB X7 units cost more
  • That's notably pricier than a base Mac mini — you're paying for upgradeable RAM, dual Thunderbolt, redundant ports, and the NPU

How the cluster works:

  • Three NUCs linked so the 70B model spans all of them — no single machine fits it
  • Uses RDMA over high-speed networking (same approach as his Dell GB10 / DGX Spark and Mac Studio clusters)
  • Lower network latency = faster generation; more machines = faster, generally
  • Dual Thunderbolt on each NUC is the key interconnect (teased as the secret sauce)

Hardware perks:

  • Wi-Fi 7, Bluetooth 6, 2× Thunderbolt, 2× HDMI, 4× USB-A, dual Ethernet, upgradeable RAM
  • Tool-less pull-tab access to internals

Tools & links:

  • Thunderbolt 5 enclosure
  • Internxt 5TB lifetime storage — sponsor, zero-knowledge cloud backup

Why it matters for you: Bottom line — the NUC 16 Pro is a capable local-AI box but costs more than a Mac mini ($1,700+ for 32GB), and a single one still can't run a 70B model without clustering.
