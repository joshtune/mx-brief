224GB of GPU Memory on 1 Desk... This Should Not Work

Alex Ziskind · 2026-08-26 · 76,855 views  ·  Watch on YouTube →
AMD Strix Halo mini PC plus external Nvidia GPU, together.

It's the first mini PC with an OCuLink port, which means a Strix Halo box can now take a real desktop GPU — a very different price/performance story than stacking Mac minis.

What it is: A hands-on test of the GMKtec EVO X3 (AMD Strix Halo, 128GB unified memory) with an RTX 5080 bolted on via OCuLink, then both GPUs driven at once on a single 122B-parameter model.

The machines on the desk:

  • GMKtec EVO X3 — AMD Strix Halo APU (Radeon 8060S iGPU + CPU sharing one memory pool, up to 128GB, most of which can be handed to the GPU). Ships with Windows; Alex dual-boots Linux and reports both GPUs behave identically on either OS.
  • RTX 5080 eGPU — 16GB of very fast VRAM, plugged into the EVO X3's OCuLink port.
  • 224GB total graphics memory across the pair; a $10,000-class GPU test is teased later in the video.

The new trick — OCuLink:

  • A PCIe slot with an external port on the back of the mini PC, ~63 GB/s.
  • Same electrical slot a desktop GPU uses internally — first time a Strix Halo machine can take one.
  • Nobody else in this form factor has it, including Nvidia's DGX Spark.

The numbers that matter:

  • Qwen 2.5 32B on the older EVO X2: ~11 tok/s. On the X3: 11.2 tok/s — same chip, same speed, so the generational bump is the port, not the silicon.
  • RTX 5080 on a model that fits in 16GB: ~3x faster than the built-in 8060S.
  • RTX 5080 on a model that *doesn't* fit: falls off a cliff to ~1.6 tok/s vs 11.2 on the iGPU. VRAM at 100%, GPU pegged, nothing coming out.
  • Both GPUs together on the 122B model: 33–34 tok/s combined, split across AMD and Nvidia. A separate combined run hit 87 tok/s.
  • Runtime note: all tests on llama.cpp, not Ollama — Ollama is measurably slower on this hardware.

Tools & links:

  • GMKtec EVO X3 (Amazon) — the OCuLink Strix Halo mini PC under test
  • llama.cpp — the inference runtime he uses instead of Ollama
  • nvtop — GPU monitor showing both cards spiking during the dual-GPU run

On cost vs. a Mac mini: the video doesn't quote prices in the portion covered here. Rough street ballpark for framing, not from Alex: a 128GB Strix Halo mini PC lands near $2,000, an RTX 5080 adds roughly $1,000+, and an M4 Pro Mac mini tops out at 64GB unified memory for around $2,000 — so the EVO X3 buys you 2x the addressable model size at similar money, plus an upgrade path a Mac mini structurally cannot have.

Why it matters for you: If you're sizing a box to run local LLMs, this is the machine that breaks the Mac mini's memory ceiling *and* lets you bolt on a discrete GPU later — but the 1.6 tok/s cliff is the real lesson: VRAM capacity beats VRAM speed the moment your model doesn't fit.
