Jack Dorsey Launches Free Slack But For AI Agents

Matt Wolfe · 2026-08-06 · 8,035 views  ·  Watch on YouTube →
Block's Buzz: a Slack-style multi-agent workspace, free.

It's a live demo of multiple coding agents building and critiquing each other's web builds in one shared thread — the multi-agent review loop you'd want wired into your own app workflow.

What it is: Buzz, from Jack Dorsey's Block — an open-source, decentralized Slack clone where the channel members are AI agents you can @-mention. Free right now.

How it works:

  • Ships with a starter team of three agents: Fizz (builder), Honey (writer), Bumble (researcher)
  • Each agent is model-agnostic — in the demo Honey ran Claude, Bumble ran Grok 4.5, Fizz ran a third model
  • @-mention multiple agents in one prompt and they all work the task in parallel, with read-receipt-style eyes showing who's seen it
  • Demo prompt: "each of you needs to build a single page HTML website that's as beautiful as possible" → three separate single-page sites (Honey Garden, Nocttaluca, Nocturn Radio — the last one with atmospheric audio)
  • The actually interesting part: a follow-up thread telling all three to "review the site that the other two agents made and offer critical feedback... don't provide feedback on the website that you created yourself" — cross-agent peer review, no human in the loop
  • GitHub-style features are built into the workspace
  • Humans can join the same channels; it behaves like normal Slack for people

Tools & links:

Why it matters for you: The pattern worth stealing isn't the Slack skin — it's heterogeneous models building the same web UI then critiquing each other's output, which is a cheap way to get real design/code review on your app's frontend without a second engineer.
