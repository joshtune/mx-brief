Complete Guide to ChatGPT 5.6 + Prompting Guide

Matt Wolfe · 2026-07-15 · 36,819 views  ·  Watch on YouTube →
Tour of the new all-in-one ChatGPT 5.6 app.

OpenAI folded Codex, a browser, hosting, and scheduled agents into one app — several of which overlap with tools you currently stitch together to build web apps.

What it is: A sponsored walkthrough of the rebuilt ChatGPT app, which mashes ChatGPT, Codex, the OpenAI browser, and the new "work" platform into a single product around the 5.6 model.

How it works:

  • Codex mode — dev-focused surface: write/prompt code, review diffs, fix bugs, explore a codebase. Reachable from the top-left dropdown.
  • ChatGPT Work — agentic assistant for non-devs; connects to your tools and executes actions on your behalf.
  • Sites — one-click hosting for a site/app/game. No web host, DB, or CDN to wire up; it goes live with a shareable public URL, hosted by OpenAI.
  • Built-in browser — navigate anywhere; an annotate feature lets you select a page region and describe a change ("add more green here") and it maps the instruction to the exact element/code with no extra context.
  • Cookie/password import — pull creds from Chrome so the agent can log into sites and act as you.
  • Scheduled tasks — cron-style prompts that run hourly/daily on autopilot (clean downloads folder, daily calendar+email brief, follow-up monitoring).
  • Side chat — a docked chat pane you keep open while Codex builds a feature, so you can ask questions without breaking flow.
  • Sponsor disclosure: video is paid by OpenAI (creator claims editorial honesty).
