I Gave Local AI and the Cloud the Exact Same Job

Alex Ziskind · 2026-08-31 · 512,309 views  ·  Watch on YouTube →
Four clustered Mac Studios vs. a $10/mo cloud agent.

This is the hardware math you actually want: a $60K four-node 512GB Mac Studio cluster (2TB unified memory) benchmarked head-to-head against a cloud subscription — the clearest read yet on what buying local silicon actually gets you over renting.

What it is: Round two of Alex's local-vs-cloud death match — four 512GB Mac Studios wired into a 2TB unified-memory cluster running Kimi K3, against Abacus AI's cloud "Supercomputer" agent, both handed an identical front-end build prompt.

The hardware (the part you care about):

  • 4× Mac Studio, 512GB each = 2TB unified memory, ~$60,000 total. That's roughly $15K per node — versus a base Mac mini at a few hundred bucks, or a maxed mini in the low thousands.
  • Interconnect: Thunderbolt 5 mesh, 6 cables, every machine wired to every other machine. No switch, no InfiniBand. Running RDMA over it.
  • Software stack: MLX distributed for tensor parallelism across nodes.
  • Live memory split during the run: 208GB / ~200GB / 177GB / 215GB across the four Studios.

Why four and not three:

  • Kimi K3 is 2.8 trillion parameters, 1.56TB on disk at original 8-bit precision. Doesn't fit on one Studio at Q4 or even Q2.
  • Alex runs a smaller quantization but unpruned — all 896 experts, ~817GB of weights on disk.
  • Two nodes *looks* like enough (2×512 = 1TB > 817GB) but large context blows past that.
  • Hard constraint: tensor parallelism splits model dimensions evenly, so node count must be 1, 2, 4, or 8. Three is not an option.

The cloud contender:

  • Abacus AI Supercomputer (sponsor) — an always-on virtual machine, not a chat box. No cold start, no container provisioning. Scheduled tasks, databases, storage, GitHub integration, SSH.
  • One login, 100+ frontier models: GPT 5.6 Soul, Claude Fable 5, Grok 4.5, Llama 2.5, DeepSeek V4 Flash/Pro, GLM 5.2, and Kimi K3 itself. RouteLLM picks per context.
  • Hermes agent runs server-side — nothing installed locally.
  • Alex ran the test with Opus 5 High and GPT 5.6 Soul.

The task: identical extensive prompt — TypeScript front end for a "silicon compute exchange," mock data, dark mode, microinteractions, accessibility, unit tests, and agentic self-verification (the model runs commands to validate its own work).

Tools & links:

  • Abacus AI Supercomputer — always-on cloud VM + multi-model agent (sponsor)
  • MLX distributed — Apple's framework doing the tensor-parallel split across the four Studios
  • Prompt is published as a GitHub gist; the Thunderbolt 5 mesh build has its own prior video (both linked in the description, not spelled out in the transcript)

Why it matters for you: The cost delta is brutal and clean — $60,000 of Mac Studio versus $10/month — and the real takeaway is that fitting a frontier-class model locally isn't a mini-vs-Studio spec question at all, it's a "do you have 2TB of unified memory and a Thunderbolt mesh" question, which puts models like Kimi K3 categorically out of reach for any single-box Mac mini setup.
