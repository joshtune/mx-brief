GPT-6.2 Astra is over 7x cheaper than Fable 5.2

Nate Herk | AI Automation · 2026-11-18 · 23,548 views  ·  Watch on YouTube →
Fable 5.2 vs GPT-6.2 Astra on 12 real business projects

If you're picking a coding agent for real business work, this gives you a cost/time/quality scorecard plus Nate's practical play: use the expensive model to build skills, the cheap one to run them.

What it is: Nate runs a head-to-head bake-off of Fable 5.2 (in Claude Code) vs GPT-6.2 Astra (in Codex) on 12 real projects from his own business, with identical prompts and effort settings while tracking every dollar and minute.

How it works:

  • Setup: Fable 5.2 runs in Claude Code and GPT-6.2 Astra runs in Codex. Each gets the same prompt at the same effort level, with cost and time logged per task.
  • Web design: Astra wins with a cleaner site for about $2.50. Fable's cost is garbled in the transcript, so check the video for the exact figure.
  • Canva painting task: Astra hit the stroke limit, exported the painting, and kept going on a fresh canvas. Fable stopped after running for about 3 hours.
  • YouTube video edit: Fable wins. It used Nate's actual editing skill, while Astra ignored the skill and invented its own style.
  • Other Fable wins: the 3D game, the financial model, and the trip plan.
  • Final score: Fable 7, Astra 5.
  • Cost and time: Fable cost about 7x more and ran almost 5x longer.
  • Pricing: Both models charge the same price per token. The gap comes from Fable burning far more tokens and time, not from a higher rate.
  • Takeaway workflow: Let Fable solve the hard problem once, have it package the solution as a reusable skill, then let Astra run that skill cheaply.

Tools & links:

  • Claude Code, running Fable 5.2 — Anthropic's agentic coding CLI, used for Fable's runs
  • Codex, running GPT-6.2 Astra — OpenAI's coding agent, used for Astra's runs
  • Canva — design task target; its stroke limit tripped up the agents
  • Skills (Claude Code skills) — reusable instruction packages, such as Nate's video-editing skill, that Fable followed and Astra ignored
  • No repos or URLs are given in the transcript or description. Check the video description or Nate's channel for project files.

Why it matters for you: The playbook is a two-tier setup. Use the premium model to discover and codify a workflow as a skill, then run it on the cheaper model. That should cut cost without giving up much quality, but expect Astra to ignore skills in some cases, so verify its output.
