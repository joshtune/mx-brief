8 DGX Spark Cluster with this Switch

Alex Ziskind · 2026-09-10 · 17,625 views  ·  Watch on YouTube →
Eight DGX Sparks clustered into ~1TB VRAM

Shows what a $30k+ DGX Spark cluster actually buys you over a single box — and the answer is 'less than you'd hope,' which is exactly the data point you need before comparing against a Mac mini.

What it is: Alex wires eight NVIDIA DGX Sparks together over a 400Gbps switch to pool ~1TB of unified memory for LLM inference.

The machine:

  • 8× NVIDIA DGX Spark (GB10, 128GB unified memory each, ~$4,000 each → ~$32,000 in compute alone)
  • Rebadged variants shown: MSI EdgeExpert and ASUS GX10 (same GB10 silicon)
  • Switch: 4-port 400Gbps half-rack, $1,300 — double-density so it exposes 8 interfaces, one per Spark
  • Each port needed manual tuning: auto-negotiation off, rate 100, FEC 91

Results:

  • Qwen VL 32B Instruct at ~17 tokens/sec (TG32) via llama-bench
  • ~110GB of 119GB used per node
  • Alex's own verdict: going from 4 to 8 nodes gives 'not that great' a gain — interconnect overhead eats the scaling

Tools & links:

  • 2-port 400Gbps switch — cheaper option if you only need two nodes
  • 4-port 400Gbps switch — the one used here, $1,300
  • MSI EdgeExpert — DGX Spark clone
  • ASUS GX10 — DGX Spark clone

Mac mini comparison:

  • Cluster total: ~$33,000+ for 1TB pooled memory, 17 tok/s on a 32B model
  • A single M4 Pro Mac mini with 64GB is ~$2,000 and runs 32B quantized models locally at roughly comparable single-stream speeds — you just can't fit the 400B-class models this cluster is aimed at
  • A Mac Studio M3 Ultra with 512GB (~$10,000) gets you half the memory for a third of the price with zero networking headaches

Why it matters for you: The DGX Spark cluster is a $33k science project with diminishing returns past 4 nodes; unless you need >500GB of model in memory, a Mac mini or Studio is the saner buy.
