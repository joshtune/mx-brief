Codex Can Now "Copy" Your Tasks

Matt Wolfe · 2026-06-23 · 73,816 views  ·  Watch on YouTube →
OpenAI Codex records your screen, replays repetitive tasks.

If you keep doing the same manual web-app chores by hand, Codex can now watch you once and automate the whole flow afterward.

What it is: OpenAI shipped "Record and Replay" for Codex — record yourself doing a task once, and Codex turns it into a reusable skill it can run on command.

How it works:

  • You record your screen performing a task (the demo: uploading a YouTube video).
  • Codex watches the recording, learns the exact steps, and saves them as a named "skill."
  • Later you drop in new inputs (e.g. a video file, thumbnail PNG, subtitle file) and say "do this with the YouTube upload skill."
  • It replays the steps: selects/uploads the file, attaches the thumbnail and subtitles, sets visibility to private — autonomously.

Tools & links:

  • OpenAI Codex — the agent gaining the Record and Replay feature
  • futuretools.io — Wolfe's AI tool directory

Why it matters for you: Record-once-replay automation could kill the repetitive GUI grunt work around your web apps — deploys, dashboard clicks, content uploads — without you scripting each one by hand.

Caveat: This is a short hype recap of a single demo, not a hands-on test — no detail yet on reliability, dynamic UIs, or how brittle the replays are.
