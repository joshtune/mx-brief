This AI Creates Insane 3D Worlds

Matt Wolfe · 2026-08-24 · 19,448 views  ·  Watch on YouTube →
Tencent's WorldClaw generates editable 3D worlds from prompts.

Skip it unless you build 3D/WebGL — this is a no-access research demo with zero bearing on web app work.

What it is: Tencent's new WorldClaw model turns a text prompt into a full 3D scene where every object is a separate, editable asset — not a baked mesh, not a splat.

How it works:

  • Prompt in ("a snowline village", "a desert battle scene") → full environment out
  • Trees, houses, carts, lamp posts, terrain all generated as individual assets, not one fused blob
  • Pipeline per the video: GPT Image 2 generates the 2D images → Segment Anything (SAM) cuts out each object → Hunyuan 3D converts each 2D cutout into a 3D asset
  • Ships auxiliary outputs alongside the geometry: depth map, normal map, instance map
  • Explicitly *not* Gaussian splatting or NeRF — it's real separable geometry, which is why it's editable
  • Stated use case: generating virtual environments to train robots across many scenarios before real-world deployment

Availability: No public access. Matt has not used it — this is a "look at this cool thing" segment based on demos, not a hands-on review.

Tools & links:

  • Tencent Hunyuan 3D — the underlying 2D→3D model this builds on; that part *is* publicly usable
  • Segment Anything (Meta) — the segmentation step in the pipeline
  • futuretools.io — Matt's AI tool directory

Why it matters for you: Essentially nothing here touches web app development — the one transferable idea is the pipeline pattern (generate → segment → transform per-object) if you ever need structured, individually-addressable output instead of one monolithic asset from a generative model.
