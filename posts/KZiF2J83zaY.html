Sponsored demo of Kylon, a shared workspace for humans and agents

If your team runs separate Claude Code and Codex setups and keeps duplicating integrations and skills, this shows a Slack-style shared workspace where humans and agents work in the same channels.

What it is: A sponsored walkthrough of Kylon, a Slack-meets-ClickUp workspace where several people and their AI agents collaborate in shared channels. Nate argues that team AI is moving from "single player" to "multiplayer".

Caveat: The transcript I had cuts off after the intro and context-setting. It never reaches the actual build steps, so the setup walkthrough below is not covered here.

How it works (from the demo shown in the intro):

  • Interface: Slack-style layout with channels on the left and chat on the right. Nate's demo channel is called "AIS Media".
  • Shared agent: Nate, Cody and Aiden all talk to one agent ("Herk") in the same channel at the same time. They build apps, automations, files and knowledge together.
  • Bring your own subscriptions: Each person plugs in their own Claude Code and Codex subscriptions as agents. The agents list shows a "head of agents" plus Nate's and Aiden's Claude Code and Codex agents alongside the human users.
  • Example build: Nate had the Herk agent build a dashboard. He then brought in his own Claude Code agent to restyle it to match the AIS brand.
  • Agent-to-agent chat: Agents message each other proactively. His Claude Code agent and Herk went back and forth on the work without him in the loop.
  • Per-channel assets: Each channel has its own apps (the dashboard), automations (a check-in) and files. Files are either agent-generated or user-uploaded.

The problem it targets:

  • Today's setup: Everyone builds a personal AI operating system ("second brain") on Claude Code, Codex, Hermes and similar tools. Each one is wired to Slack, ClickUp, Gmail, Notion, Skool and so on.
  • What goes wrong: Skills, memory and connected accounts belong to individuals. Teammates rebuild the same integrations and duplicate work. Shared tools like Drive and ClickUp end up as the only source of truth.
  • The pitch: One team-level workspace where everyone builds and talks to the same agents, and the agents talk to each other.
