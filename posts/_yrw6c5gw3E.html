M5 Ultra vs 2 DGX Sparks… The Number You're Not Looking At

Alex Ziskind · 2026-10-01 · 332,620 views  ·  Watch on YouTube →
M5 Ultra Mac Studio vs dual DGX Spark for local LLMs

It tells you exactly which machines Alex runs big local AI models on and what they cost, with the Mac side priced at $14K, so you can sanity-check it against a Mac mini without sitting through the benchmark weeds.

What it is: Head-to-head of a 256 GB M5 Ultra Mac Studio against two clustered NVIDIA DGX Sparks (also 256 GB total) running big local LLMs.

The machines & what they cost:

  • Mac Studio M5 Ultra — 256 GB unified memory, 8 TB SSD, configured at $14,000. One box, loads the whole model.
  • 2x NVIDIA DGX Spark — 128 GB each (256 GB total), 4 TB each (8 TB total). Launched at ~$4K each, now almost $5K each, ~$10K for the pair, plus the pricey QSFP cable.
  • Link — one 200 Gb QSFP cable running RoCE (RDMA over Converged Ethernet), so the Sparks can write directly into each other's memory.
  • Mac mini comparison: the transcript excerpt never prices a Mac mini. Both rigs here are in the $10-14K league, a different tier from a mini. Treat any mini comparison as your own back-of-napkin math.

How it works:

  • Headline result: both generated exactly 800 tokens. The M5 Ultra did 38.7 tok/s and the dual Spark cluster did 34.3 tok/s, so basically neck and neck. Alex says this is the closest they get for the rest of the video.
  • Why two Sparks: DeepSeek V4 Flash is ~150-160 GB, so it won't fit on one 128 GB Spark. Split across two, each node holds ~111 GB.
  • Split method: vLLM with tensor parallel. Every layer is cut in half, and the boxes swap results over the cable on every token. That's a lot of chatter.
  • Same model, different files: both run 4-bit quantized builds, but not the identical file.
  • Software: Sparks run vLLM (llama.cpp also works). The Mac was tested with both llama.cpp and MLX, and the winner varies.
  • Models tested: DeepSeek V4 Flash and Qwen 3.8 Flash Next, which also needs two Sparks.
  • Cut off: the transcript ends before the actual 'number you're not looking at' from the title, so the real verdict isn't in the excerpt. The description hints the M5 Ultra 'needs something from you before it really pulls ahead'.

Tools & links:

  • Merlin AI — sponsor, all-in-one ChatGPT/Claude/Gemini access, code ALX5, ~$60/yr
  • vLLM — high-throughput inference/serving engine, used for the Spark cluster (no URL given in the transcript)
  • llama.cpp and MLX — local inference engines used on the Mac (no URLs given in the transcript)

Why it matters for you: If you're pricing local AI hardware, this puts the ceiling at $10-14K for 256 GB, which is far above Mac mini money. Only worry about it if you need to run 150 GB+ models.
