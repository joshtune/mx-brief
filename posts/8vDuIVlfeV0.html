Apple’s Hidden AI Model… The Speed Test Apple Never Showed

Alex Ziskind · 2026-07-10 · 56,959 views  ·  Watch on YouTube →
Benchmarking macOS 27's hidden local AI model on Apple hardware.

It answers whether a $10K Mac Studio actually runs Apple's built-in local LLM faster than a Mac Mini — the exact price-vs-performance question you care about.

What it is: macOS 27 ("Golden Gate") ships a hidden built-in CLI called `fm` that runs an Apple LLM locally in your terminal — no Ollama, LM Studio, or MLX install needed. It's a free, private, on-device AI endpoint you can script against.

How it works:

  • `fm` has two backends: a local model running on your Mac's silicon, and an Apple cloud model ("Private Cloud Compute"). You choose which per call.
  • The cloud model ran ~3x faster than local — but the local one is the one that actually stresses your hardware.
  • Off-the-shelf benchmarks choke on it: Apple's server isn't fully OpenAI-compatible, so tools like Llama-bench spat out garbage (600,000 tok/s prompt processing — a clear artifact), forcing Alex to build his own harness, Apple FM Bench.

Hardware tested (your focus):

  • Mac Mini (upgraded to the macOS 27 beta) — local model: ~50 tok/s prompt processing, ~52 tok/s decode/generation.
  • M3 Ultra Mac Studio — the ~$10,000 machine, brought in to test whether throwing expensive hardware at the local model makes it meaningfully faster. (Transcript cuts off before the head-to-head verdict — the payoff numbers are in the full video.)
