Sonnet 5.5 vs Opus 5.5: which model, when

Nate runs identical real-world prompts (a landing page first) through both models at high effort and compares speed, tokens and dollar cost, so you can pick a model per skill instead of guessing.

What it is: A blind head-to-head of Sonnet 5.5 and Opus 5.5 on Nate's actual workflows, with speed, token and cost comparisons. The transcript cuts off during the first demo, so only that demo and the framing are covered here.

How it works:

  • Pricing baseline: Sonnet 5.5 is $2 per million input tokens and $10 per million output tokens. Opus 5.5 is $4 in and $20 out, so Opus costs about 2x. The question is whether Opus delivers 2x the quality.
  • Sonnet 5.5 vs Sonnet 5: Nate claims about 30% faster and about 30% cheaper for most work.
  • Test setup: Every session got the exact same prompt, and both models ran at high effort. Results are shown blind, with the model reveal saved for the end.
  • Workflows tested (per intro): building websites, messy data into spreadsheets, Excel with multiple views and per-cell formulas, motion design and video editing, interactive dashboards with real-time data syncing, and project management and planning.
  • Demo 1, landing page for a fictional drink brand "Perk Form":
  • The prompt asked for an engaging, immersive, high-converting landing page and allowed an image generation tool (said as "key.ai").
  • Nate had to correct the model's spelling of the tool name, and says he'll add it as a correction in his dictation app (Glido, as transcribed).
  • Output A had a hero can that tracks the mouse and rotates on click-drag, with text in the background.
  • Output A also had in-hero flavor switching, and a scroll-driven story: two drinks (coffee and protein) merge into one can, a gym bag/phone/keys scene with a time-lapse, then three flavors (salted caramel, vanilla latte, bold mocha).
  • Nate's critique of A: the can is a 3D approximation, not pixel-accurate to the real product. He still likes the effect.
  • Output B is calmer and has less wow factor at first load. The transcript ends before the rest of B's review and the reveal.
  • Anthropic's own routing guide (as Nate reads it):
  • Sonnet: well-scoped everyday coding, bug fixes, high-volume dev, and polished docs, slides, spreadsheets and one-pagers.
  • Opus: complex work needing careful judgment, long-horizon agentic coding and knowledge work, and the hardest problems.
  • Nate's heuristic: if a task has a clear spec and an objective way to check it's done, try Sonnet 5.5 first. If you need a creative thought partner to define what "done" means, use Opus.
  • Workflow tip: run each of your skills on both models, note which wins, and record that per skill.
