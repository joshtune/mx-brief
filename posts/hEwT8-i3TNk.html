GB10 Dgx Spark 2 Node Cluster From Scratch

Alex Ziskind · 2026-09-04 · 15,483 views  ·  Watch on YouTube →
Clustering two Dell DGX Spark boxes for LLM inference.

If you're weighing a Mac mini against Nvidia's desktop AI box, this shows what two ~$4k GB10 machines actually get you when chained together: ~218 GB of pooled memory running vLLM.

What it is: Alex links two Dell GB10 (DGX Spark) machines into a two-node cluster and runs vLLM inference across both.

The hardware (what you actually care about):

  • Two Dell DGX Spark units, Nvidia GB10 Grace Blackwell chips, 128 GB unified memory each
  • Clustered, the software reports ~218 GB of usable memory across both nodes
  • Linked over 400 Gbps networking via a 2-port or 4-port 400 Gbps switch (not cheap, and not optional for this setup)
  • Driven from a MacBook; the Sparks are headless and controlled remotely

How it works:

  • Boot both Sparks, sit through a long round of firmware/OS updates first
  • Install Nvidia Sync on the controlling machine (any laptop works) and follow the "Connect two Sparks" use case in the docs
  • Nvidia claims the pairing takes about an hour; Alex says it took him closer to 6 to 12 hours in practice
  • Once paired, load a model with vLLM and prompt it; both GPUs light up to ~93-94% utilization on a small test model

Cost vs Mac mini (prices not in the transcript, approximate street pricing):

  • DGX Spark: roughly $3,000-$4,000 per box depending on vendor (Dell, ASUS GX10, MSI EdgeExpert, Nvidia Founders). Two of them plus a 400 Gbps switch lands you around $8,000-$10,000 all in
  • Mac mini M4 Pro with 64 GB: about $2,000. Cheaper, but 64 GB caps your model size well below one Spark
  • Mac Studio M3 Ultra with 512 GB: about $9,500. Comparable spend to the two-Spark cluster, more memory in one box, no cluster setup pain, but slower raw GPU compute and no CUDA
  • The Spark pitch is CUDA plus Blackwell compute. The Mac pitch is one box, one plug, no 6-12 hour pairing session

Tools & links:

  • 2-port 400 Gbps switch — the interconnect between nodes
  • 4-port 400 Gbps switch — if you want to scale past two
  • MSI EdgeExpert — another GB10 vendor
  • ASUS GX10 — another GB10 vendor
  • DGX Spark — Nvidia's own unit
  • Nvidia Sync — the pairing/management tool, linked from Nvidia's DGX Spark first-boot docs
  • vLLM — the inference server used for the multi-node test

Why it matters for you: Two Sparks buy you ~218 GB and CUDA for roughly Mac Studio Ultra money, but the setup tax is real; a single Mac mini is not in the same weight class on memory, and a single Spark is the honest comparison point.
