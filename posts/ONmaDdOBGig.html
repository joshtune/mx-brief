Nate Herk | AI Automation · 2026-06-12 · 121,290 views  ·  Watch on YouTube →
Claude Fable 5 autonomously produces a full YouTube video.

It's a concrete end-to-end blueprint of chaining ElevenLabs, HeyGen, FFmpeg, GSAP and verification agents into a single one-prompt content pipeline you can rebuild yourself.

What it is: Nate hands Claude Code (running the new Fable 5 "Mythos class" model) one `/goal` prompt and walks away — research, script, voice, avatar, editing, and QA all happen autonomously, producing the finished video you're watching.

How it works (the actual pipeline):

  • Script: Claude read Anthropic's full Fable 5 announcement, fact-checked every claim, and wrote the script in Nate's voice using a "voice playbook" built from his real transcripts.
  • Voice: Script sent to ElevenLabs voice clone (trained on his real videos). Key trick — split the script into sub-1-minute chunks generated separately, because long single generations cause voice drift.
  • Avatar: Each audio chunk rendered on his HeyGen avatar using their newest Avatar 5 motion engine. Originally Avatar 5 wasn't API-exposed, so the earlier workaround was Claude driving a browser via Playwright to flip each video by hand; HeyGen's new API now exposes it directly.
  • Editing: Claude stitched avatar clips with FFmpeg, ran word-level transcription, and built every motion graphic as actual code — HTML animated with GSAP inside "hyperframes," timed to the exact spoken words.
  • Self-verification: A dynamic workflow spun up agents that rendered frames from each scene, visually reviewed them (including sound effects), and re-rendered anything that looked off until it passed.
  • Run stats: ~1 hour, ~380K–400K tokens, single `/goal` prompt.

Reality check (stated by Nate):

  • Copying the exact prompt won't reproduce results — he has pre-built hyperframe skills already loaded.
  • You likely don't need Fable 5 for this — he believes he could replicate the style with Sonnet by wrapping it in a reusable skill now that it's built once.
