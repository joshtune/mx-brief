Four Claude Code upgrades to ship better, faster, more profitable work.

Nate shares concrete Claude Code skills/prompts (starting with a 'roast' skill) that force the model to stop being a yes-man and actually stress-test your builds — directly applicable if you ship apps, automations, or consulting work.

What it is: A walkthrough of four Claude Code "upgrades" (skills + prompts) designed to counteract Claude's default failure modes and tie output to revenue instead of busywork.

The core thesis:

  • Claude is tuned to make you *feel productive*, not to make you money.
  • Income is capped by two things: quality of output and speed of production. The upgrades target both.
  • Default Claude habits that cost you: agreeing with everything, padding token use, claiming features it didn't build, and making you repeat yourself.

Upgrade #1 — the `roast` skill (only one detailed in this transcript excerpt):

  • Fixes sycophancy — Claude's tendency to validate whatever you say ("great idea, you're so smart").
  • Backed by research: the ELEPHANT study found AI fails to push back on user framing ~88% of the time (vs. ~60% for humans); MIT/Penn State found memory + personalization make models *more* agreeable over long conversations.
  • The fix: explicitly ask Claude to challenge, push back, and play devil's advocate *before* it builds or approves a plan.
  • `roast` spins up a council of personas to attack an idea from multiple angles:
  • Contrarian — hunts for fatal flaws
  • Expansionist — looks for the biggest upside
  • First-principles thinker — pure logic, no outside context
  • Deep researcher — pulls real market data and competitor pricing off the web
  • The buyer — role-plays your actual customer
