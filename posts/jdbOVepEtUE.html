What it is: A 6-hour beginner-to-"AI native" course teaching non-coders to build automations and AI agents entirely through Claude Code — no coding required.

How it works:

  • Frames Anthropic's ecosystem as three products you talk to in plain chat: Claude Chat (chatbot/search-style Q&A, Gmail drafts — not real agentic work), Claude Co-work (simpler interface for knowledge workers/managers doing lighter automations), and Claude Code (the most powerful, agentic tier Nate actually uses).
  • Fun fact he drops: Claude Co-work itself was built *with* Claude Code by a few engineers in ~a week — work that would've taken a larger team weeks.
  • Key mental model: skills transfer across all three products, so pick the most powerful (Claude Code) without feeling locked in.
  • Why Claude Code is different: it can access your local files (pick a folder — desktop, downloads, or his "Herk 2" AI operating system) *and* reach anything online — Gmail, Slack, CRM. Claude Chat can't touch local files.
  • Clarifies the intimidation factor: the word "code" just means Anthropic exposed the raw agentic power; you still drive it by talking in chat.
  • Claude Code runs the same models as Claude Chat — Opus, Sonnet, Haiku, Fable — you choose per task.
  • Teased follow-up: a full course on building your own "AI operating system" on top of Claude Code.
  • Course is modular — skip around by topic, with real step-by-step builds throughout.
