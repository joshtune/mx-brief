AMD Says 2 Ryzen AI Halos Can Run a 400B Model... I Tested It

Alex Ziskind · 2026-07-26 · 235,111 views  ·  Watch on YouTube →
Clustering two AMD Ryzen AI Halo boxes over Ethernet.

It's the closest head-to-head you'll get on whether stacking two 128GB AMD mini-boxes beats buying one big-memory Mac for local LLM work — and the transcript excerpt cuts off before the actual verdict.

What it is: Alex takes two AMD Ryzen AI Halo mini-PCs (Strix Halo APU, 128GB unified memory each) and clusters them over 10GbE to test AMD's claim that the pair can run ~400B-parameter models.

The hardware in play:

  • AMD Ryzen AI Halo mini-PC — APU (CPU + GPU on one die) with 128GB shared memory; AMD claims up to ~200B params on a single box
  • Two clustered = 256GB pooled (minus OS overhead, so realistically less)
  • Sold exclusively through Micro Center — Alex doesn't state a price in this excerpt
  • Compared in his *previous* video against the NVIDIA DGX Spark — that's the video to watch for the raw benchmark numbers

The catch nobody mentions:

  • Two machines don't become one machine — the model must be split across both, and the GPUs exchange data continuously during generation
  • The only interconnect is a single 10-gigabit Ethernet port per box
  • You cannot just run a cable between the two. AMD's own playbooks require a 10GbE switch in the middle
  • So the real bill of materials is: 2× Halo boxes + a 10GbE switch

Two clustering methods (both from AMD's playbooks):

  • llama.cpp + RPC — remote procedure call, built into llama.cpp. This is the same engine under Ollama and LM Studio, so it's the low-friction path
  • RCCL ("rickel") + vLLM + Ray — AMD's answer to NVIDIA's NCCL; does proper tensor parallelism to split the model across GPUs. Heavier setup, better theoretical throughput

The switch he used:

  • UniFi Flex XG — 4× 10GbE ports + 1× 1GbE uplink. The four 10G ports handle up to a 4-node cluster; the 1G port is your management/network link
  • Fanless — completely silent, which matters if this lives on your desk

Tools & links:

  • llama.cpp — the inference engine (RPC mode enables cluster splitting)
  • vLLM — high-throughput serving with tensor parallelism
  • Ray — distributed orchestration layer vLLM uses for multi-node
  • RCCL — AMD's collective comms library (NCCL equivalent)
  • Micro Center affiliate link: https://micro.center/ef6aec

Why it matters for you: If you're weighing a Mac mini/Studio against local-AI hardware, the honest cost of the AMD route is *two* boxes plus a 10GbE switch — and the open question is whether Ethernet-speed interconnect kills the throughput advantage of that 256GB pool versus a single Mac with unified memory and no network hop.
