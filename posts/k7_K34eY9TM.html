NVIDIA, It’s Happening Again

Alex Ziskind · 2026-11-10 · 252,221 views  ·  Watch on YouTube →
GMKtec EVO X5 Pro vs two NVIDIA DGX Sparks

One $7K mini PC with 192GB of memory might replace $14K of DGX Sparks for running huge local models, and that's the whole answer you asked for.

What it is: Alex pits the GMKtec EVO X5 Pro (AMD Ryzen AI Max+ Pro 495, 'Gorgon Halo') against NVIDIA's DGX Spark to see if one box can run models too big for a single Spark.

How it works:

  • The AI machine: GMKtec EVO X5 Pro, 192GB unified memory, running Linux (stock out-of-box setup can't give the GPU enough memory for the big model, so he walks through the fix)
  • The test: GLM 5.3 (157GB, too big for one Spark), plus several models loaded at once, multiple coding agents running real tools, and ~250K tokens of context
  • Why people buy 2+ Sparks: the models they want don't fit in one box's memory, so they link them together
  • Memory bandwidth: effectively a tie. Spec is 273 GB/s for both, measured GPU-side 246 GB/s (GMK) vs 248 GB/s (Spark)
  • CPU bonus: 16 x86 cores beat the Spark's 20 ARM cores. Linux kernel build took 54s vs 66s (~22% faster), and 7-Zip scored ~18% higher
  • The transcript cuts off before the final LLM results, so the verdict on speed and the Linux fix details aren't covered here

Cost comparison (from the video):

  • GMKtec EVO X5 Pro, 192GB / 4TB: ~$7,000 (the 2TB version is $6,800)
  • Two DGX Sparks: almost $14,000
  • One DGX Spark: about $150 less than the GMK, so roughly $6,850, with 128GB of memory
  • Cost per GB of memory: $37 (GMK) vs $54 (Spark)
  • Mac mini: not mentioned in this part of the video, so no direct price comparison is given
