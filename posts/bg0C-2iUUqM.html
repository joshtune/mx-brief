I Tested Claude Code vs. Codex on Design. It Wasn't Even Close.

Nate Herk | AI Automation · 2026-08-26 · 47,780 views  ·  Watch on YouTube →
Claude Code vs Codex head-to-head on eight website builds

Hard cost/time/token numbers from eight controlled builds — not vibes — so you can pick the right agent for front-end work.

What it is: A controlled bake-off — Nate had Claude Code and Codex each build the same eight fictional business websites from identical prompts, brand guidelines, logos, and copy, then compared design output alongside build time, subagent count, output tokens, and dollar cost.

How he set it up:

  • Same inputs for both agents: business name, logo, brand guidelines, and source copy — variability stripped out so the only difference is the agent
  • Side-by-side review: Claude Code on the left, Codex on the right, scrolled through page by page
  • Judged on more than the hero section — he clicks into interactive subpages (e.g. the "Build Your Care Box" configurator) to see whether flows actually work
  • Responsive check factored in: he notes output looks different at half-screen vs. full-screen vs. mobile, and that a good agent should be testing those breakpoints itself

Round 1 — "Bowl & Bloom" (postpartum meal delivery):

  • Claude Code: text-heavy hero, long-form "Chapter One / Chapter Two" narrative structure, very wordy, flavors and how-it-works buried far down the page. Care-box configurator worked cleanly — pick items, set quantities, choose delivery date, see price, hit checkout
  • Codex: image-first hero, nav bar, clear CTAs, scroll-progress indicator on the left, horizontal scroll animation for the "first 14 days" story, four core flavors surfaced early (chicken, red lentil, garden greens, miso mushroom)
  • Codex bug: the configurator's visual doesn't sync with quantity — five red lentils selected still renders one tile, one ginger chicken rice still shows four
  • Verdict on round 1: Codex is cleaner and communicates faster, despite the bug

The numbers that actually decide it (Round 1):

  • Subagents: Claude Code 4 vs. Codex 1
  • Wall time: Claude Code 2 hours vs. Codex 50 minutes
  • Output tokens: Claude Code ~500K vs. Codex ~100K
  • Cost: Claude Code $53 vs. Codex ~$20
  • Same information, radically different communication — Claude Code spends 2.5x the time and money to say the same thing more verbosely

Caveats worth noting: n=1 per build with a single human judge, no blind evaluation, and no note on which Claude/Codex models or settings were used — treat this as directional, not benchmark-grade.

Why it matters for you: If you're spinning up agent-built front-ends, the takeaway is concrete — spec your own design hierarchy (nav, CTAs, progressive disclosure) instead of trusting either agent's default, and budget by output tokens, because Claude Code's subagent fan-out is where the 2.5x cost lives.
