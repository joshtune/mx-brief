It Begins... Local AI and the Cloud Start Sharing

Alex Ziskind · 2026-10-20 · 125,283 views  ·  Watch on YouTube →
Perplexity's hybrid compute splits tasks between Mac and cloud

It shows which Mac runs which local model (a 32GB M6 Mac Mini is the entry point for the bigger ones), but the excerpt gives no prices, so skim it.

What it is: A sponsored test of Perplexity Computer's "hybrid compute" mode, where a local model on your Mac keeps private data (bank statements, medical records) on-device and sends only the non-sensitive parts of a task to cloud models.

Machines used (the part you care about):

  • MacBook Air, 16GB — only fits the smallest local model (Gemma 4 E4B)
  • MacBook Pro, 128GB — the top-end box; can run any of the local models
  • M6 Mac Mini, 32GB — the minimum RAM for the two bigger local models (Qwen 3.6 35B and Perplexity's own)
  • Prices: none are stated in the portion of the transcript provided. The transcript cuts off before the per-machine results, so there is no cost comparison against the Mac Mini here. The Mini is one of the three test machines, not the baseline he compares against.

Local orchestrator models and RAM needs:

  • Gemma 4 E4B — open weights, 4-bit, 6.6 GB, needs 16GB RAM
  • Qwen 3.6 35B — open weights, needs 32GB RAM
  • Perplexity's custom model — 19 GB, needs 32GB RAM
  • His rule of thumb: the more capable the machine, the larger the model it can run

How it works:

  • Install the Perplexity Computer Mac app, then turn on Privacy Gate in settings
  • Pick Hybrid in the model picker of a new session. It also lets you choose which local model to use
  • The cloud model orchestrates the task and hands suitable subtasks to the small local model
  • Privacy Gate detects sensitive data automatically, so you don't have to say "keep this on my Mac"
  • Test setup: fake bank statements, internet bills and a service agreement, with planted discrepancies. He also grabbed real papers (vehicle info, address, a medical record, a parking ticket) to see whether any of it leaks
  • The test prompt: match payments to bills and flag charges that don't match the agreed rate. It also needs a web search, which exercises the cloud/local split

Tools & links:

  • Perplexity Hybrid Compute — the sponsor's product, which routes tasks between local and cloud models

Caveat: It's a sponsored video. The transcript excerpt ends before any results, so whether Privacy Gate actually holds up isn't shown here.

Why it matters for you: The takeaway is that 32GB is the floor for the better local models, which is where a Mac Mini fits. Check his on-screen pricing or the video description for actual costs.
