This was a data center a year ago… Now it's on my desk

Alex Ziskind · 2026-08-15 · 86,241 views  ·  Watch on YouTube →
Desk-sized 748GB AI server pushes 2600 tokens/sec.

This is the machine that makes a Mac mini look like a toy — but it's a ~$40K+ class desktop supercomputer, not a $600 box, so it's worth knowing exactly what that money buys.

What it is: The ASUS ExpertCenter Pro ET900N G3 — an NVIDIA DGX Station–class desktop built around a GB300-generation Grace Blackwell superchip, tested as a local AI inference box.

The specs that matter:

  • 748GB unified memory — CPU and GPU share one pool, same architectural idea as Apple Silicon but roughly an order of magnitude larger than a maxed Mac Studio
  • 1400W power draw for the superchip alone — this is a wall-circuit consideration, not a desk gadget
  • 400Gb networking — built for clustering multiple boxes, not just single-node work
  • Price class: DGX Station hardware in this tier lands in the tens of thousands (Alex flags the link as "not affiliate, but I wish"). For comparison: base M4 Mac mini ~$599, 64GB M4 Pro Mac mini ~$2,000, 512GB M3 Ultra Mac Studio ~$9,500

The actual benchmark (Nemotron 12B, concurrent requests):

  • 1 user → ~180 tok/s
  • 2 users → ~250 tok/s
  • 4 users → ~300 tok/s
  • 8 users → ~400 tok/s
  • 16 users → keeps scaling linearly
  • 64 users → ~1,500 tok/s
  • 128 users → ~2,600 tok/s aggregate

The real takeaway: Single-user speed (~180 tok/s) is good but not shocking — a Mac Studio runs a 12B model respectably too. The gap is concurrency. This box doesn't fall over at 128 simultaneous requests; consumer hardware collapses well before that. You're paying for parallel agent throughput and the memory headroom to hold frontier-size models, not for a faster chatbot.

Tools & links:

  • ASUS ExpertCenter Pro ET900N G3 / DGX Station — the machine under test
  • 400Gbps switch (B&H) — for clustering multiple units
  • Nemotron 12B — NVIDIA's speed-optimized model used for the benchmark

Why it matters for you: If your question is "what do I buy to run AI locally," this answers the ceiling: a Mac mini/Studio is the sane single-developer choice, and this is what you'd step up to only when you need to serve dozens of concurrent agents — at roughly 20–50× the Mac mini's price and 1400W of power.
