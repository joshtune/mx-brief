Nate Herk | AI Automation · 2026-11-25 · 69,412 views  ·  Watch on YouTube →
Claude chat creations now install as real desktop apps

Nate's usual build-along walkthroughs would show how far 'describe it, get desktop software' actually goes, but this transcript is only the announcement, so treat it as a news brief and not a tutorial.

What it is: Claude Apps, a beta feature that turns anything Claude builds in chat (artifacts) into an installable desktop app on Mac or Windows.

How it works:

  • Ask Claude for a tool in chat. Nate's example is a Pomodoro timer that lives in the menu bar.
  • Claude builds it. Then you right-click and choose Install as app.
  • The app gets its own window and icon. It opens from the Dock or Start menu like any native app.
  • Apps can send notifications, run on keyboard shortcuts, and float over other windows.
  • With your permission, apps can also run programs and change files on your machine.
  • It's rolling out in beta on every plan, including free.

Caveats:

  • No review: Anthropic does not review these apps before you install them. Only grant full access (run programs, edit files) to apps you trust.
  • Thin transcript: It cuts off after the announcement, so there is no build walkthrough, prompt, repo or step-by-step demo to summarize.
