I Cloned Calendly and Now It’s Free Forever

Nate Herk | AI Automation · 2026-08-28 · 33,239 views  ·  Watch on YouTube →
Vibe-coded Calendly clone, self-hosted, free to run

A one-week, few-prompt build that replicates a $3B product's core loop — the setup guide, stack, and real cost breakdown are the useful part, not the demo.

What it is: "Snag Time" — a self-hosted Calendly/cal.com clone Nate built in ~1 week with a handful of AI prompts, given away free via his Skool community.

How it works:

  • Auth + workspaces: Sign-in, a branded workspace (his is "Up at AI"), profile photo/colors/description, invite members with member vs. admin permissions.
  • Dashboard: Upcoming bookings, bookings this month, hours booked, count of published links. Each booking drills into detail with reschedule/cancel.
  • Event types: Multiple bookable types — e.g. "Revenue Strategy Session," "Regular Strategy Call," and a paid scoping session backed by Stripe, so calls can be booked with payment attached.
  • Live Google Calendar sync (the load-bearing part): He demos it both directions — existing calendar blocks (all-morning block, 3–4pm, a 9–11am Monday pair) disappear from the booking page's availability; drop a fresh 1pm–6pm "busy" block on Monday, refresh the public link, and those slots vanish. Confirmed bookings write straight back onto the real calendar with the attendee's email.
  • Booking flow: Public link → date/time picker under your branding → info form (custom questions configurable per event type) → review → confirm → attendee-facing confirmation screen with reschedule/cancel.
  • Deployment: Demo runs entirely on `localhost`. To send real client links you push it to a public domain — he names Vercel — then wire up three integrations: a Google account (calendar), a backend database, and Stripe.
  • Getting it: Free Skool community → Classroom → All YouTube Resources. Full setup guide lives there; he claims a one-day setup.
