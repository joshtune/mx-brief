OpenAI GPT-6.2 Astra is Here - It's Not What You Think

Matt Wolfe · 2026-11-18 · 128,622 views  ·  Watch on YouTube →
GPT-6.2 Astra: cheaper and more efficient, not smarter

If you're picking a model for your web app's coding or API calls, this says Astra cuts token cost but isn't a coding upgrade, so you can skip the hype.

What it is: OpenAI's GPT-6.2 launch (Astra flagship, Soul everyday tier), pitched on token efficiency rather than raw intelligence. The transcript cuts off before the self-improvement section and Matt's own tests.

How it works:

  • Pricing: Astra is $8 per 1M input tokens and $40 per 1M output tokens, 20% cheaper than the previous Astra and the same as Claude Fable 5.2. Soul stays at $2 input and $10 output.
  • Availability: Both are live in the API, ChatGPT Work and Codex on paid plans (Plus, Pro, Enterprise, Edu).
  • Efficiency claim: Same jobs use fewer tokens. On Artificial Analysis, a benchmark task costs about $4 on Astra versus about $26 on Fable, even though the per-token prices match.
  • Benchmarks: Artificial Analysis index has Fable 5.2 first at 65 and Astra second at 62, up 5 points from the last Astra. Astra now beats Gemini 4 Carbon and Claude Opus 5.5, and ranks first on science and 3D tests.
  • Coding: No real movement. Astra in Codex scores 53, the same as before. Soul dropped 3 points. Fable in Claude Code scores 58.
  • Early tester verdicts:
  • Theo (T3): great at code review, 3D, games and computer use. He still wouldn't pick it over Opus 5.5. It stops mid-task to ask questions and its explanations are hard to follow.
  • Matt Shumer: won't write a review because he can't recommend it.
  • Every team (Dan Shipper): writing regressed, output is too compressed, and it stops early on bigger builds.
  • Ethan Mollick: uneven and weird, but it delivered on a big ambitious project.
  • Matt Berman: good, but not as good as Opus or Fable.
  • Pattern: Nobody calls it dumb. The complaint is that it's terse, quits early and is hard to steer, which fits a model tuned to use fewer tokens.
  • Caveats: Testers used pre-release builds. Matt had no early access. OpenAI has sponsored his channel before, but this video isn't sponsored.

Why it matters for you: For web app work, Astra is a cost lever (cheaper runs on API-heavy features), not a coding upgrade. Keep your current coding model, and test Astra or Soul on token-heavy production calls before switching.
