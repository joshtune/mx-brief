Fable 5 + Karpathy’s LLM Wiki is Basically Cheating

Nate Herk | AI Automation · 2026-07-03 · 22,468 views  ·  Watch on YouTube →
Turn YouTube transcripts into a self-linking LLM wiki.

Nate shows a Claude Code + Fable 5 pipeline that ingests your own content into a backlinked knowledge graph and one-shots a browsable HTML frontend from it — a repeatable pattern for building a queryable 'second brain' over any corpus.

What it is: A Karpathy-style "LLM wiki" (interlinked markdown knowledge graph) built by pointing Claude Code at Nate's YouTube transcripts, then rendered into a beginner-friendly HTML explorer by Fable 5.

How it works:

  • Ingest: Nate prompts Claude Code — "go grab my YouTube videos and ingest them into this wiki" — and it auto-generates per-video wiki pages (summary, key takeaways, tools mentioned, techniques) with relations/backlinks between concepts. No manual linking.
  • Graph structure: Each page (e.g. "Nano Banana 2") links to entities like GitHub → Vercel → Claude Code; you follow backlinks to traverse the whole mind map. It grows continuously as new videos are added.
  • Frontend generation: He fed Fable 5 one prompt — "turn this messy blob of transcripts + connections into a simple, non-overwhelming resource that shows how tools/techniques/ideas connect, that a beginner could click through." Fable one-shotted a searchable HTML app (tools, techniques, videos; orchestrator/models/inputs "layer framework"; click a concept → see source videos + connections on the right).
  • The Fable-vs-Opus point: Same backend database. He spent ~a full day going back and forth with Opus 4 / Opus 4.8 and disliked the result (felt overwhelming); Fable nailed the "emotional"/beginner-friendly UX framing in one shot. Claim is about UX interpretation, not raw capability.
  • Multiple wikis in his AI OS: a YouTube-transcript wiki and a "Herc brain" wiki of internal/external meeting recordings — so drafting LinkedIn/community posts and emails pulls full business context. He also had Fable generate a one-shot "visual journey of 2026 so far" from the meeting data.

Tools & links:

  • Claude Code — did the transcript ingestion + wiki-page generation with backlinks
  • Fable 5 — one-shot generated the browsable HTML knowledge explorer from the graph DB (strong at emotional/beginner-friendly UX prompts)
  • Opus 4 / Opus 4.8 — the contrast baseline for UX generation
  • Concept borrows from Andrej Karpathy's LLM wiki idea (interlinked, LLM-maintained knowledge base)
  • Glaido voice-to-text (free month, code NAT) — sponsor tool from description
  • AI Automation Society (free resources) — his community
  • Note: transcript names no public repo — the wiki + HTML are custom Claude Code output, not a shared template.

Why it matters for you: This is the reproducible move — point Claude Code at any corpus to auto-build a backlinked knowledge graph, then have a model one-shot a UI over it — a concrete RAG-adjacent "second brain" pattern you could wire to your own docs, transcripts, or codebase.
