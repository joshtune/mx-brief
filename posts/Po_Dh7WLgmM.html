The Most Overhyped and Underhyped New AI Models

Matt Wolfe · 2026-09-03 · 83,086 views  ·  Watch on YouTube →
Model-release week triage: what actually changed for builders.

Matt's honest take is that this week's model drops mostly move math/science/coding benchmarks — worth 8 minutes to know what's real before you swap models in your app's API calls.

What it is: A skeptical roundup of this week's frontier model releases — Anthropic's Fable 5.1, Google DeepMind's new models, and OpenAI teasing an upcoming "Astra" model — with Matt arguing most of the hype doesn't translate into user-visible change.

The core argument:

  • Release cadence hasn't slowed, but the average ChatGPT/Claude user's daily experience has plateaued
  • The real gains are concentrated in math, science, and agentic coding — coders are the group actually feeling it
  • Even for coding, the delta is "same end result, less prompting," not a new capability class
  • Everyone else's content frames each drop as "this changes everything"; Matt's calling that a hype machine

Fable 5.1 (Anthropic) — the concrete details:

  • Available now on paid Anthropic plans. Mythos 5.1 also shipped but is gated to a narrow set of cyber-defense orgs
  • Benchmarks are visibly cherry-picked — the selected charts are the ones where GPT 5.6 Soul looks weakest
  • Agentic scientific research: roughly 2x every prior model
  • Agentic coding: large jump over GPT 5.6 Soul. Knowledge work: solid but more modest jump
  • ~25% cheaper than Fable 5 for typical workloads — the line that actually matters if you're paying per token

Fewer refusals:

  • Cybersecurity safeguards were made more precise; you can now use it to identify software vulnerabilities
  • Anthropic claims ~60% fewer interventions on average vs. the prior behavior of bouncing prompts down to an Opus model
  • Dual-use cybersecurity tasks still get redirected to Opus models — the gate moved, it didn't disappear

Anti-distillation mechanisms:

  • Distillation = using a big "teacher" model's prompts and outputs to train a smaller "student" model
  • New API accounts can no longer manually edit Claude's prior context in a multi-turn conversation while preserving the transcript of Claude's prior thinking
  • Purpose: stop extraction of Claude's reasoning traces as training data — aimed squarely at the "Chinese labs are distilling frontier models" narrative
  • Matt flags the hypocrisy: labs that trained on scraped internet now object to having their homework copied
