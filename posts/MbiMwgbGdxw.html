Every Claude Code Skill I Use to Drive My Entire Development Process

Cole Medin · 2026-08-13 · 15,963 views  ·  Watch on YouTube →
Cole open-sources his complete Claude Code skills library.

It's a plug-and-play skill library plus a "validation-first" philosophy you can cherry-pick into mx-workflow without adopting someone else's entire SDLC.

What it is: Cole's full working collection of Claude Code skills — the actual folder he uses on real client codebases and in his enterprise training — packaged as a Claude Code marketplace plugin.

The core claim:

  • He hasn't written a line of code by hand in over a year. The system driving that is "quite simple" — just a collection of skills.
  • A skill = a reusable prompt = a workflow that walks the coding agent through one process. That's it. No framework religion.
  • Six months of stability on this setup, across real production work.

What he's doing differently:

  • Minimalist and plug-and-play by design. Explicit contrast with GitHub Spec Kit and Gastown — he calls them impressive, but says adopting them means adopting their *entire* SDLC. His pitch: a library you raid, not a process you convert to.
  • Assumes you already have a workflow. He expects you to take two or three skills, or just the ideas, and graft them onto what you have. Even suggests the modern move: point your agent at the repo and say "grab this skill."
  • Skills are customization targets, not black boxes. A stated focus of the video is editing them to fit your codebase and your habits.
  • Covers the decide-what-to-build end too. The description flags skills for deciding what to build + how to build it, and cutting PRDs into tickets — not just code-writing skills.
  • Validation-first is the linchpin. His words: the most important thing in the entire process. The framing — "let the model cook" but stay confident in its outputs. Validation is the gate that makes long autonomous runs safe, not more supervision.

Install path (Claude Code):

  • Two commands: add his marketplace, then `/plugin install`.
  • Install scopes offered: global (all codebases — his default recommendation), current repo only, or for collaborators (team-committed).
  • Verify with `/plugins` and `/skills`; skills show up immediately as slash commands.
  • Non-Claude-Code agents (Codex etc.) are supported via a separate path he covers later in the video.
