Omarchy Can Do WHAT?! 50 Features You’re Missing

NetworkChuck · 2026-09-05 · 235,771 views  ·  Watch on YouTube →
50 post-install Omarchy tricks, keyboard-first, mouse optional.

Chuck is turning Omarchy into a keyboard-driven, AI-touched daily driver, and the workspace/scratchpad tricks here are exactly the muscle memory that makes an agent-heavy terminal workflow fast.

What it is: A follow-up to Chuck's Omarchy install video: 50 things to do once you're staring at DHH's blank Arch + Hyprland tiling desktop, plus a segment where he lets an AI agent modify the OS directly.

How it works (the keybinding crash course):

  • Discoverability first — `Super+K` opens the full shortcut cheat sheet; `Super+Space` is the system-wide launcher (apps, reboot, shutdown); `Super+Alt+Space` is apps only.
  • Universal clipboard — `Super+C` / `Super+V` copy-paste everywhere, including the terminal. `Super+Ctrl+V` opens clipboard history with images.
  • Window navigation without a mouse — `Super+Arrow` moves focus, `Super+Shift+Arrow` swaps positions, `Super+J` toggles horizontal/vertical split, `Super+W` closes, `Ctrl+Alt+Del` closes everything. Hold `Super` to drag if you must.
  • Workspaces replace monitors — `Super+1..4` switches, `Super+Shift+N` moves a window and follows it, `Super+Shift+Alt+N` moves it without following.
  • Three flavors of fullscreen — `Super+F` true fullscreen, `Super+Alt+F` full width with gutters, `Super+Ctrl+F` fullscreen inside the tile.
  • Scrolling layout — `Super+L` swaps tiling for a scrolling layout when you have too many windows open.
  • Scratchpad (Chuck's favorite) — `Super+Alt+S` hides a window into a scratchpad; `Ctrl+S` summons it on any workspace. Ideal for Slack or a persistent terminal that follows you around.
  • Window groups — `Super+G` tabs windows together, `Super+Alt+1/2` or `Super+Ctrl+Arrow` cycles tabs, `Super+Alt+G` ungroups.

The AI angle:

  • Later in the video Chuck lets an AI agent change things inside the operating system directly. He explicitly frames this as fine at home, dangerous at work.
  • The sponsor segment (ThreatLocker) is actually on-topic: allow-listing what an agent can execute and ring-fencing what an approved app can reach (files, network, other apps). Agents generate helper scripts constantly; the pitch is to let them run but not roam.
