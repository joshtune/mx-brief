27B model on a tiny Khadas Intel mini PC

It names the machine (Khadas Mind Pro, 64GB), but the price and Mac mini comparison aren't in the transcript we have, so skim for those.

What it is: Alex runs a 27B-parameter model on the Khadas Mind Pro, a palm-sized Intel Panther Lake mini PC, and benchmarks four ways to run it.

The machine:

  • Box: Khadas Mind Pro, billed as the smallest Core Ultra X7 358H machine he's seen
  • Memory: 64 GB, shared between CPU and GPU
  • GPU: integrated Intel Arc B390 (no discrete card)
  • Model: 27B, about 17.66 GB of weights

How it works:

  • Four backends tested: CPU, Vulkan, SYCL and OpenVINO, with the last three all targeting the same iGPU
  • Prefill (reading the prompt):
  • CPU: ~17 tok/s
  • OpenVINO: ~446 tok/s, about 27x faster
  • Decode (writing the answer):
  • CPU: under 5 tok/s
  • Vulkan: 5.4 tok/s
  • SYCL: 5.7 tok/s
  • OpenVINO: 2.6 tok/s, the slowest
  • Why decode is slow: every token streams all ~18 GB of weights through shared memory
  • Measured bandwidth: ~100 GB/s (17.66 GB × 5.42 tok/s), the real figure, not the advertised one
  • Takeaway: the GPU sits idle waiting on memory, so memory bandwidth caps writing speed and compute barely matters
