5 Prompts For Every ChatGPT New Feature

Matt Wolfe · 2026-09-24 · 7,504 views  ·  Watch on YouTube →
Five prompt demos for ChatGPT's newest features and APIs.

Two of the five demos — the Agents API's persistent sessions and the GPT Live API's concurrent voice+work — are actual building blocks for web apps, buried under three consumer-toy examples.

What it is: A rapid-fire tour of 5 new ChatGPT capabilities, each shown as a single prompt example rather than a deep technical walkthrough.

The 5 features:

  • Computer use (GPT-6) — operates desktop apps like Blender directly; demoed building a 3D diorama from a photo
  • Image editing (GPT Image 2.5) — precise, localized edits that preserve everything outside a specified region
  • Cloud browser (ChatGPT Work) — persistent hosted browser session that logs into your accounts without hijacking your local browser
  • GPT Live 1 API — voice API that keeps a conversation running while an agent researches in the background
  • Agents API — supports persistent sessions/memory across conversations, so an agent can resume where it left off

Why it matters for you:

  • Agents API — persistent, resumable sessions are the missing piece for any app-side agent feature (onboarding flows, long-running assistants, multi-step workflows) without you having to hand-roll session state
  • GPT Live 1 API — if you're building anything with a voice or chat interface that needs to keep talking while doing async work (search, tool calls), this is the API primitive for it
  • Computer use, image editing, and the cloud browser are consumer-facing demos with no direct API angle shown here — skip unless you're building desktop-automation or browser-agent products specifically
