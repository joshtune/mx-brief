Lesser-known AI voice and avatar models, mostly not web-dev relevant

Only the Fish Audio Drama 3 segment matters if your web app needs character voices or narration; the rest is research-demo noise.

What it is: A grab-bag of under-the-radar AI releases. The transcript covers two: Fish Audio's Drama 3 (text-to-speech) and ByteDance's OmniHuman 2.0 (image + audio to talking video).

How it works:

  • Drama 3 direction: put plain-English performance notes in square brackets inside the script, e.g. `[barely holding it together, forcing a smile] I'm fine.` No emotion dropdown.
  • Word-level scoping: a direction can apply to specific words only (e.g. whisper just one phrase).
  • Inline sound effects: things like a small laugh or shaky breath, placed exactly where you want them.
  • Multi-speaker: multiple voices in a single script.
  • Benchmarks: top pronunciation score on Artificial Analysis, ahead of ElevenLabs. It does worse on the Arena blind preference leaderboard, so people often still prefer other voices.
  • Open weights: on Hugging Face, 36B parameters. Reported VRAM needs are ~46 GB, or ~32 GB with a community 4-bit quant. Not laptop territory.
  • License: free for commercial use under $500k/year revenue.
  • API pricing: ~$10 per million characters now. It jumps to $50 after November 12 (launch discount).
  • API gotchas: takes vary, so generate several and keep the best. The API can silently fall back to older models while still billing you, so verify the model is set to drama 3.
  • OmniHuman 2.0: one image plus one audio track gives a talking, singing or acting video. Up to 5 minutes in a single continuous shot (v1 capped at 60s), so no stitching clips.
  • Truncated: the transcript cuts off during the OmniHuman demos, so the rest of the video isn't covered here.

Tools & links:

  • Fish Audio Drama 3 — free web playground plus API
  • OmniHuman 2.0 (ByteDance) — no URL given in the transcript

Why it matters for you: If your web app needs narration, game dialogue or character voices, Drama 3's bracket-direction syntax is a neat API feature. Watch the November 12 price jump and the silent model-fallback billing trap. Everything else here is demo-reel material for a web-app builder.
