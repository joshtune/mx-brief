Claude Code phones you when it's stuck

Skip it if you're after web app tips: it's a 60-second demo of agent-to-human notifications, but the pattern could be useful for long-running coding agents.

What it is: A short demo of an AI agent (Claude Code) calling and texting Matt through a tool called "bird" while editing his videos.

How it works:

  • Claude Code hits a decision it can't make (e.g. which shot opens the video) and places a phone call to ask.
  • The call is interactive: keypad options (press 1 for the phone shot, press 2 for his face), and the answer feeds back into the agent.
  • Low-stakes events, like a finished render, trigger a text instead of a call.
  • If no input is needed, the agent keeps working without interrupting him.
  • Matt says bird also works with ChatGPT, Cursor, and Codex.

Tools & links:

  • Bird: gives AI agents the ability to send texts and emails and place phone calls. The transcript gives no URL, so I can't link it. Search for it before relying on it.
  • Claude Code: the agent doing the editing work.

Why it matters for you: Not much directly: nothing here covers building web apps, and the video is a teaser with no setup steps. The takeaway is the escalation pattern (call for decisions, text for status, stay quiet otherwise), which could suit long agent runs on your own projects.
