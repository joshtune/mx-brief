This Skill Turns Claude Code Into an Expert Video Editor (I'm Giving It Away)

Cole Medin · 2026-11-19 · 13,617 views  ·  Watch on YouTube →
Free open-source skill that edits videos end to end

Cole shows how he turned months of 'the agent almost got it right' failures into one reliable, customizable skill, which is the pattern to copy for mx-workflow.

What it is: An open-source `edit video` skill that guides Claude Code (or any coding agent) from a folder of messy raw footage to a finished video. Cole says it has edited all his recent videos, including this one.

Note: The transcript cuts off right as the pipeline walkthrough starts, so the step-by-step internals below are limited to what he states up front.

How it works:

  • Invocation — you say "edit this video" and give the folder path. The folder can be a mess of raw takes, and the skill sifts out the clips to stitch together.
  • Up-front guidelines — you describe the job first: shorts from the long-form video, heavy animation or a clean edit. The skill adapts to that brief.
  • Script-driven pipeline — the core flow is scripts, not freeform agent improvisation. This is the main difference from just dumping files on an agent.
  • Animations and B-roll — built from your description. Animation style and brand colors are the customization points.
  • Local transcription — the base version teaches the agent to transcribe locally, so the only cost is your agent subscription.
  • Elaborate pipeline — optional. It uses OpenRouter multimodal models to review and fix things like voice quality in the video. Cole edited his Fable 5.2 video this way for $2.71.
  • Extras — it also helps with thumbnails and with cutting shorts from long-form videos.
  • Catches small problems — he promises examples of it fixing subtle issues in its own output and in the raw footage.

What he does differently (the transferable lesson):

  • Codify the last 10% — a bare agent gets you ~90% of the way, but the last 10% costs more iteration than editing by hand. He fixed this by iterating on real videos and writing every fix into the skill.
  • Scripts over prompts — deterministic scripts handle the pipeline, and the skill guides the agent through the small details it wouldn't do on its own.
  • Tiered cost — a free local baseline, plus an optional paid multimodal review layer.
  • Scoped honestly — it's built for presentation and educational content, not flashy edits.
  • One shared repo — it lives inside his main GitHub repo of all the skills he shares on his channel.

Why it matters for you:

  • Skill structure — for mx-workflow, check where your skills lean on agent judgment where a script would be more reliable. Cole's big gain came from moving the fiddly details into scripts.
  • Adapt to the brief — see if your skills ask for the user's intent up front and adapt, as his does.
  • Tiering — consider a cheap default path plus an optional higher-cost review pass.
