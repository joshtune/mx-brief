Seven-persona AI council debates your decisions in Claude Code

Nate gives away a working multi-agent debate skill (/roast-room) and shows the sub-agent-plus-chair pattern behind it, so you can copy the architecture or grab the skill.

What it is: A free Claude Code skill, `/roast-room`, that convenes seven founder-inspired advisor personas to debate a business decision over three rounds and return a scored verdict.

How it works:

  • Trigger: Run `/roast-room` in Claude Code and submit the question. His example was which of four conference options (A/B/C/D) to pick for a June 2027 event. He includes the options, business info, resources, and what success looks like.
  • Personas: Bezos, Paul Graham, Alex Hormozi, Gary Vee, Dan Martell, Gino Wickman, and Warren Buffett. Each is built from material by the real person and is tied to one question:
  • Bezos: is this the right bet, and how reversible is it?
  • Graham: do people actually want this, and is it growing?
  • Buffett: what does it do to cash risk and long-term value?
  • Architecture: Sub-agents, not an agent team. Each sub-agent talks to a chair, which facilitates the debate. Agents do not message each other directly.
  • Round 1: Each advisor writes an opening position and scores each option (e.g. Bezos B 7/10, Graham B 6/10, Hormozi B 8/10). All seven picked B, averaging 7.1/10.
  • Round 2: Advisors read each other's positions and rebut. The chair treats unanimous agreement as a warning sign, so it forces Buffett and Martell to argue for option C as hard as they can.
  • Round 3: Final vote and verdict.
  • UI: An animated web interface sits on top, with talking avatars, per-round key points, and who-said-what-to-whom. It is only a visualization linked to the live Claude Code session. The real work still runs in the terminal.
  • Persona brains: He says each persona has a lot of data behind it and promises a breakdown. The transcript cuts off before that part, so how the persona files are built is not covered here.
