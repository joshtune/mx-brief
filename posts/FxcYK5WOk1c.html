Matt tries Meta's new agent Muse on a real email task.

Skip the app itself — the useful bit is the onboarding pattern: agent runs on a hosted VM instead of your machine, connects to email/calendar via chat, and self-suggests next actions.

What it is:

  • Meta's new consumer AI agent, Muse — a chat-first interface for connecting an agent to real accounts (email, calendar, apps) and having it take action.

How it works:

  • Runs tasks on a hosted/secure virtual machine rather than executing locally on the user's device.
  • Onboarding is conversational: connect an account, and the agent proactively suggests what it can do with it.
  • Demo task: audit AI tool subscriptions by reading email and returning a cost report (Midjourney, Leonardo, Creaya, etc.).

Tools & links:

  • No repo, API, or docs linked in this video — it's a first-look demo, not a build walkthrough.

Why it matters for you: Thin on technical detail, but the remote-VM execution + zero-config account connection is a UX pattern worth stealing if you're building agent features into a web app — it sidesteps the "give the agent access to my machine" trust problem.
