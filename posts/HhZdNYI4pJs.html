I Tried 100+ Github Repos for Claude. These 6 Are the Best

Nate Herk | AI Automation · 2026-10-11 · 225,877 views  ·  Watch on YouTube →
Four Claude-powered repos that turn into sellable client services

Nate names the exact repos and tools behind his video editing, Google automation, scraping and web design workflows, and pitches each one as a service you can sell.

What it is: A repo roundup from Nate Herk. He says he tested 100+ GitHub repos for Claude and kept the ones he can't work without, each paired with a way to sell it to businesses. The title says 6, the intro says 10, and the transcript I had cuts off during repo #4, so only four are covered here.

How it works:

  • 1. Hyperframes (HeyGen) — You describe a video in plain language and Claude builds it from HTML and animations. Hyperframes renders a real MP4 locally.
  • Covers captions, motion graphics, title cards and product promos.
  • Nate builds his own skills on top for YouTube intros, Instagram Reels, course videos and ads.
  • Example prompts: drop in a raw clip and ask for captions and a title card, or ask to turn it into a Reel. A finished file comes back in minutes.
  • He prefers it to Remotion. It's open source with no per-render fees, and he says it isn't sponsored.
  • Sell it as a monthly content package, e.g. a gym that wants 20 caption clips a month.
  • 2. Google Workspace CLI — A command-line tool that lets Claude Code, Codex or any agent work with Drive, Gmail, Calendar, Docs, Sheets and Slides.
  • It ships with 40+ skills, so Claude already knows how to drive it.
  • Nate uses it because Claude's built-in Google connector only works in the desktop app and doesn't cover everything.
  • Setup takes a few minutes because you need a Google Cloud project for the login. Claude can walk you through it, and you grant access only to the apps you want.
  • Sell it as automation of weekly reports, invoices and follow-up emails for small businesses that run on Google.
  • 3. Apify MCP server — Connects Claude to thousands of ready-made scrapers (Instagram, TikTok, Amazon and more).
  • It fixes sites that block Claude or need JavaScript to load, which return an empty page.
  • Example prompt: find bakeries in Chicago on Instagram, get follower counts, download videos, and flag ones with no website in their bio. A spreadsheet comes back in minutes.
  • The connector is open source, but the scrapers run on Apify's cloud. The free plan gives $5/month of credit, and other actors cost per result.
  • Firecrawl is the open-source alternative he mentions.
  • 4. Scrollcraft (Nate's own, disclosed) — Gives Claude a real scroll engine plus design rules for Apple-style scroll-driven sites.
  • Without it, Claude tends to produce generic pages with a few text fade-ins.
  • It has a built-in checker that screenshots the scroll states and inspects element positions, so Claude fixes layout problems itself.
