What Computer Should You Buy for Local AI

Alex Ziskind · 2026-08-16 · 34,592 views  ·  Watch on YouTube →
Alex vibe-codes a local-AI hardware recommendation app.

Skip it for hardware shopping — this is a sponsored Replit build video, not a Mac mini vs. GPU price comparison, though the app he ships is meant to become exactly the buying-advice tool you want.

What it is: A Replit-sponsored build log where Alex turns years of scattered local-AI benchmark data from his own videos into a web app that recommends hardware based on the model you want to run and your budget.

The premise (the part relevant to buying advice):

  • "What should I buy for local AI" has no single answer — it depends on model, size, quantization, VRAM, speed tolerance, and laptop vs. desktop vs. Mac vs. PC.
  • He's tested Macs, Nvidia GPUs, gaming laptops, mini PCs, workstation cards, "weird little AI boxes," and full desktop builds.
  • No specific machines, benchmarks, or prices are given in this video. The data stays trapped in the app, not the script — so there's no Mac mini comparison here.

How the app works:

  • Input: target AI model + budget + form factor. Output: hardware that actually makes sense, backed by real benchmark data.
  • Data sourcing was the hard part — he used AI to extract specs from old videos and found gaps (models named but quantization missing), meaning manual re-watching to fill in.
  • Dataset is small enough to live in a ~5KB JSON file; the agent still spun up a database (29MB of 20GB used).

Build technique worth stealing:

  • Don't hand-write the prompt. Have the agent *plan* first, then have it generate the implementation prompt from that plan. Paste that in.
  • Use Plan mode on a fresh context before Build so the agent asks questions instead of guessing.
  • Explicitly instruct: "do not invent benchmark numbers or fill missing results" — then validate and backfill the data yourself anyway. Alex's take: never fully trust AI with the data layer, only the app around it.
  • Replit supports uploading a design system (colors, fonts, Figma components) to steer the UI; he skipped it.
