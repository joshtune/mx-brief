Claude Code mod that tracks cache expiry to cut costs

Nate shows a custom 'Cachekeeper' mod that stops you paying full price for a cold prompt cache, and it's built by simply asking Claude Code to change its own desktop app.

What it is: A custom Claude Code desktop mod ('Cachekeeper') that surfaces cache and usage stats, and automates session handoff so you don't pay to re-read a stale context.

How it works:

  • Claude Code 'mods' let you ask the desktop app to change itself. You describe what you wish it did and it modifies the UI.
  • The prompt cache covers everything in the chat, so each new message doesn't re-read the history at full cost.
  • The cache has a 60-minute window. The mod shows a countdown, for example 57 minutes, then back to 60 after a message.
  • If the cache expires, you repay full price for all the text. The cost grows as the context window fills.
  • The mod shows the estimated cost if the cache expires.
  • It also shows the 5-hour session limit and the weekly limit.
  • It shows what the session would have cost at API billing rates.
  • One-click handoff: a button runs your session-handoff skill. A second button, 'clear and continue', then runs `/clear`. This replaces the manual routine of running the skill, copying the output, clearing, pasting and hitting enter. It's now two clicks.
  • Expiry notification: when the cache is about 5 minutes from going cold, the mod sends a notification. It asks whether to re-prompt, compact or hand off, so you avoid the repay.
