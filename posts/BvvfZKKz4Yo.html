OpenAI's Dots vs Meta's Muse personal cloud agents compared

This is a feature comparison, not a build tutorial, so there's no workflow to copy, but it shows which persistent cloud-agent setup (memory, connectors, schedules) is worth your time.

What it is: A hands-on comparison of OpenAI's Dots and Meta's Muse, two persistent personal cloud agents, covering features, feel, pricing and direction. The transcript cuts off early, so pricing and the model comparison aren't covered here.

How it works:

  • Muse (Meta) hit #1 in the Apple App Store. Powered by Muse Spark 1.3. Nate's instance is named "Charlie".
  • Dots (OpenAI) runs on GPT-6 Astra (as transcribed: "GBD6 Astra"). Nate says it feels rushed, a catch-up to Muse. The live demo at Dev Day failed and was muted on stream.
  • Same basic shape: both are a single-thread personal agent, not a Grok-bot-style swarm of bots talking to each other. Both are persistent cloud agents with schedules, conversations and their own cloud computer.
  • Customization: you can name and customize each one.
  • Connectors: both have one-click connectors (single sign-on, no API keys). Because each has its own computer, they can also run scripts and hit APIs that have no native connector.
  • Outputs: both create documents, presentations and interactive dashboards. Muse keeps them in a Library as documents or live web artifacts. Dots shows markdown files, dashboards and other outputs.
  • Memory in Dots: starts from your ChatGPT memory, then builds its own context over time. Nate's was stale (old business details, n8n usage), so he pointed it at his local files and Codex memory for current priorities. Dots connects directly to ChatGPT Work and the Codex desktop app if you allow access.
  • Memory in Muse: an Identity tab shows a visual memory file (editable facts, preferences, commitments) and a soul file (persona). Nate says this is familiar if you've used Hermes agent or OpenClaw, and it's easier to see and edit than Dots, where memory is more abstract and there's less profile control.
  • Nate's verdict so far: Muse is better on transparency and UX. Dots has the stronger model and the existing ChatGPT/Codex ecosystem.
