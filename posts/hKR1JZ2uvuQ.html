Rime Finally Made Voice Agents Good Enough

Cole Medin · 2026-08-28 · 4,187 views  ·  Watch on YouTube →
Sponsored review of Rime Labs' TTS voice models.

Almost nothing here for your Claude agent skills — it's a paid voice-model spot, worth two minutes only if mx-workflow ever needs a spoken notification layer.

What it is: A sponsored product review of Rime Labs text-to-speech models. No agent architecture, no harness engineering, no Archon — Cole is selling voices this week.

How it works:

  • Rime was founded by linguists — a Stanford computational linguistics PhD and a linguist who worked on Alexa. Cole's argument is that domain expertise gets encoded into the voice models themselves.
  • ~600 voices across 10 languages, with real dialect granularity: Spanish splits into Mexican, Colombian, Dominican, Puerto Rican rather than one generic "es".
  • Filter the catalog by native language, country, gender, age, style. The voice in the demo is Capola.
  • Cole's actual technical claim (the only one worth anything): it doesn't fumble the stuff TTS normally fumbles — numbers, dollar amounts, IDs, commit SHAs. That's the tell that gives away a synthetic voice, and Rime handles it.
  • Ships an API and an MCP server, so you can wire it into an agent without writing a client.
  • Production users cited: Mayo Clinic, Dialpad, "millions of calls a month."
  • Pricing: 800 free minutes, then $0.05/min.
  • Easter egg: the demo script is Archon reporting on PR 37 — "Opus 5 rewrote the auth middleware, tests went 9/12 → 12/12, cost $42, commit 7AF8C22, want me to merge?" That's Cole trailing his agent-orchestration work, not teaching it.

Tools & links:

  • Rime Labs — TTS models, dashboard, sample generation, API + MCP server
  • Archon — Cole's agent orchestration platform, only cameoed here via the demo script

Why it matters for you: Zero harness or skill lessons to port into mx-workflow — the one transferable idea is the demo script's shape: a run summary that leads with PR, model, test delta, cost, and commit SHA is a genuinely good template for your pipeline's completion notifications, spoken or not. If you ever want `pnpm pipeline` to say "brief published, 14 videos analyzed, $0.38" out loud on the mini, Rime's MCP server is the cheapest path; otherwise skip it.
