The Ultimate Knowledge Base: Bring YouTube Into Your AI Second Brain

Cole Medin · 2026-07-30 · 9,955 views  ·  Watch on YouTube →
Turning a whole YouTube channel into an OKF knowledge base

Cole ships a repeatable skill-driven pipeline that converts any channel's 200+ videos into a citable markdown knowledge base your agent can query — exactly the ingestion layer mx-workflow is missing.

What it is: Cole packaged his entire 200-video YouTube channel as an OKF (Open Knowledge Format) knowledge base / bundle you install into your second brain with a single copy-paste prompt, plus the Claude skills to do it for any channel.

What's different this time:

  • Previous videos covered OKF as a *spec*; this one is the proof-of-concept — a knowledge base useful enough that you install it before you understand it.
  • He frames OKF as the third standard in the stack: MCP = agent↔tool, A2A = agent↔agent, OKF = agent↔knowledge base. Portable, shareable knowledge — not just private notes.
  • Distribution is a *prompt*, not a setup guide. The prompt teaches the agent OKF if it doesn't know it, clones the repo, and is query-ready. No install script, no MCP server, no config.
  • Knowledge base is agent-agnostic — works with Claude Code, Hermes, open-claude, whatever your second brain runs on.

How the knowledge base is structured:

  • `README.md` — human-facing, holds the one-shot install prompt.
  • `index.md` — the agent's entry point (standard LLM Wiki / Karpathy-style pattern). Agent always reads this first.
  • Themes section in the index — Cole calls this the most important part: a high-level map of what questions this KB can actually answer, so the agent orients before it searches.
  • Concepts and entities files — the drill-down layer the agent routes to based on the question.
  • Everything is plain markdown. Videos → markdown transcripts → concept/entity notes. No vector DB, no embeddings.

What it looks like in use:

  • Demo query: *"What is my entire end-to-end process for building a new feature with AI coding agents?"* — a multi-video answer. Agent digs through the wiki and returns a synthesized walkthrough citing specific videos with timestamps.
  • Other demos: "When is RAG dead and when is it still essential?", "How does my second brain work under the hood and which videos explain each part?"
  • The real unlock: it's a navigation layer for channels too big to keep up with — high-level answer first, click into the source video only if you want depth.

Why it matters for you: mx-workflow already has the review/build agent fleet — the gap is durable knowledge, and OKF gives you a copyable pattern: an `index.md` with a themes map plus concept files, so your agents route by theme instead of grepping, and every answer they give cites its source. Steal the "distribute via one prompt" trick for mx-workflow skills too — installation as a paste-able prompt beats a README any day.
