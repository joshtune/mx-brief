Trying To Solve The Biggest AI Problem

Matt Wolfe · 2026-09-09 · 31,747 views  ·  Watch on YouTube →
Vibe-coding an AI video slop detector with Codex and Gemini.

It's a real end-to-end build of a URL-in, verdict-out web app using ChatGPT for planning, Codex for coding, and Gemini's video-understanding model as the detection engine, which is a workflow you can steal for your own apps.

What it is: Matt builds a website where you paste a YouTube/TikTok/Instagram/X link (or upload a clip) and it tells you whether the video is probably AI-generated, with a confidence score and "receipts."

How it works:

  • Step 1: A long voice-dictated ChatGPT prompt asking for a viability check. ChatGPT chewed on it for 17 minutes and came back with "doable, but never 100% accurate, don't oversell it."
  • Step 2: Switched to Codex, created a project pointed at an empty local folder, and instead of re-explaining, pasted the share link to the ChatGPT planning chat and said "read this and map out the plan."
  • Step 3: Told Codex to use Google's new Gemini agentic video-understanding model (rolled out September 2026) as the analysis engine, linking the announcement article directly into the prompt.
  • Result: About 1 hour 16 minutes of autonomous Codex work produced a deployable site with a landing page, URL input, upload option, and a sample report format (verdict + confidence rating).
  • Detection stack: Google SynthID for watermark checks on Google-generated video, plus Gemini video understanding for the actual "does this look fake" analysis.
  • Tested it on a clearly fake clip (a woman in an inflatable suit with a jetpack, the "Fart Zuka") to see if the detector catches obvious slop. Transcript cuts off before the result.
  • Side note: AI-generated marketing copy on the landing page was rough. Codex ships working code faster than it ships good words.

Tools & links:

  • ai-slop-detector on GitHub — the finished app, runnable yourself
  • Google SynthID — detects Google's own AI watermarks in media
  • Gemini video understanding — the September 2026 model update used as the core classifier
  • OpenAI Codex — did the actual build from a linked ChatGPT planning conversation
  • FutureTools — Matt's tool directory

Why it matters for you: The transferable pattern is plan-in-chat, hand the chat link to Codex, point it at a specific model announcement, and let it run for an hour. Also worth noting Gemini as the practical choice for video-input features in a web app.
