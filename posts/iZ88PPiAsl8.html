What it is: First-look review of the MSI Prestige N16 Flip AI+, the first RTX Spark laptop, put up against Alex's DGX Spark desktop box.

The machine he's running AI on:

  • MSI Prestige N16 Flip AI+: NVIDIA N1X chip with a 20-core ARM CPU, running Windows on ARM.
  • Memory: 128 GB LPDDR5, the same capacity as the DGX Spark.
  • Display: 16-inch 4K tandem OLED, 120 Hz, touchscreen, with a flip-back hinge.
  • Power: 140 W charger, smaller than he expected.
  • Comparison box: his own DGX Spark, which he says is "selling like hot cakes while the price keeps going up."

Claims he's checking (results not in the available transcript):

  • MSI says it runs 120B-parameter models.
  • MSI says it holds peak performance with no thermal throttling.
  • He also wants to know whether being plugged in changes performance.

Early results:

  • Speedometer 3.1 (single core): 35-37 across four runs.
  • Multi-core compile-style test (PowerShell `Measure-Command`): about 22 seconds. The transcript cuts off before he compares it to other machines.
  • Software compatibility is good. Of 250+ services running, only 4 were still x64. VS Code, Visual Studio, Zed, Python and Node are all native ARM64.
