It's a Mac-mini-vs-Mac-mini shootout (no other machine, no pricing) — watch only if you want hard numbers on how much faster the M6 is at running local LLMs than the M4 you might already own.

What it is: Head-to-head local LLM benchmark, M6 Mac mini vs M4 Mac mini — no other hardware, no pricing discussed.

How it works:

  • Runs Qwen 3.5 9B (Q4_K quant) through llama.cpp on both machines
  • Synthetic benchmark: prompt processing 210 tok/s (M4) vs 742 tok/s (M6); token generation 18 tok/s (M4) vs 26.9 tok/s (M6)
  • Real-world prompt run: 45.9 tok/s prompt / 17.4 tok/s generation (M4) vs 71 tok/s prompt / 26 tok/s generation (M6)
  • M6 wins everywhere — roughly 2–3.5x on prompt processing, ~1.5x on generation
