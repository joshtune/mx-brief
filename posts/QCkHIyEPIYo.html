If you're choosing between Claude effort levels for agentic coding tasks, this is a real side-by-side of output quality vs. cost vs. runtime on an identical prompt.

What it is: Nate runs the exact same complex agentic prompt through Opus 5.5 at every available effort level (low, medium, high, extra, max, ultra code) and compares the results.

The task given to the model:

  • Build a walkable, third-person 3D world of a real virtual tech conference ("AIS Live")
  • Source material: a Frame.io folder with 105GB of event recordings from the virtual conference
  • Requirements: multiple rooms, tracks, stages; should feel like an in-person conference
  • Allowed to use Kling AI (referred to as "key.ai" in transcript, likely a transcription artifact) to generate supplemental images/video
  • Allowed to pull from Nate's "Herk 2" project (his personal AI operating system / toolset)
  • Judged on: creativity, design, physics, overall exploration feel

How it works:

  • Same prompt fed to Claude Code (or similar agentic harness) at each effort setting
  • Nate tracks: output quality, total runtime, API billing cost, total tokens used, number of self-checks the model ran, and number of clarifying questions asked
  • Video walks through each effort tier's build starting with low, moving up to ultra code

Low effort results (first tier shown):

  • Overall verdict: rough, more slideshow than immersive 3D world
