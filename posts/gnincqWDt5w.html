Framework 13 Pro Shows Why Apple Solders Your Memory

Alex Ziskind · 2026-08-04 · 273,209 views  ·  Watch on YouTube →
Framework 13 Pro vs MacBook Pro M5, benchmarked

It's the Intel-based Linux laptop pitched as a MacBook Pro replacement — and the socketed-RAM tradeoff is exactly why Apple's soldered memory wins on AI-adjacent memory bandwidth.

What it is: Alex builds a Framework Laptop 13 Pro (Intel, modular, user-serviceable RAM/SSD), installs Fedora, and races it against an M5 MacBook Pro.

The hardware, as-configured:

  • Framework 13 Pro — Intel "Pro" chip, fully modular
  • Expansion modules he bought: USB-A, DisplayPort, HDMI, Ethernet (10GbE), USB-C, microSD — all of them
  • 1TB NVMe SSD, socketed SO-DIMM memory (the whole point of the video's title)
  • Metal chassis, weight roughly a MacBook Air, slight lid flex
  • Haptic trackpad (rare outside Mac/Surface), longer key travel than MacBook membrane

Benchmarks — Framework vs MacBook Pro M5:

  • Speedometer 3.1 (single-threaded JS, web app responsiveness): 12.5 on battery → 30.8 plugged in
  • Geekbench-style single core: M5 = 60.6, Framework performance mode = 37.3
  • Takeaway: the Intel chip needs to be plugged in to be competitive at all — classic x86 behavior, unchanged for years
  • Performance mode ran silent — no fan noise spike

The soldered-memory argument:

  • Framework's socketed RAM is repairable and upgradeable, but SO-DIMM slots cap memory bandwidth
  • Apple solders (and now packages on-die) precisely to hit the bandwidth that makes unified memory viable for large local LLMs
  • Modularity is the tradeoff you pay for in AI workloads, not general dev work

Linux notes:

  • Fedora 44 is the framework-recommended version — 42 and 43 lack the Intel chip support and the machine won't come up right until you update
  • HDMI out, 10GbE module, external display all worked post-update

Tools & links:

  • Framework Laptop 13 — modular, repairable laptop; expansion cards sold individually
  • Speedometer 3.1 — browser/JS responsiveness benchmark used here
  • Fedora — Linux distro Framework officially recommends
  • ChatLLM by Abacus AI — sponsor, multi-model chat frontend, $10/mo
  • Abacus DeepAgent — sponsor, agent + app hosting

Why it matters for you: If you're sizing a local-AI box, this is the clean data point — a modular Intel laptop lands at roughly 60% of M5 single-core and only when plugged in, which means for LLM work a Mac mini remains the cheaper, faster, higher-bandwidth choice; Framework buys you repairability, not inference throughput.
