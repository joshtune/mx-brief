Weekly AI news: Haiku 5.5 launch, Claude dashboards

Only the first few minutes matter for web-app builders: Haiku 5.5 is a cheap API model for high-volume app features, and Claude's live dashboards connect to data platforms. Skim the rest.

What it is: Weekly AI news roundup. The transcript only covers the Anthropic segments (Haiku 5.5, live dashboards, Claude Motion). The OpenAI, Grok and Google segments were cut off, so nothing is summarized for them.

How it works:

  • Haiku 5.5 positioning: Fast and cheap, not the smartest. Anthropic pitches it for high-volume, cost-sensitive work: summaries, compactions, database queries, classification. They also recommend it as a coding sub-agent.
  • Benchmarks: It trails Sonnet and Opus everywhere. Knowledge work scores 1620 vs Sonnet's 1840. Computer use scores 72 vs 83.9.
  • Cost vs. quality: Haiku 5.5 at extra-high effort is about as smart as Sonnet 5.5 at medium. The cost per task is about 28 cents vs about 93 cents.
  • Pricing: Matt quotes input as roughly 10 cents per million tokens for the first 100K, then 50 cents. Output is 50 cents per million for the first 100K, then 250 beyond that. He misspoke "output" for input once, so check Anthropic's pricing page before budgeting. He says it's cheaper than the old Haiku and about a quarter of Sonnet's price.
  • Artificial Analysis: Anthropic holds the top three intelligence slots. Haiku 5.5 ranks below Kimi K3, GLM 5.3 and Grok 4.7. It costs about 21 cents per task on average.
  • Token usage: It uses the second-most tokens per task, behind only Sonnet 5.5. The cheap per-token price offsets that.
  • Matt's own test: His Buccy Bench run cost under half a cent, took 42 seconds and used under 10K tokens. He said the output wasn't very pretty.
  • Effort setting: Medium is the recommended effort level.
  • Where it fits: Matt's view is that Haiku matters via the API, not the chat UI. That means app features, or simple tasks in Claude Code.
  • Live dashboards (Anthropic): Claude can build dashboards that stay current. They connect to BigQuery, Databricks, Snowflake and CRMs like Salesforce, and work on any paid plan.
  • Claude Motion: Animated explainers. Matt says it isn't widely available yet, and the transcript cuts off before he explains it.

Tools & links:

  • Artificial Analysis — independent model intelligence and cost-per-task comparisons

Why it matters for you: Haiku 5.5 is a candidate for the cheap tier of your app's LLM calls (classification, summaries, DB-query helpers) and for coding sub-agents. Don't swap it in for hard reasoning, since it loses to Sonnet at the same effort.
