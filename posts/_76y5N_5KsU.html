AI Models Get Nerfed After Launch (Here's the Proof)

Nate Herk | AI Automation · 2026-11-18 · 13,803 views  ·  Watch on YouTube →
Models feel nerfed after launch because of settings, not weights.

Two minutes on why your model suddenly feels dumber, plus a cheap, repeatable test you can run yourself. Note this is a short opinion piece, not a build-along, so there's no workflow, repo or code to copy.

What it is: A short take arguing that post-launch "nerfing" comes from the settings around the model (like reasoning effort), not from degraded weights, and showing you how to check it yourself.

How it works:

  • The admissions: Anthropic published postmortems saying users felt Claude Code got less intelligent and that its own tests missed it. Sam Altman said GPT seemed way dumber the day after launch.
  • The trackers: Services that run the same model on the same tests every day show the model itself isn't changing.
  • The dials that do change: Things like how hard the model is allowed to think (effort level).
  • The evidence: Opus 5.5's own launch page lists 57.8% on a coding test at max effort and about 52% at default effort. Same page, same model.
  • The fix: Set effort yourself instead of trusting the default. In Claude Code, type `/effort` or click the effort button.
  • DIY nerf test: Pick 5 prompts from your real work. Run them on launch day, then rerun them every couple of weeks and compare.
  • His verdict: He found no proof that labs turn down weights. He admits it "feels fishy" and speculates labs might pump the model for viral launch days, then quietly dial it back. That part is speculation.

Tools & links:

  • Claude Code `/effort` command — sets reasoning effort in-session; no URL given.
  • Opus 5.5 launch page — source of the 57.8% vs 52% numbers; no URL given in the transcript.
  • No repos, daily-tracker names, or links are mentioned in the transcript or description. The video doesn't name which trackers he used.

Why it matters for you: If you ship on Claude Code, set effort explicitly and keep a 5-prompt regression suite, so a model that "got worse" gets a measurement instead of a vibe.
