What it is: A roundup of 9 free, harness-agnostic "skills" and "plugins" for AI coding agents (Claude Code, Codex, Cursor, Copilot, etc.).

How it works:

  • A skill = a reusable instruction file (`skill.md`) — a pre-tuned prompt the model reads alongside your prompt, so you get consistent behavior every time it's invoked.
  • A plugin = a bundle that can package skills, agents, hooks, MCP servers, and slash commands so you install the whole kit instead of copying folders.
  • Install is dead simple: paste the GitHub repo URL into Claude Code or Codex and say "install this for me." Codex also has a skills/plugins marketplace with one-click Add.
  • They work across IDEs/harnesses — install once, reuse the behavior everywhere.
