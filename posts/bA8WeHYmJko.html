Jev is the FIRST of a Whole New Class of AI Models (Here's How to Actually Use It)

Cole Medin · 2026-09-21 · 36,782 views  ·  Watch on YouTube →
New 'system one' AI model class specializes in decisions, not text.

Jev's decision-only architecture is a direct answer to the reliability/determinism problem Cole (and you, in mx-workflow) keep running into with LLM-based routing and judgment calls.

What it is:

  • Jev is the first "system one 1 model" — a new AI model class built purely for decision-making, not text generation.
  • Unlike ChatGPT/Claude/Gemini, you can't converse with it. It never outputs free-form text — only a structured decision plus a confidence score.

How it works:

  • Input is two-part: (1) a situation description, (2) a set of multiple-choice questions to answer about that situation, all evaluated in parallel.
  • Output is a choice per question + a confidence score — closer to structured-output JSON than an LLM completion, but trained differently.
  • Trained with a new algorithm called RLCD (Reinforcement Learning for Calibrated Decisions), contrasted with RLHF (used for generative models). The pitch: optimizing directly for calibrated decisions reduces hallucination/reliability issues that plague generative models used for routing/classification.
  • Demo use case: a customer-support agent gets a complaint ("can't connect Stripe account, losing sales"). Jev simultaneously does routing (64% confident → billing dept) and sentiment analysis (frustration score) from the same situation input.
  • Cole flags a real critique worth weighing: skeptics argue this isn't fundamentally new — it overlaps with existing classification-model techniques rather than being a novel architecture. He engages with this rather than dismissing it.
