8 RTX Pro 6000’s Wasn’t What I Expected

Alex Ziskind · 2026-09-16 · 228,363 views  ·  Watch on YouTube →
Alex tests a $150K+ 8-GPU AI workstation, not a laptop.

If you're benchmarking your Mac mini against 'real' local AI hardware, this is the other end of the spectrum — 768GB VRAM for the price of a house down payment.

What it is: A borrowed Camino Grando workstation — 8x Nvidia RTX Pro 6000 Blackwell (96GB VRAM each, 768GB total) — tested for running large local LLMs and multiple parallel coding agents.

The machine:

  • 8x RTX Pro 6000 Blackwell Server Edition, 96GB VRAM each
  • AMD EPYC 9474F (48 cores/96 threads), 512GB DDR5 RAM
  • Liquid-cooled, 4U chassis, 121 lbs, rack- or desktop-mountable
  • Only 2 M.2 slots (all PCIe lanes eaten by GPUs), no NVLink — GPUs talk over PCIe
  • Draws ~6.5kW running; PSUs rated for 8kW total

Cost vs. a Mac mini/Studio:

  • GPUs alone: ~$15K each × 8 = ~$120K, before chassis, CPU, RAM, cooling — realistically $150K+ all-in
  • A maxed M3 Ultra Mac Studio (512GB unified memory) runs ~$9,500 — roughly 15-16x cheaper for less VRAM and no multi-GPU parallelism
  • Not for sale to Alex personally — Camino loaned it; this is enterprise/server-tier pricing, not prosumer

Why it exists: Aimed at teams or power users running multiple coding agents simultaneously (each sending 50K+ tokens of context), not the "one person, one chat window" local LLM use case. He ran a 400B-parameter model with a 400K+ token context window on one box, no cloud.

Why it matters for you: This confirms the Mac mini/Studio isn't competing in this tier — it's a different category (single-user, unified memory, sub-$10K) versus this rack-mount, multi-GPU, six-figure server built for teams running parallel agent workloads.
