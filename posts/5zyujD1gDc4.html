Chuck builds a Framework laptop, installs Omarchy in 60 seconds.

This is the closest thing to a portable extension of Chuck's home lab — a user-serviceable, module-swappable Framework running Omarchy, which is the same Arch/Hyprland stack a lot of AI-heavy terminal workflows are converging on.

What it is: A short-form unboxing/build of a Framework laptop shipped in pieces, followed by a sub-60-second Omarchy (Arch + Hyprland) install.

The build:

  • Ships unassembled — QR codes on the packaging walk you through each step
  • NVMe SSD: standard, slots in like any M.2 drive
  • RAM is the curveball — CAMM2 (Compression Attached Memory Module). No DIMM slot, no angle-and-click. It lays flat and is compressed down by a bracket. Chuck admits he wasn't sure he'd done it right
  • Keyboard and bezel snap in last; the bezel is translucent, retro Game Boy aesthetic
  • Expansion cards: the I/O ports are modules. Slot HDMI where you want HDMI, USB-C where you want USB-C, buy more modules later. All-USB-C or all-HDMI is a valid (if cursed) config
  • Hardware kill switches for camera and mic — physical, not a software toggle

The install:

  • Ships with no OS. You bring your own
  • First USB boot failed — not a bad flash. Framework ships with Secure Boot enabled by default. Disable it in BIOS and Omarchy boots fine
  • Install clocked in right at the 60-second line
  • Battery life and raw speed both got called out as better than expected

Tools & links:

  • Omarchy — DHH's opinionated Arch + Hyprland distro, preconfigured for a keyboard-driven terminal-first workflow
  • Framework — modular, repairable laptops; DIY edition is the one that arrives in pieces
  • Framework Linux guides — official per-distro install notes, including the Secure Boot gotcha

The AI/work-life angle — be honest about it: This is a 60-second short with zero AI content. No Claude, no local models, no agent setup. But the *reason* Omarchy keeps showing up in this corner of the internet is that it's a fast, disposable, keyboard-driven Arch base — the kind of machine you nuke and rebuild in a minute, which is exactly what you want when you're running CLI agents and want a clean, reproducible environment. Chuck is building toward that; he just didn't say it here.

Why it matters for you: If you want lab-grade tinkering that travels, a DIY Framework + Omarchy gets you a machine you fully own and can reinstall in under a minute — and it's the same substrate the terminal-native AI tooling crowd is standardizing on.
