Hands-on walkthrough of Grok Bot's always-on agent teams

It's a first-look at spinning up a persistent, multi-agent team where each bot gets its own computer, browser session, and recorded skills — no n8n graph or custom orchestration code required.

What it is: A walkthrough of Grok Bot — a desktop/iOS app for running always-on teams of AI agents that each get their own persistent computer, synced across devices.

How it works:

  • Download from grokbot (Windows, macOS, iOS) — installs on all three so state stays synced. Nate notes access requires being on the Cursor Ultra plan (worth verifying yourself; the transcript is thin here).
  • Onboarding walks you through creating your first bot: name, color, shape. The UI ends up looking like iMessage/Telegram — a sidebar of bots you switch between.
  • Each bot has its own computer. Not a sandbox per task — a persistent VM with browser, file manager, and terminal. Log into a site once (YouTube, Skool) and the session sticks. Nate demos his agent "Klaus" logged into his Skool community as him, liking posts.
  • You can drive the same machine manually — take over the browser, solve the CAPTCHA yourself, hand it back.
  • Teach a Task: record yourself doing something on the bot's computer and Grok Bot converts the recording into a reusable skill. Nate's example: an "AIS" skill and a "7-day challenge post on Skool" skill, both created by demonstration and then run autonomously.
  • Agent-to-agent delegation: each agent has a name, title, and description. The description works exactly like a skill manifest — an agent facing a task scans the other agents' descriptions, finds a match, and messages that agent instead of doing it itself. Nate's "Klaus" (executive assistant) delegates build work to "dev" (AI engineer).
  • Repo context: connect a GitHub repo and every agent inherits it. Nate wires in his own `MyHerk2` repo — the AI operating system / second brain he's been building — so new agents start with his context instead of from zero.
  • Plugins: GitHub was the only connector he'd wired up at record time; Gmail, Google Calendar, Slack, Google Drive, and ClickUp are listed as available.
  • Claim to take with salt: the bots "get smarter over time." No mechanism shown.
