This was a data center a year ago… Now it's on my desk

Alex Ziskind · 2026-07-30 · 166,888 views  ·  Watch on YouTube →
Nvidia DGX Station desktop supercomputer tested on huge LLMs

This is the machine that actually beats a maxed Mac Studio at running 400GB+ models locally — but it needs a 240V outlet and pulls 1,400W, so it's a very different animal than a Mac mini.

What it is: The ASUS ExpertCenter Pro ET900N G3 — an Nvidia DGX Station with a GB300 Grace Blackwell superchip, 748GB of unified memory, sitting on a desk instead of in a rack.

The hardware:

  • Chip: Nvidia GB300 "desktop superchip" — the same silicon that's been in HGX data center service since last year, repackaged for a desk
  • Memory: 748GB total, but it's two fused pools, not one — 256GB ultra-fast HBM (7–8 TB/s) + ~500GB Grace LPDDR5X (500 GB/s). Nvidia calls the combo "coherent memory"
  • Networking: 2× 400Gb ConnectX-8 "SuperNICs" — data-center-grade, lets you cluster multiple boxes. (DGX Sparks ship with ConnectX-7; same idea, half the pipe)
  • Expansion: 3× PCIe slots. Review unit shipped with an RTX Pro 4000; an RTX Pro 6000 also fits
  • Power: ~360W idle, ~1,400W flat out for the chip alone — whole machine at the wall is more. Alex ran it on a 240V/20A outlet rather than a standard US 115V/15A circuit

The memory trick (this is the actual story):

  • Blackwell runs NVFP4 natively — Nvidia's own 4-bit float format. Shrinks a 16-bit model ~4× and runs faster
  • GLM 5.2 goes from ~2TB to 465GB on disk in NVFP4
  • 465GB still doesn't fit in the 256GB fast HBM pool, so it spills into the slower Grace memory
  • It doesn't crawl, because GLM is a mixture-of-experts model — only the offloaded experts each token actually reads hit the slow lane
  • Result: ~24 tokens/sec on a 400GB+ frontier model, on a desk

Models tested:

  • Nemotron 3 Super (120B, NVFP4)
  • DeepSeek V4 Flash
  • Qwen 3 235B (NVFP4)
  • GLM 5.2 (465GB NVFP4 — the headliner)

Mac comparison: Alex explicitly frames the spill-to-slow-memory behavior as "the same trick as running a giant model on a maxed out Mac Studio." Same architectural idea (unified memory, MoE offload), but the DGX Station has a 7–8 TB/s fast tier a Mac Studio simply doesn't have — and a wall-outlet requirement a Mac mini simply doesn't have.
