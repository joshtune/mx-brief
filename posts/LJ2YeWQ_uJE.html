What it is: A one-minute short listing three ChatGPT updates: event-triggered tasks, secure agentic web sign-in, and a temporary price cut on the top model.

How it works:

  • Event-triggered tasks (Plus/Pro): Tasks can now fire when something happens in Gmail, Slack, or GitHub. Example: a matching email lands, ChatGPT summarizes it; a GitHub change occurs, ChatGPT kicks off a workflow.
  • Secure sign-in for agentic browsing (ChatGPT Work): The agent navigates a site, then hands off to your browser password manager or 1Password for auth. ChatGPT never sees the credential.
  • Price cut on the flagship model: Description cites GPT-5.6 Sol at 20% less for the next few months. Applies to heavy use in ChatGPT and Codex. The transcript itself drops the model name, so treat the exact figure as unverified.

Why it matters for you:

  • GitHub-triggered tasks are a zero-code way to get PR or issue summaries without wiring your own webhook, but a real CI or GitHub Action is still the right tool for anything that touches your codebase.
  • The password-manager handoff is the pattern to copy if you ever build agentic features that need to log into third-party sites on a user's behalf.
