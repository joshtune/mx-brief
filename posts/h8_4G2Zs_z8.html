The M5 MacBook Air Changed More Than It Looks

Alex Ziskind · 2026-08-12 · 227,455 views  ·  Watch on YouTube →
Five MacBook Air generations benchmarked, M1 through M5.

If you're eyeing an Air as a cheap local-AI box, this is the generational comparison that tells you what M5 actually fixed — and where Apple quietly capped it.

What it is: A five-generation MacBook Air shootout (M1 → M5), all running macOS Tahoe, testing networking, external displays, storage, and local AI performance.

Test setup:

  • All five Airs updated to macOS Tahoe — even the M1 runs it fine
  • Alex bought all machines himself, no Apple sponsorship
  • Memory deliberately excluded from comparison: M1/M2/M3 base at 8GB, M4/M5 base at 16GB — tests target the chip, not the RAM tier

What M5 changed:

  • Wi-Fi 7 via the new N1 chip — the headline upgrade, plus Bluetooth with distance sensing
  • Single-port dual displays — M5 drives both external monitors off one Thunderbolt port; M4 needed both. Real win when you only get two ports
  • Nothing else physically — same chassis, keyboard, screen, MagSafe, ports as M2/M3/M4. Still Thunderbolt 4, not TB5

Where Apple capped it:

  • Wi-Fi 7 is limited to 160MHz channels, not 320MHz — a built-in bottleneck
  • iperf3 on 6GHz: M5 landed around M4 level and *behind the M3*. On 5GHz it topped out at 625 Mbps
  • Alex speculates the cap is an Air-vs-Pro segmentation thing — unconfirmed

External display progression:

  • M1 / M2 — one external display only
  • M3 — two externals, but lid closed only
  • M4 — two externals + built-in screen (three total)
  • M5 — same as M4, but through one port instead of two

Storage — the long-running crack:

  • Four generations of faster CPUs while SSD speed stagnated
  • The M1 (512GB) still beats the M4 on sequential write
  • Base 256GB drives in M2/M3 are the weak link — 512GB configs use faster NAND. Don't buy the 256GB base if you care about disk throughput
