Your OS Changes Everything for Local AI

Alex Ziskind · 2026-06-30 · 88,772 views  ·  Watch on YouTube →
Testing Windows vs WSL vs Linux for local LLMs on one mini PC.

The machine in question is the GEEKOM A9 Max — a ~$800-class AMD mini PC positioned as a cheaper local-AI box than a comparably-specced Mac mini.

What it is: A local-AI benchmark shootout across three OSes (Windows, WSL, bare-metal Linux) on a single AMD mini PC.

The machine (what you actually care about):

  • GEEKOM A9 Max, 2026 Edition — model HX470
  • Chip: AMD Ryzen AI 9 HX 470 (Strix Point APU) — 12 Zen 5 cores, Radeon 890M iGPU, 50 TOPS NPU
  • Memory: 32GB DDR5-5600
  • Storage: 2TB SSD
  • Ports: dual USB4, dual HDMI 2.1, dual 2.5GbE, 5× USB-A, audio jack, SD reader
  • Same chip as the Beelink Certan Alex tested weeks earlier; he benchmarks it against the Apple M4 Pro as the reference point

Price vs Mac mini:

  • Transcript doesn't state a dollar figure, but there's an 18% coupon: `AZKA9MAX` (official stores) — these A9 Max units land roughly in the ~$700–900 range, undercutting an M4 Pro Mac mini with equivalent RAM/SSD (which climbs well past $1,300 once you spec 32GB/2TB).
  • Verdict framing: cheaper box, but AMD's local-AI software stack is rougher than Apple's.

How it works (the OS/inference findings):

  • Windows + Ollama defaults to 100% CPU — it silently ignores the AMD GPU even with Vulkan enabled
  • Switch to llama.cpp + Vulkan to actually hit the iGPU (~100% GPU util) — only ~10–14% faster than Ollama CPU, and the gain shrinks as models grow (14% at 1.5B → 10% at 14B)
  • AMD Lemonade server offers hybrid recipes: NPU for prefill, GPU for decode; decode ties llama.cpp Vulkan, NPU shines on long-context prompts
  • Some benchmark numbers came in at ~half of the chip's spec — flagged as unresolved
  • Test model referenced: Gemma-class 12B

Tools & links:

  • llama.cpp — direct Vulkan GPU inference
  • AMD Lemonade Server — NPU+GPU hybrid inference
  • Ollama — easy but CPU-only on AMD by default
  • GEEKOM A9 Max — coupon `AZKA9MAX`

Why it matters for you: This is the AMD mini PC to weigh against a Mac mini for local AI — cheaper hardware with the coupon, but expect to fight the software stack (llama.cpp/Lemonade) to get real GPU/NPU performance out of it.
