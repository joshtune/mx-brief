3 New PCs, One Giant AI Model… This Shouldn’t Work

Alex Ziskind · 2026-06-25 · 73,764 views  ·  Watch on YouTube →
Clustering three Panther Lake NUCs to run 70B AI.

Three $-each ASUS NUC 16 Pro mini-PCs gang up to serve a 70B model — a direct mini-PC-vs-Mac-mini AI box comparison.

What it is: Alex clusters three ASUS NUC 16 Pro mini-PCs (Intel Panther Lake) to run Llama 3.3 70B and benchmarks two clustering strategies.

The machines:

  • 3× ASUS NUC 16 Pro — Intel Core Ultra X7 358H
  • New Arc B390 GPU inside, up to 50 TOPS on the NPU
  • 64 GB RAM per unit (his config)
  • Pricing vs Mac mini: not stated in the video — check the gear links below

How it works:

  • Model-splitting (shard one model across all three): runs Llama 3.3 70B (a large dense model no single 64GB box can hold) — but only 1.4 tokens/sec. Disappointing.
  • Replication (full copy per machine, route each request to a different one): this is the win. One machine = ~196 tok/s under load; three machines = ~500 tok/s, ~2.5× faster. Scales for throughput, not for fitting a bigger model.
  • Takeaway: clustering cheap mini-PCs buys you *concurrency/throughput*, not the ability to run a model too big for one box.
