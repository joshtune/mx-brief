Framework 13 Pro...Why Apple Solders Memory

Alex Ziskind · 2026-08-20 · 51,564 views  ·  Watch on YouTube →
Framework 13 Pro vs M5 MacBook Pro dev benchmarks

If you're weighing a Linux dev box against Apple silicon, this shows where 16 cheaper cores beat 10 Apple ones — and where they don't.

What it is: Head-to-head developer benchmark of the Framework Laptop 13 Pro (modular, Linux, 16 cores) against the M5 MacBook Pro (10 cores).

The machines:

  • Framework Laptop 13 Pro — modular x86 laptop, runs Linux, 16 CPU cores, user-replaceable RAM and expansion cards
  • M5 MacBook Pro — 10 cores, soldered memory (the title's framing: Apple solders for bandwidth/latency, Framework trades that for upgradability)

Benchmark results:

  • Manor Broad multi-core (Python, pegs all cores): Framework 23–25s vs MacBook ~30s — Framework wins on raw core count
  • DevBench "Hello World" (tiny build): MacBook 836ms cold / 294ms warm / 335ms incremental; Framework 2,172ms cold / 446ms warm / 491ms incremental — MacBook wins decisively on small builds
  • DevBench huge build (100k namespaces/classes): MacBook 85s cold, 10.5s warm; Framework 54s cold, 7.9s warm — Framework wins big
  • Orchard Core build: near-tie; Framework a couple seconds faster cold, warm/incremental within half a second

The pattern: M5's per-core speed dominates short workloads; Framework's 16 cores pull ahead once the project is large enough to saturate them. Crossover is somewhere between "hello world" and a real codebase.

Tools & links:

  • WisdPi 10G Ethernet Expansion Card — Framework expansion module shown in the video
  • DevBench — build-time benchmark used for cold/warm/incremental compilation tests
  • Manor Broad — Python multi-core saturation test

Caveat for your use case: No AI/LLM inference benchmarks here — no tokens/sec, no local model runs, no memory-bandwidth tests. Pricing isn't broken out in the transcript either, so there's no direct Mac mini cost comparison to pull.

Why it matters for you: This is a build-times video, not an AI-inference video — if you're picking a machine to run local models, the soldered-memory bandwidth argument in the title is the relevant thread, but Alex doesn't test inference or give you the price-per-machine math to compare against a Mac mini.
