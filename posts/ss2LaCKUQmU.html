Weekly AI roundup: Claude Code browser, Google, Spotify updates.

Claude Code's new in-app browser lets you visually select page elements and have the agent edit your web app's code in place — directly useful for how you build.

What it is: A weekly AI news roundup; the one segment worth your time is Claude Code's new in-app browser for desktop.

How it works (Claude Code browser):

  • Only works on the Claude Code side (not the normal chat), inside an open project
  • Open it with `Cmd+Shift+B` or the browser icon in the top right
  • Browser docks on the right of your code window
  • Element annotation: select a live element on your rendered site → it highlights the matching code on the left → tell it what to change (e.g. "change the button text") and it edits the source in place
  • Browser as data tool: point it at a site and have it scroll/scrape (e.g. X, Instagram) instead of paying for expensive APIs like the X API

Other headlines (skimmable):

  • Google AI Search apps: AI mode can now connect to third-party apps mid-prompt (e.g. build a grocery list → connects to Instacart). Search is becoming an agent.
  • Google Vids: now uses Gemini Omni to animate slides, chat-to-edit videos, and drop in your own avatar (birthday-card style clips).
  • Spotify: Premium users can now talk/type to Spotify to shape playback, dig into listening history, and explore podcasts.
