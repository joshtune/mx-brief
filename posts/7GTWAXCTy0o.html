I Built the Ultimate AI Board of Advisors

Nate Herk | AI Automation · 2026-10-13 · 86,705 views  ·  Watch on YouTube →
Claude Code sub-agents of famous founders debate your business decisions

If you want a free, reproducible multi-agent pattern (persona sub-agents + knowledge folders + voting) for stress-testing decisions in Claude Code, this is the blueprint, though the actual skill is gated behind a comment.

What it is: A Claude Code skill called the "roast room" that spins up seven founder/advisor personas as sub-agents, has them debate a business question, vote, and output a PDF verdict.

How it works:

  • Agents: Each advisor is a sub-agent defined in the `.claude/agents` folder: Bezos, Buffett, Gary V, Alex Hermozi, Dan Martell, and Gino Wickman (seven agents total are launched per session).
  • Brains: A separate `brains` folder holds per-person knowledge. Hermozi's brain, for example, has books, frameworks, positions, principles, sources, stories, and voice files.
  • Knowledge source: The brains were built by scraping public videos and talks, over 1.3 million words for Hermozi alone.
  • Kickoff: Triggering a roast room makes Claude Code launch all the sub-agents and load each one's brain.
  • Debate: The agents argue with each other in rounds (Hermozi vs Bezos, Gary V vs Buffett, Martell vs Gary V).
  • Vote: After the debate they vote on the options, producing weighted average scores.
  • Deliverable: A PDF showing the council's decision, weighted scores, the recommendation, and key points on how the council landed.
  • UI: The visual dashboard is optional. The same session runs inside plain Claude Code and returns the deliverable and full info in the terminal.

Tools & links:

  • Claude Code (https://claude.com/claude-code) — runtime for the sub-agents and the skill
  • Claude sub-agents (https://docs.claude.com/en/docs/claude-code/sub-agents) — the `.claude/agents` mechanism each advisor uses
  • Roast room skill — free, but only via commenting "roast room" on the video; no repo or URL is given in the transcript

Why it matters for you: The architecture (persona agent plus a structured brain folder plus debate-and-vote orchestration) is easy to copy for your own advisory panels, but the transcript is a teaser, so you'll need the comment-gated skill or your own build to get the details.
