I Tested Opus 5.5 vs. GPT-6 Sol on 10 Real Use Cases

Nate Herk | AI Automation · 2026-09-23 · 54,033 views  ·  Watch on YouTube →
Head-to-head test: Opus 5.5 vs GPT-6 Sol across 10 real tasks.

If you're picking a model for agentic work, this is a live pricing-vs-quality comparison with a concrete failure case (wrong date recall) that shows accuracy gaps you won't catch from benchmarks alone.

What it is: A 10-use-case bake-off between Claude Opus 5.5 and GPT-6 Sol (via Codex), covering website builds, video editing, slide decks, browser use, and reasoning-heavy tasks — same prompt given to both models each time.

How it works:

  • Pricing framing first: Opus 5.5 is $4/$20 (input/output) per million tokens vs Sol's $2/$10 — exactly 2x — so Nate evaluates on a "$100 of spend, which gives better output" basis rather than raw score.
  • Warm-up test before the 10 cases: both models run in parallel via Claude Desktop (Opus) and Codex Desktop (Sol) on two tasks — (1) pull the two latest Fireflies call transcripts for Q4 planning and ingest them into a wiki, (2) find the last AIS Plus Q&A where he mentioned "NAND" (a mistranscribed term).
  • Sol/Codex answered the NAND question wrong (Aug 17) while Opus got it right (Sept 14) — both finished ingesting the ~4-hour combined transcript into the wiki in about the same time, but Opus's retrieval accuracy was clearly better.
  • Use case #1 shown in detail: a landing page build for a protein-coffee brand ("Perk"), testing layered scroll animations, parallax imagery, text reveals, and FAQ sections — transcript cuts off before revealing which model produced it or scoring the rest of the 9 cases.
