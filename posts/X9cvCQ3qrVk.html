Matt Wolfe · 2026-06-10 · 6,272 views  ·  Watch on YouTube →
New GitHub Copilot app promises any-model coding, but signups are paused.

A model-agnostic coding agent could let you pick the fastest/cheapest LLM for building your web apps instead of being locked to one provider — but right now it's vaporware you can't actually use.

What it is: A new GitHub Copilot desktop app (shown at Microsoft Build) that gives a Codex-style coding agent experience but lets you choose any model from any provider.

How it works:

  • Same overall experience as OpenAI's Codex coding app
  • Key difference: not locked to OpenAI models — pick whatever's currently state-of-the-art, fastest, or cheapest
  • Requires an active GitHub Copilot subscription to use
  • Matt couldn't actually test it: new plan signups are "temporarily paused" — so the whole video is anticipation, not a demo

Tools & links:

  • GitHub Copilot — https://github.com/features/copilot — the new model-agnostic coding app (announced at Microsoft Build)
  • OpenAI Codex — the locked-to-OpenAI competitor Matt compares it against

Why it matters for you: If it ships, model-provider choice in a Copilot coding agent means cheaper/faster builds for your web apps without vendor lock-in — but skip the video until you can actually sign up; there's nothing to act on yet.
