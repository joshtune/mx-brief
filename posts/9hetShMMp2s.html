Claude Desktop mods: plugins that customize its UI

Nate shows how to install mods by pasting them into Claude and how to have Claude build custom ones from your own session logs, though the transcript cuts off before he finishes the list.

What it is: Claude Code "mods" are plugins that change the Claude Desktop UI. You can describe a feature in plain English and Claude builds it.

How it works:

  • Mods ship inside plugins. Install them with `/plugin` in the CLI or desktop app.
  • Quick install: copy the mod's code or snippet, paste it to Claude, and say "set up this mod". Nate says it takes about 30 seconds and the UI element appears in the same chat.
  • Build your own: update Claude, then say "I want a mod for X" in natural language.
  • Nate's discovery trick: he had Claude read through lots of his past session logs. It looked for repeated phrases and frequent tasks, then suggested the top 5 mods to save money, move faster and stay organized. He didn't take them all, but it gave him ideas.
  • Official examples from the Claude devs' release tweet:
  • *Token weather* shows how full the context window is, inside the UI.
  • *Blast radius* previews what a destructive action would delete, so you can proceed or cancel.
  • *Replay theater* replays recent edits step by step with all the diffs.
  • Next steps is by a Claude Code engineer, written "Thoric" in the transcript. At the end of every turn it pops up about 3 suggested next actions, or you can dismiss it.
  • Nate's demo asked about ClickUp action items. The suggestions were to close demo and hackathon tasks, push certification due dates, or run a morning coffee briefing.
  • His take: marginal for knowledge work, but likely more useful when building an app ("fix this bug first", "merge these changes").
  • Cache mod (his first "actually helpful" one):
  • It shows the prompt-cache countdown (he showed it going 57 → 60 minutes after a message).
  • Everything in a chat is cached, so new messages don't re-pay full price for old text.
  • If you leave a session idle for more than 60 minutes, you re-pay for the whole context.
  • The mod also shows what that expiry would cost, which grows as the window fills.
  • Others on screen: a "command center" mod that shows notifications, and a pet mod he calls "pretty useless". He is skeptical of the viral visual-workflow mods going around X.
  • Transcript gap: it cuts off mid-explanation of the cache mod. The other mods he covers are not in the data, so the "5" in the title can't be confirmed here.
