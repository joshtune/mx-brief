AI agent IT department diagnoses a toilet-triggered network outage

Chuck is running a fully agentic IT department (networking, storage, security agents as 'employees') on his own home lab, which is the work-life AI setup you envy.

What it is: A short teaser for Chuck's full video. He sets up an all-AI IT department in Paperclip and has it chase a bug: everyone drops off the NAS whenever someone flushes the toilet.

How it works:

  • Agents as employees: Paperclip models each agent as a staff member. Networking, systems engineering, storage and security roles each get a manager and assigned tasks.
  • Communication runs through tasks: Agents talk to each other via the task itself, not free-form chat. That keeps it intentional and focused.
  • Everything is trackable: Timelines and task history make the work traceable, so you can audit how the agents reached a conclusion.
  • The agents' verdict: It's not the toilet. Four links on 'flu powder', his MikroTik switch, have been broken for 15 months. Anything that disturbs the building knocks them over, and nothing else on the switch notices.
  • Chuck's counter-theory: Mike flushes and opens the bathroom door forcefully. The vibration jostles gear in the adjacent server room.
  • The fix: Replace the modules and patch the cables.
  • Parallel work: The agents worked the problem simultaneously, which clearly impressed him.
