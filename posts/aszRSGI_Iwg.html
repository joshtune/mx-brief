3 New Ways To Use ChatGPT Codex

Matt Wolfe · 2026-08-15 · 15,991 views  ·  Watch on YouTube →
Codex adds browsing, one-click web publishing, phone control.

Codex can now preview and publish a web app to a shareable URL without you touching hosting — that's a real shortcut for demoing side projects.

What it is: A 60-second promo clip listing three newer capabilities in the ChatGPT Codex app.

How it works:

  • Browser-based social scraping — Codex opens a real browser, clicks through sites, and searches posts/topics in-app. No platform API keys, no OAuth dance, no rate-limit paperwork for one-off research.
  • Build → preview → publish — Build a dashboard, game, or web app and ship it to a shareable link from inside Codex. Preview, iterate, publish. No separate hosting step.
  • Phone as remote — Connect an iPhone to the Codex desktop app via the remote feature, start a voice session, and steer work running on your machine: update the site, check a task, run tests, change direction — all away from the desk.

Tools & links:

  • ChatGPT Codex — the agentic coding app all three features live in
  • futuretools.io — Matt's tool directory (channel's standing plug)

Reality check:

  • This is an ad, not a tutorial. Zero setup steps, zero gotchas, zero pricing. Transcript is ~200 words with music stings.
  • The publish target is OpenAI-hosted preview infrastructure, not your infra. Fine for demos and stakeholder links; don't confuse it with a deploy pipeline.
  • Browser-driven scraping is slow and brittle versus an API. Good for exploratory pulls, bad for anything scheduled.

Why it matters for you: The instant shareable-link publish is the one piece worth trying on a web app project — it collapses "built it locally" to "someone else can click it" without standing up hosting.
